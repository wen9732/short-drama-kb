# 案例库｜总说明

案例库收的是**可以拿来对照的作品正文**。规则不在这里，规则只在 `.claude/skills/`。
用户发 `收案例：` 时，按本文件的「收录流程」处理。写提示词要借鉴案例时，按「案例怎么用」处理。

## 案例怎么用（不能照抄）【用户】

案例只是辅助，目的是让提示词产出得更快、更好，**不是拿来原样调用**。

1. **先有本场戏，再找案例。** 先按 `工位/导演.md` 定配方、想清楚这场戏要什么；卡在某个写法上，再去各类 `索引.md` 的「写法反查」里找。不要先挑一个案例，再往里套自己的戏。**例外：** 用户点名类型或对标作品时，动笔前先查同类型对标、读它的机制（见 `script-shanyin` 接入补充规则 3），这一步不能省。
2. **只取机制，不取文本。** 学的是"它怎么解决这个问题"，然后用本场戏的人物、地点、道具重新写一遍。例：学《反相之地》的"怪物只在一个时间窗出现，之后连倒影都不许有"，写成"本场的鬼影只在第 4 秒出现在镜子里，之后镜子里只剩她自己"。
3. **不搬原作的东西。** 人物名、台词、怪物、法宝、专有设定、场景，一律不搬；成段的句子不复制；"徐克《青蛇》……的浓艳美学"这类美学总纲和"8K、ARRI、UE5"这类参数串，也不照抄，按本场需要重写，视觉部分归 `genre-` 层。
4. **原稿的格式不继承。** 小数秒、帧级要求、括号里的"不是X，像Y"、超长质感段，都按 `exec-seedance25` 改写。
5. **交付前查照抄。** 运行 `python3 tools/check_copy.py 草稿文件`。有连续 25 字以上和案例相同的段落，就改写到干净为止。
6. **借了什么，说一句。** 在回复里用一行写明"借了 D01 的怪物时间窗"，方便用户回查；不用长篇解释。

## 分类

**分类规则：整部作品按题材归类；单场示范按层归类；多集连载的系列单独放进 `短剧/`。**
- 题材类收的是整部作品或整个画布，用来学"一部片怎么写"。
- 层类收的是单场戏，用来学某一层（表演、转场、动作）的写法。
- 一部作品里有某场戏特别值得某一层学习时，不复制正文，在那一层的索引里写一行"另见 G01 第5条"。

| 目录 | 编号前缀 | 收什么 | 对应的库 |
|---|---|---|---|
| `短剧/<剧名>/` | D | 多集连载的系列作品，按集存放（`第01集.md`）。题材写在索引里 | 跨层 |
| `国风修仙/` | G | 神话、修仙、志怪、古装奇幻的整部作品 | 将来的 `genre-` 国风库 |
| `科幻悬疑/` | S | 科幻、末日、怪兽、悬疑、惊悚的单篇作品 | 将来的 `genre-` 科幻库 |
| `真人情绪表演/克制型/` | K | 压住情绪、隐忍、强撑体面的真人情感戏 | `perf-restrained` |
| `真人情绪表演/爆发型/` | B | 对峙、嘶吼、脏话、情绪失控的真人戏 | `perf-explosive` |
| `真人情绪表演/对照案例/` | C | 有可取之处、也有明显问题的作品，当正反对照用 | 表演层 |
| `镜头-转场/` | T | 以转场设计为主要看点的作品 | `cam-transitions` |
| `动作特效/` | A | 追逐、打斗、特效动作（暂存，等打斗库建成后改名 `动作-打斗/`） | `fight-`（待建） |

**新类别怎么建：** 一种作品放不进上面任何一类、而且至少有 2 个案例时，才新建目录。目录名用"大类-小类"，表演层的作品统一放在 `真人情绪表演/` 下面。建好后要做三件事：给它定一个没用过的编号前缀（导演库占用了 M、HW、JP、KR、CN，转场类型占用了 T01–T34，都不能用），补上它的 `索引.md`，在上表加一行。只有 1 个案例时，先放进最接近的类别，在索引里注明。

**一场单场示范跨了好几层，归哪一类？** 按它**最值得学的那一层**归类。其他相关类别的索引里只写一行指向，不复制正文。例：一场哭戏里用了很漂亮的转场，如果主要学的是表演，就归 K，再在 `镜头-转场/索引.md` 里写"另见 K0X"。

## 五种提示词骨架（对照用）

同样是一条视频提示词，库里的作品有五种写法。写新提示词前先想清楚用哪一种：

| 骨架 | 长什么样 | 适合 | 代表 |
|---|---|---|---|
| 分镜八要素式 | 人物全程状态卡 → 场景、道具、声音 → 风格与参考片 → 分镜 N（时间、景别、机位、构图、运镜、画面、动作表情、台词声音） | 多人、多镜、要求连续性的剧情；**爆款对标** | D01《反相之地》 |
| 时间码长段式 | 美学总纲一句 → 参考图身份 → 方位坐标 → `00:00-00:05：起幅 50mm……硬切 85mm……` → 分层音效 → 具体禁止清单 | 大场面、少台词、奇观 | G01《封神》 |
| 阶段式 | 整体描述 → 情绪递进 → 第 N 阶段（时间、镜头、表演、台词） → 约束 | 情感文戏 | K03–K07 |
| 镜头表式 | 全局设定 → 镜头表（镜号、景别、运镜、切镜过渡、画面、音效、情绪、光影、构图） | 多场景快切 | S01《新数码宝贝》 |
| 图生视频指令式 | 依赖参考图，只写画面里要发生的变化，反复要求"不改构图" | 有分镜图、逐镜生成 | G02《山海有妖》 |

本库的标准模板（`exec-seedance25`）最接近"分镜八要素式"。其他四种用来借鉴局部写法，格式以 `exec-seedance25` 为准。

## 收录流程（口令 `收案例：`）

1. **查重。** 先运行 `python3 tools/check_kb.py`，再把新作品和 `范例/`、`原始素材/` 比对；去掉空白后完全相同的就是重复。已经在范例里的，不再收，直接告诉用户它的编号。只在原始素材里的，收进范例，再把原始素材里那一条改成指针："已收入 `范例/…`，正文见该文件。"
2. **清理。** 只留正文提示词。下面这些全部删掉：画布链接、工作区、节点号、"参数："行、参考图清单、"提示词全文（逐字…）"这类标题、提取注释"（注：…）"。正文里的错别字、小数秒照原样保留，不在案例里修改。
3. **分类、编号。** 按上面的分类表定目录，编号接着该类别现有的最大号往下编。文件名格式：`两位序号_场景_核心写法.md`，例：`09_病房探视_沉默递水.md`。
4. **写索引。** 在该类别的 `索引.md` 里做三件事：总表加一行（编号、文件、场景｜时长｜台词语言、可调用的写法、评价与出处）；给「写法反查」表补上它能对照的写法；用户给了评价的，照原话记下来。
5. **判断要不要升规则。** 用户的评价里如果有"以后都这样"，或者同一个现象已经在 2 个案例或 2 条日志里出现过，就提出升级为规则，按 `维护手册.md` 第六节办。只是案例本身的特点，留在索引里，不写进技能。
6. **校验、提交。** 运行 `python3 tools/check_kb.py`，通过后提交。收新案例算"新增范例"，属于小版本，按 `维护手册.md` 第六节升版本号、记 `CHANGELOG.md`、更新 `日志/当前状态.md`。

## 索引条目模板

```
| K09 | `克制型/09_病房探视_沉默递水.md` | 病房探视｜15 秒｜中文 | 写法一、写法二、写法三 | 出处；用户评价原话 |
```

「可调用的写法」用短语写，要能直接拿去「写法反查」表里查。不要写"情绪很到位"这种评价，评价放在最后一列。

## 校验脚本会自动检查什么

- 每个类别目录下都有 `索引.md`，目录里每个案例文件都出现在索引里。
- 范例之间没有重复的正文，范例的正文也没有在 `原始素材/` 里再存一份。
- 范例文件里没有画布元数据残留。
