## 二、三大画风光谱的边界与识别铁律（严禁把所有动画一刀切洗成皮克斯/迪士尼）

1. **【光谱 A：写实拟人电影风（以 `N02 班尼打工日记` 为代表）】**
   - **视觉核心：** 追求“把超写实毛发与衣料纤维的拟人动物放进真实电影实拍镜头里”的质感。**必须保留** `电影级现实主义、35mm/50mm 自然焦段、f/2.8-f/4 真实浅景深、细腻克制的 35mm 胶片颗粒、温暖自然阳光/丁达尔光束`，并**反向锁死 `避免 CG 感、避免 3D 动画感、避免玩偶感、避免塑料感`**。
   - **表演尺度：** 走韦斯·安德森或真人生活流冷幽默——靠“半垂死鱼眼、长耳自然下垂、一本正经的平静语气讲最荒唐的台词（内裤与真心、一万变三万、麻辣兔头流水线）”制造反差；动物器官微表情（耳尖微动、鼻腔呼气、眼神游移）只做写实克制点睛，**严禁套用 `N03` 的眼珠暴突或皮球压扁**。
2. **【光谱 B/C：高级 MJ 现实梦幻美学 × 2D 艺术插画混媒 / 手作毛毡定格（以 `N01 路西的世界` 为代表）】**
   - **视觉核心：** 环境层是**高审美 Midjourney 异世界微距温室**（肥厚莲座多肉、半透明玻璃质感卷须、粉珊瑚与翡翠绿交织的柔软发亮叶缘、潮湿轻雾空气感、写实人手第一人称伸入拨叶）；角色层是**纯正 2D 独立艺术插画生物**（或 `12fps` 手工戳制毛毡纤维布偶）。
   - **保护边界：** **严禁把 2D 艺术生物同化渲染成 3D 塑料模型，严禁把角色参考图里的 2D 背景色块带入 3D 丛林，也严禁把 MJ 高级梦幻植物降级为低幼 3D 卡通森林**。
3. **【光谱 D：院线 3D 卡通迪士尼/皮克斯喜剧风（以 `N03 唐阿虎求职记` 为代表）】**
   - **视觉核心：** 高明度 HDR 全局光照、细腻蓬松毛发与皮肤 `SSS 次表面散射`。
   - **表演尺度：** 全面放开**动画十二法则与夸张卡通物理**——允许`眼珠暴突、脸颊肚皮被踹成扁平再像弹簧反弹飞出、身体像皮球滚动、人肉板凳像气球压扁回弹、咆哮声浪空气波、速度线与残影`。
