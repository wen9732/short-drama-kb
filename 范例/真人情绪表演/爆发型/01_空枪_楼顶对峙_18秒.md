# 《빈 총》（空枪）｜18秒｜韩国黑色犯罪片·爆发型

## 台词
| 韩语 | 意思 |
|---|---|
| 쏴. | 开枪。 |
| 쏘라고, 씨발! | 我让你开枪啊，操！ |
| 아이씨……왜 안 도망갔어, 이 개새끼야! | 妈的……你为什么不跑啊，你这个混蛋！ |
| 총알은 내가 뺐어. | 子弹我卸了。 |
| 씨발…… | （又哭又笑地）操…… |

## 提示词
```
【视频约束】18秒，16:9。韩国黑色犯罪电影质感，粗粝、紧绷、情绪爆裂。全部台词为韩语，严格按台词生成，禁止增减台词，脏话照原样说出。无背景音乐，无字幕，无旁白，只保留风声、雨声、呼吸声、对白和枪械声。人物为正常人眼，不发光。全片只用胸部以上的近景、特写和手部特写，禁止全身镜头。

【影像】35mm胶片质感，粗颗粒，低饱和，高反差。主光是楼顶边缘的冷白色工作灯，从侧面硬打过来；背景是首尔夜空下成片的红色霓虹十字架，虚化成红色光斑。阴影偏青黑色。手持摄影，晃动明显但不乱。多处使用荷兰角，画面倾斜约15到20度，制造失衡感。焦段偏长，背景压缩。

【风场】楼顶强侧风，从画面左侧持续吹向右侧，夹着斜飞的雨丝。女主银灰色长发和刘海被风持续抽打到脸上；男主黑色凌乱刘海被吹乱，西装下摆和衬衫领口不停抖动。风声贯穿全片，盖过城市底噪。

【参考】图片1为男主（先出场），参考其五官、黑色凌乱刘海、眼周暗红色眼妆、雀斑、银色圈形耳环、黑色西装与白衬衫；他嘴角有一道新鲜的血迹。图片2为女主，参考其五官、银灰色长直发与齐刘海、酒红色挂脖上衣、黑色皮质项圈与绑带。

【站位】深夜楼顶，下着暴雨。女主在画面左侧，男主在画面右侧，两人相距一臂远，面对面。

【情绪上限】女主可以嘶吼，声音会破，但不能变成舞台剧式的尖叫；泪水只在第9到12秒落下一滴。男主全程不怕死，笑里带着疲惫，不疯癫狂笑。

0-3秒：女主面部特写，荷兰角向左倾斜。前景是她伸直手臂握着的黑色手枪，枪身虚化，占据画面右下角。她双手握枪，手臂绷直，枪口微微发抖。风把湿发抽打在她脸上，她没有拨开。她咬着牙，鼻翼翕动，呼吸又急又重，眼睛死死盯着前方。画外传来男主一声短促的、带着气音的轻笑。

3-6秒：男主面部近景，低机位仰拍，荷兰角向右倾斜。他看着枪口，嘴角带血，反而笑了一下，笑意到不了眼睛，只剩疲惫。风吹乱他的刘海。他往前迈了半步。
男主台词（低沉，平静，几乎带着笑）：쏴.

6-9秒：双人侧面近景，胸部以上，镜头剧烈手持跟随。男主突然伸手攥住女主握枪的手腕，把枪口一把拉过来，死死顶在自己额头正中。女主的手臂被拽得一晃，她下意识想往回抽，没能抽开。
男主台词（突然爆发，嘶哑，最后一个词几乎是吼出来的）：쏘라고, 씨발!

9-12秒：女主面部大特写，荷兰角倾斜加大，镜头跟着她的情绪晃动。她的脸在发抖：下颌绷紧又松开，嘴唇抽搐，眼眶通红，一滴眼泪终于从右眼滚下来，马上被雨水冲散。她吼出来，前半句压着，后半句破音。
女主台词（先是咬牙压低的"아이씨"，随后整句爆发，"개새끼야"嗓子撕裂破音，带着哭腔）：아이씨……왜 안 도망갔어, 이 개새끼야!

12-15秒：先切女主手部特写：食指扣在扳机上，指节发白。她闭上眼睛，扣下扳机，只听到一声干脆的"咔哒"空响，没有枪声，没有火光。紧接着切女主面部特写，她猛地睁开眼，愣住，呼吸停了一瞬。风声和雨声在这一刻突然变得很大。

15-17秒：男主面部特写，枪口仍然顶在他额头上。他松开她的手腕，用拇指抹掉嘴角的血，嘴角慢慢扬起一个很轻的笑，眼神温柔得近乎残忍。
男主台词（很轻，几乎是耳语，被风声压着）：총알은 내가 뺐어.

17-18秒：女主面部特写，荷兰角回正。她的表情从错愕崩成一个又哭又笑的扭曲表情，嘴角往上扯，眼睛却在哭，从鼻腔里挤出一声破碎的笑。
女主台词（又哭又笑，气音，声音发抖）：씨발……
随后直接切黑，风声戛然而止。

【道具状态】手枪从头到尾都在女主手里，始终没有开火。男主嘴角的血迹全程保持。

【排除内容】禁止全身镜头，禁止枪口喷火或出现枪声，禁止慢动作，禁止舞台剧式尖叫和狂笑，禁止瞪眼张嘴式的夸张表情，禁止增加人物。无背景音乐，无字幕。
```
