# 《마지막 잔》（最后一杯）｜18秒｜韩国写实犯罪片·克制型

> 用户评价：方向是对的，但对"想要的刺激度"来说偏平淡，后续改写为爆发型《空枪》。
> 保留原因：这是克制型写法的完整示范——两次反转、零动作、最轻的一句台词放在最重的位置。适合文艺向、李沧东式的需求。

## 设计要点
- 两次反转：观众先以为是约会 → 桌下特写看到她解开枪套 → 他推过酒杯"喝了再动手"，原来他早知道。
- 无枪响、无哭喊、无大动作，最后一句后直接切黑，结局留白。

## 台词
| 韩语 | 意思 | 潜台词 |
|---|---|---|
| 늦었네. | 你来晚了。 | 我等你很久了，像在等一场约会。 |
| 마시고 해. | 喝了再动手。 | 他知道桌下发生了什么，不躲不求饶。 |
| 도망가지 그랬어. | 你怎么不跑啊。 | 她希望他跑；埋怨他，更埋怨自己。 |
| 네가 오는데, 어딜 가. | 你要来，我能去哪儿。 | 来的是她，他就不跑。 |

## 提示词
```
【视频约束】18秒，16:9。韩国写实犯罪剧情电影质感，克制、安静、压抑。全部台词为韩语，严格按台词生成，禁止增减台词。无背景音乐，无字幕，无旁白，仅保留雨声、环境声与对白。人物为正常人眼，不发光。全片只使用胸部以上近景、特写和桌下局部特写，禁止出现人物全身镜头。

【影像】35mm胶片质感，明显但细腻的颗粒，低饱和。主光是帐篷顶上一盏裸灯泡与橙色防水布透下来的暖橙色光，阴影偏青绿色，冷暖分明。焦段偏长，背景压缩虚化。机位以固定为主，只有极轻微的手持呼吸感。不打补光，暗部保留层次。

【参考】图片1为男主（先出场），参考其五官、黑色凌乱刘海、眼周暗红色眼妆、雀斑、银色圈形耳环、黑色西装与白衬衫。图片2为女主，参考其五官、银灰色长直发与齐刘海、酒红色挂脖上衣、黑色皮质项圈与绑带；她右大腿上绑着黑色皮质枪套。

【场景】深夜下雨，路边的韩式帐篷小酒馆（포장마차）。橙色防水布帐篷，透明塑料门帘，雨水顺着帘子往下流。塑料折叠桌上放着一瓶绿色烧酒瓶和两只倒满酒的小玻璃杯，其中一杯摆在空位前。店里没有其他客人。

【站位】男主坐在桌子画面左侧，朝右；女主坐在画面右侧，朝左。两人隔桌相对，全程只有一人说话。

【情绪上限】女主全程不哭出声，泪水不落下，不咆哮。男主全程不激动、不辩解、不求饶，他已经接受了结局。

0-3秒：男主胸部以上近景，固定机位。他独自坐在桌前，低着头，食指慢慢转着面前那只烧酒杯，雨声密集。背景虚化处，透明塑料门帘被一只手掀开，冷风把帘上的雨水甩进来。男主转杯的手指停了一下，但没有抬头。

3-6秒：过男主肩膀拍女主，胸部以上。女主坐下，银灰色头发被雨打湿，几缕贴在脸颊上，她没有擦。她看着他，下巴微微绷紧，嘴唇抿成一条线。
男主台词（平静，像在说一件平常的事，不抬头，尾音下沉）：늦었네.
女主没有回答，只是看着他，眨了一次眼。

6-8秒：桌下局部特写，浅景深，前景是虚化的塑料桌沿。女主的右手垂到右大腿外侧的黑色皮质枪套上，拇指拨开枪套的扣带，手指握住露出来的枪柄，然后停住。枪套扣带打开的声音很轻，几乎被雨声盖住。

8-12秒：男主面部特写。他这才第一次抬起眼睛看她，眼神很平静，甚至带着一点疲惫的温柔。他把她面前那杯还没动的烧酒，用两根手指往她的方向轻轻推近一点，手指在杯沿多停了一瞬才收回。
男主台词（很轻，几乎带一点笑意，"마시고"说得慢，"해"轻轻落下，不是命令）：마시고 해.

12-15秒：女主面部特写，背景是虚化的橙色帐篷光。她原本稳住的表情出现裂缝：下眼睑先收紧，鼻翼快速翕动一次，喉咙吞咽一次，眼眶慢慢泛红，泪水蓄在下眼睑，不落下。她没有碰那杯酒，视线短暂落到杯子上，又逼自己抬回来看他。
女主台词（声音压得很低，带着压住的埋怨，像是在怪他，又像在怪自己，句尾下沉，不是质问）：도망가지 그랬어.

15-17秒：男主面部特写。他看着她，嘴角慢慢扬起一个很浅的笑，笑意一直到达眼睛，没有一丝害怕。
男主台词（温柔，平稳，"네가 오는데"稍慢，"어딜 가"很轻地收尾）：네가 오는데, 어딜 가.

17-18秒：硬切回女主面部特写。她的嘴唇轻轻颤了一下又被她咬住，握枪的那侧肩膀微微一沉。画面在她湿润却没有落泪的眼睛上停住，随后直接切黑，没有枪声。

【道具状态】两只烧酒杯始终在桌上。女主面前那杯酒从头到尾没有被喝。枪全程留在桌下的枪套里，不出现在桌面以上的画面中。

【排除内容】禁止全身镜头，禁止枪出现在桌面以上，禁止枪声，禁止慢动作，禁止偶像剧式柔光和慢推，禁止瞪眼、张嘴愣住、泪流满面式表演，禁止增加人物。无背景音乐，无字幕。
```
