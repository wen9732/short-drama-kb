# A07｜裂变示范：悬崖栈道御剑缠斗，一剑压塌三层崖台

> **裂变自 A03**（楼内高速缠斗，重劈贯穿楼层）。换了三根轴：手段（刀与爪 → 飞剑与重剑）、空间（多层楼内 → 悬崖栈道与崖台）、制式（写实 CG → 三维国漫）。保住的骨：两个高速个体互相追砍，每次交手打掉一处支撑，最后一记下劈把对手连续压穿数层。
> **未实测。** 本库自己写的示范稿，用来对照"打斗段怎么按新规则编译"：站位卡、能力合同、六拍、下一镜四问、段尾停在未完成相位。跑通之前不当规则用。
> 人名是占位，用时换成自己的；`@图片N` 换成平台上的实际素材名。

## 设计表（给人看的，不进提示词）

| 项 | 内容 |
|---|---|
| 体验 | 险中求胜：先被压着打，借对方的重击反手一剑定局 |
| 连招链 | 争线链起手 → 重击破局链收尾 |
| 摄影机流派 | 冷静的旁观者（宽景、稳、慢而流畅），只在最后一击用一次冲击扰动 |
| 节点 | ①栈道对冲，第一段栈木断 ②乙重剑下压，甲被逼到栈道外沿 ③甲借反震跃起 ④甲下劈，乙连同栈道压穿三层崖台 |
| 每镜换了什么 | 镜1→2：距离（十步→一臂）、景别、机位方位；镜2→3：攻击权（乙→甲）、高度层（同层→甲在上）、机位高度；镜3→4：景别（中→超远）、高度层、运镜 |
| 段尾 | 停在尘雾里甲落到第三层崖台、剑尖未收的一刻，不摆定格 |

## 第1条｜提示词（15 秒）

```
15秒，16:9，三维国漫写实CG，仙侠动作。主题：悬崖栈道上的御剑缠斗。剑修沈砚被持重剑的魔修厉屠压着打，退到栈道外沿；他借厉屠一记下压的反震跃到高处，回身一剑把厉屠连同栈道压穿三层崖台。节奏紧，不停攻，不摆姿势。本段落在沈砚落到最下一层崖台、剑尖未收的一刻。

【全局影像与风格】
三维国漫写实CG质感，材质真实：木头有纹理和裂口，岩石断面粗粝，布料有重量。冷灰青的山体与雾，天光从画面左上方来。沈砚的剑光是青白色，厉屠的剑气是暗红色，两种颜色全段不换。焦段分工：对打用中等焦段、镜头在侧面五六步外，两人全身在画内；最后一击用广角仰拍和超远景。摄影机平稳、慢而流畅，只跟随和小幅调整构图；只在最后一击命中的一瞬有一次短促的震动。浅雾，不遮挡人物腰部以上。

【人物与场景锁定】
沈砚：@图片1，长相、发型、服装以参考图为准。体型修长，比厉屠矮半头。右手持一柄三尺长的直身细剑；身侧悬着两柄巴掌长的青色小飞剑，由左手并指指挥。青白剑光只从剑身和飞剑上发出。
厉屠：@图片2，长相、发型、服装以参考图为准。肩背宽厚，比沈砚高半头。双手持一柄一人高的宽刃重剑，暗红剑气只从重剑刃口发出。重剑挥出后改向慢，回收慢。
场景：@图片3，只参考山体与栈道的样子。一面近乎垂直的灰色崖壁，崖壁在画面右侧。一条两人宽的木栈道贴着崖壁向前延伸，栈道外沿是木栏杆，栏杆外是深谷和雾。栈道正下方每隔一层楼高有一层凸出的石质崖台，共三层。栈道由一根根斜插进崖壁的粗木梁撑着。
站位：沈砚在栈道上，面朝前方，后背离外沿栏杆三步；厉屠在他正前方十步，面朝他，后背方向是栈道深处。两人的连线沿栈道走向，与崖壁平行。这一段的移动先是沈砚被逼向外沿，再是垂直向下。栈道上没有第三个人；两人都不贴到崖壁上。结束时沈砚在最下一层崖台上，厉屠在他脚前的碎石里。

【镜头与表演原则】
冷静旁观的拍法：宽景为主，把出手、接触和结果放在同一镜里看清。每次交手都有可见的接触点和受力方向。厉屠是活的对手，会追、会压、会反击。沈砚脸上是专注，不夸张；厉屠是压迫，不嘶吼。人物为正常人眼，不发光。无台词。

【分镜】
镜头1（0-3秒）｜对冲，第一段栈木断
全景，机位在栈道外侧的半空，与栈道平行，平视。两人同时蹬出：沈砚左手一引，两柄小飞剑一高一低先射向厉屠；厉屠重剑横扫，暗红刃口把两柄飞剑磕向崖壁，飞剑钉进石头，碎石溅落。重剑扫过的余势砍进栈道内侧的一根木梁，木梁从中间断开，厉屠脚下那一段栈板向下一沉。镜头随两人的接近缓慢前移。两人已贴到一臂距离。

镜头2（3-7秒）｜重剑下压，逼到外沿
中景，机位移到沈砚的右后方，越过他的肩看厉屠，略仰。厉屠借栈板下沉的势头双手举剑过顶，一步踏前，重剑竖直劈下；沈砚横剑硬接，细剑的剑身被压弯，他双脚在栈板上向后犁出两道木屑，后腰撞上外沿栏杆，栏杆向外折断，碎木落进雾里。暗红剑气沿刃口压到他额前一拳的位置。他左手并指向崖壁方向一勾。

镜头3（7-10秒）｜借反震跃起
中全景，机位降到栈板高度，低位侧拍，两人在画面正中。钉在崖壁里的两柄小飞剑同时拔出，从厉屠身后射向他的后颈；厉屠偏头撤半步，压在细剑上的力一松。沈砚顺着被压弯的剑身回弹，脚尖在断栏杆的残桩上一点，身体直直向上拔起两人高，衣摆向下甩。厉屠抬头，重剑还垂在身侧，来不及举起。

镜头4（10-15秒）｜一剑压穿三层
10-12秒，广角仰拍，机位在厉屠脚边贴着栈板向上看：沈砚在最高点翻身，头下脚上，双手握剑，青白剑光沿剑身拉长到一人多高，直劈下来。厉屠横起重剑去挡，两剑相接，接触点炸开一圈青白与暗红相间的气浪，画面短促一震。
12-15秒，切超远景，机位在对面山崖，整面崖壁和三层崖台都在画内，两人是画面中心的两个小点：栈道以接触点为中心向下折断，厉屠被压着穿过断裂的栈板砸在第一层崖台上，崖台从根部崩开；两人继续下坠，砸穿第二层，碎石和断木成串落进深谷；第三层崖台接住了他们，石面以落点为中心下陷开裂，尘雾向四周推开。尘雾里，沈砚单膝落地，剑尖斜指地面还没有收，厉屠在他脚前的碎石里，重剑脱手插在两步外。

【结尾与转场】
本段落在第三层崖台上：尘雾还在向外推，沈砚单膝着地、剑尖未收，头顶上方断掉的栈道还在往下掉木屑。

【声音】
全段无配乐。山风声持续；飞剑破空的尖细风声；金属相撞的短促脆响；木梁断裂的闷响；重剑压在细剑上的金属摩擦声；最后一击是一声沉重的撞击，随后是三次间隔越来越短的岩石崩裂声和远去的落石回声。

【保护项】
不要字幕，不要背景音乐。沈砚的剑光始终青白、只在剑上；厉屠的剑气始终暗红、只在重剑刃口。两柄小飞剑不变成更多。崖台正好三层，逐层砸穿。两人的身高差不变。不出现悬浮的符号界面和魔法阵。人物眼睛不发光。
```

## 这份稿子对照规则看

- **站位卡八项**都在【人物与场景锁定】里：锚点（崖壁、栈道、栏杆、三层崖台、木梁）、起点、距离、互动轴、主运动轴、高度层、禁区、终点。
- **能力合同**：谁的光什么颜色、从哪发出、重剑的代价（改向慢、回收慢）。镜头 3 的反击窗口就来自这个代价。
- **六拍**：镜头 2 的进入（踏前）、接触（重剑对细剑）、压缩（剑身压弯）、受力（双脚犁出木屑）、传播（栏杆折断）、新态（后腰抵在外沿）。
- **四问**：每镜从上一镜没做完的事开始；关键事件都在画面中心附近；每镜至少换了距离、高度、攻击权之一；没有重新起跑和对峙。
- **破坏**按材料和顺序：木梁先断，栏杆折，栈板折断，石台从根部崩。数量可数（三层）。
- **强镜头只用一次**：广角仰拍和冲击震动只在镜头 4。
