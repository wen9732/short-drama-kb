# 韩国黑色片·爆发型写法

适用：《新世界》《恶人传》一类韩国犯罪/黑色片；对峙、威胁、脏话对骂、情绪失控。
不适用：隐忍、强撑体面、细水长流的情感戏 → 用 `drama-restrained`。
执行规范统一见 `seedance25-spec`。

## 一句话原则
**光骂脏话是街头吵架；用骂脏话掩盖下不去手的爱/恨，才是韩国片。**
爆发底下必须压着另一种情绪，爆发是压不住之后的结果。

## 结构：顶点必须被推翻
1. 情绪一路推到最高点（逼对方开枪、逼对方说出口）。
2. 用一个反转把顶点推翻（空枪"咔哒"、早已知情、刀其实没刺下去）。
3. 落在一个矛盾表情上（又哭又笑），硬切黑。
观众情绪先炸开再落空，这个落差就是节奏。

## 脏话的写法
- **先压后炸**：咬牙压低的"아이씨"，半句之后再爆发。一上来满格 = 泼妇骂街。
- 常用：아이씨、씨발、개새끼야、미친놈아。全部写韩语原文，括号注中文意思。
- 写明破音位置："'개새끼야'嗓子撕裂破音，带着哭腔"。
- 最后一句脏话应是最轻的（气音、又哭又笑的"씨발……"）。
- 平台可能消音/拒绝 → 备选截断的"아 씨……"。

## 视觉三件套
- **风场**：写风向（"从画面左侧持续吹向右侧"）、风里有什么（斜飞雨丝）、吹动哪些部件（头发抽打到脸上、西装下摆、领口），以及风声贯穿全片。
- **荷兰角**：写倾斜方向和角度（15–20 度）。两人各倾向一侧 = 无法对齐；对峙结束时回正。
- **刺激构图**：前景大物件（枪身虚化占画面一角）、低机位仰拍、长焦压缩背景、手持晃动但不乱。

## 首尔/韩国辨识元素
红色霓虹十字架夜景、楼顶、帐篷酒馆（포장마차）、绿瓶烧酒、塑料门帘、暴雨。

## 情绪天花板（照样要写）
- 可以嘶吼破音，但不能舞台剧式尖叫。
- 眼泪只在指定时间段落一滴，马上被雨冲散。
- 不怕死的一方"笑里带疲惫"，不疯癫狂笑。
- 人物为正常人眼，不发光。

## 动作戏注意
- 两只手 + 一把枪同框（拽手腕顶额头）易穿模、多手 → 景别放宽。
- 不想要的枪声/火光写两次禁止；仍出现则删掉该特写，后期补音效。
- 结尾切黑可能被拖成淡出 → 后期剪，不重生成。
