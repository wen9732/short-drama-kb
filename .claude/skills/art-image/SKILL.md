# 美术层·美学图像

来源标注：【课程第N节】＝《AIGC 超创课》；【经验】＝本库；【官方】＝平台文档。课程讲的模型对比时效短，不写进规则。

## 边界
- **负责：** 美术定调（三基石、关键词、色板）；人设图、场景图、分镜图、身高对比图等**参考资产**的标准与生图提示词；单张图的构图、光、景深、质感；海报、概念图。
- **不负责：** 视频提示词（→ `exec-seedance25`，资产交给它的【参考】槽位挂载）；运镜和剪辑（→ `cam-`）；表演（→ `perf-`）；某个类型片的固定视觉包（→ `genre-`，本库给方法，`genre-` 库存成品）。
- **互斥：** 无。**常搭配：** 任一 `genre-`（借它的关键词和色板）；`cam-shot`（借静态构图与光）。

## 一句话原则
**先定调，再出图。** 美术一致性比单张图精美更重要；好底图的标准是任意一帧截出来都能当海报。【课程第4、5节】

## 一、美术定调（每个项目只做一次，全片共用）【课程第4节】
1. **三块基石，按顺序定：** ① 拍摄类型（广角扭曲、中焦人像、长焦压缩、伪纪录手持……）② 主体表现形式（写实人像、3D 风格化、二次元、半厚涂、混合材质……，定调的第一刀）③ 色彩范围（高饱和霓虹、低饱和电影感、单色加一抹强调色、冷暖对比……）。
2. **关键词定调：** 把"好看"翻译成 **5–10 个具体关键词**，按人物（服装、剪裁、面料）、场景（环境、建筑、自然元素）、道具（形状、线条、质感、年代）、氛围（光影、色调、情绪）四类写。错："赛博朋克风"；对："霓虹·潮湿·夜雨·钢蓝·金属质感·雨痕反光"。
3. **色板：** 主色、辅助色、强调色各几个。**色板锁死之前不出第一张正式图。**
4. **统一测试：** 同一组关键词分别出人物、场景、道具，看是否像同一个世界；不像就改关键词，不改单张图。
5. 同一世界观不混搭完全不同的美术风格（剧情需要除外）；核心风格定了不轻易改，关键词可以补。
6. 定调结果压成 ≤150 字，就是视频提示词【影像】段的底稿（`exec-seedance25` 规定全项目共用一份）。

## 二、三种生图方式，各干各的事【课程第5节】
| 方式 | 擅长 | 短板 | 用在 |
|---|---|---|---|
| 文生图 | 人、环境、光自然统一；会给意外创意；跨界融合 | 难复现同一角色；语义污染（A 的颜色染到 B） | 前期概念（一次 10–20 张挑）；已有人设时生成匹配环境；故意组合矛盾词找新美术表达 |
| 图生图 | 可控，能指定保留和修改什么 | 依赖底图质量 | 多图融合（图1 人物＋图2 场景＋图3 光影）；**机位推演**（"切到人物背后反打他的脸"）；人设迭代；从一张外景推出连续场景 |
| 视频生图 | 成本低，自带运动信息 | 分辨率低，要再高清化 | 低分辨率视频当分镜生成器，截满意的帧当底图；验证节奏；用运动模糊指导静态底图 |

## 三、参考资产标准（给视频用的图）【课程第5节】
| 资产 | 标准 |
|---|---|
| 人设图 | **头部超特写（正脸）＋脖子以下全身图（卡掉头部）**，不用全身立绘：算力不够时模型先牺牲脸。新模型能从正脸推侧脸，不必三视图。可选表情库、动作集；不同视角下服装和身体特征统一 |
| 身高对比图 | 多人同框前先做："图1–4 的人物按 190、185、175、170cm 正面并排站立"，遮住脸只留发型（防模型参考错五官）；视频里写"严格参考图N的身高比例" |
| 场景图 | **留白**：给人物留活动空间，不画满；主场景图＋正反打视角图＋关键道具标注图（"生成该场景正面和反面视角，标注所有家具和道具位置"） |
| 分镜图 | 分镜即剪辑，底图即镜头；每张写清构图、景别、视角、光影；连续几张色调光影成序列；动静交替，不连续同景别 |
| 刷过光的人设图 | 人设图直接进新环境会有贴图感：同时挂人设图和环境图，"图1 构图不变，按图2 的环境光改图1 人物的光线、色温、色相，保持白底"，刷完再进视频 |

**导演台构图：** 人物位置和透视总不准时，先在导演台（或草图）摆人物、道具、机位出一张构图参考，再"按图2 的构图，在图1 的场景里生成对应人物"。【课程第5节】

## 四、单张图怎么拍（静态镜头语言与防翻车铁律）【课程第1、5、6节；经验】
- **一个画面只有一个主体**；多主体用景别、光、景深排出主次。
- **景别与细节匹配（不越界写细节）：** 远景/大远景严禁描写瞳孔、睫毛、皮肤毛孔、戒指花纹等微观细节（一旦写微观词，生图模型会强行把远景拉成近景或让头身比崩坏）；只有特写/大特写才展开毛孔、虹膜纹理与微表情。
- **远景/全身景深防放大铁律：** 远景、全景需要看清环境或人物全身时，**必须删掉"浅景深、背景虚化、大光圈散景"**，改写"深焦，前后景均清晰对焦"；保留浅景深词会导致模型为了制造虚化而强行把人物放大成半身像。要"人物清楚、背景化成光斑"时，必须同时写**长焦＋人物近景＋大光圈**。
- **喜剧/夸张表情防漫画化铁律：** 画惊恐、暴怒、滑稽等夸张表情但仍要写实电影质感时，必须声明**"演员面部表演夸张，但摄影机光学克制、胶片写实光影，非卡通、非漫画夸张变形"**，防止模型因情绪词直接跳进二次元/美漫夸张画风。
- **多人同框防粘连与左到右排位法：** 3 人以上群像必须按**"从左到右依次为：……"**逐一指定画面横向位置，并写明**"人物之间前后错落站位、留出呼吸间隙，不并排贴脸粘连"**。
- **构图：** 三分法、居中对称（仪式感）、框中框、引导线、对角线（动感）、边缘留白；前景（虚化物件、过肩）、中景（主体）、远景（交代在哪）都参与叙事。
- **构图雷区：** 画面边缘切在关节上；背景物体从头顶长出来；背景比主体抢眼。
- **动机光：** 每一束光都要有来源（窗、灯、屏幕、火）；观众先看最亮处；冷蓝孤独、暖橙怀旧、惨白审讯、绿色不安；顶光压抑，底光邪恶，逆光剪影。
- 焦段、机位、光的完整配方见 `cam-shot`，本库只取静态部分。

## 五、生图提示词写法与分模型隔离【课程第5、6节；经验】
1. **图片线路与视频线路彻底隔离：** 生图提示词必须详写五官、服装剪裁、面料纹理、色板与胶片颗粒；而视频提示词（`exec-seedance25`）靠 `@图1` 锁外观，严禁把生图里的五官服装长句照搬进视频分镜。
2. **第一句权重最高：** 风格和媒介写第一句（"王家卫风格电影画面，一个女孩在咖啡厅"），不要放句尾；补充放最后。
3. **三类模型否定词隔离（勿混用）：**
   - **GPT-Image-2（2026）：** 走五模块自然语言（主体与动作→场景→光线与色板→镜头与画幅→胶片质感），**支持且推荐在末尾加 `Avoid:` 段**排除塑料皮肤、HDR 锐化等具体伪影。
   - **GPT-4o / Nano Banana 2：** 主提示词里**严禁写"不要 X / NOT"**（易反向激活 X），一律改成正向物理事实（"不要网红脸"→"真实皮肤纹理，自然不对称的五官"）或对比句（"像胶片电影剧照，而不是手机 HDR 照片"）。
   - **即梦 Image 2.0 / Midjourney：** 走逗号标签流，负面词放进独立负面栏或末尾 `NOT` 段。
4. **不写空词：** "好看、高级、大片感"要翻译成光、色、材质、景深、构图的具体事实。
5. **画幅：** 宽幅（21:9 / 16:9）、竖幅（9:16）比方图更容易出电影感。
6. **参考手册：**
   - 资产模板（影调前后缀、Nano Banana 2 高清重绘、1/3正脸+2/3无头三视图人设、UE5 Lumen 刷光、机位推演、身高图）：`references/生图提示词手册.md`
   - 八大电影流派速查（色板/颗粒/高光/暗部）＋分模型完整模板：`references/电影感生图流派与分模型模板.md`

## 六、讲师技巧（按需）【课程第5节】
- **九宫格＋高清化：** 大图出现头发、皮肤瑕疵时，出 3×3 九宫格（小图没瑕疵），裁单张，再高清化（细节生成程度调低，避免改原图）。
- **低清先行：** 480P 视频先验证分镜节奏，满意再高清化；截出光影割裂的帧，用图生图"调整人物光线，所有光源来自环境"修。
