# 生图提示词手册（模板，按需读）


## 1. 影调前缀与后缀（GPT 生图出"电影剧照感"）【课程第6节】
- **前缀**（放在主体描述前面）：电影摄影质感，胶片柔光，克制细节，大色块构图，材质统一，自然光主导，浅景深，胶片化学调色，模拟质感而非数码锐利。
- **后缀**（放在最末尾）：柔焦边缘，克制的细节表达，大色块优先，材质统一干净，整体通透，参考电影摄影质感：自然胶片颗粒，像一张精心打光的电影剧照，而不是高清数码照片。

## 2. 负面词改成正向目标【课程第6节】
| 别这样写 | 改成 |
|---|---|
| 不要过度锐化 | 柔和的边缘过渡，胶片柔光 |
| 不要堆砌细节 | 克制的细节，大色块优先 |
| 不要网红脸 | 真实皮肤纹理，自然不对称的五官 |
| 不要塑料感 | 哑光材质，皮肤有毛孔和细微油光 |
| 不要贴图感 | 人物受环境光照射，色温与背景一致，脚下有接触阴影 |

## 3. 画面重置与高清重绘（保留构图色调，只优化质感）
- **通用画面重置【课程第6节】：**
  > 请完整保留这张图的人物、构图、场景、色调、主体动作与信息，不改变人物身份、五官、姿态与镜头。仅优化画面质感：边缘更柔和，消除数码锐利感；细节克制，不堆砌碎纹理；材质统一干净，哑光感；高光自然晕染，胶片柔光；整体更通透。参考：精心打光的电影剧照，而不是高清数码照片。
- **Nano Banana 2 专用图生图高清重绘【经验】：**
  > 高清重绘，丰富细节，真实光影质感，4k超清画质，保留原图构图与主体结构。
- **防人物五官漂移补丁（有人脸时追加在上面那句后）：**
  > 保持面部五官与原图一致，仅增强皮肤纹理、发丝细节与服装材质光泽。

## 4. 参考资产模板【课程第5节；经验】
- **人设图·两张拆分法（实拍推荐）：** "【风格第一句】。人物正脸头部超特写，五官清晰，自然光，纯白背景。" ＋ "同一人物脖子以下全身，画面上缘卡在下巴以下，正面站立，完整服装，纯白背景。"
- **人设图·单张1/3头部＋2/3无头全身三视图法（CG/画布项目推荐，防全身图脸崩）：**
  > 生成高概念电影的人物设定图，严格按照我的布局描述绘制：画面左边 1/3 为该人物的面部正面特写（高分辨率五官、皮肤毛孔、瞳孔高光与发丝细节）；右边 2/3 为该人物无头部的全身三视图（正面、侧面、背面），脖子往上不显示，重点展示服装剪裁、甲片层次、腰封挂件与靴底结构，纯色中性灰背景，均匀柔光漫反射，无剧烈投影。
- **身高对比图：** "图1、图2、图3、图4 的人物按 190cm、185cm、175cm、170cm 从左到右正面并排站立，脚底在同一水平线上，脸部用纯色遮挡，只保留发型和服装，纯白背景。"
- **刷环境光（白底）：** "图1 构图不变，根据图2 的环境光改变图1 人物的光线、色温和色相，保持白底。"
- **刷环境光·角色融入场景（UE5 Lumen 级光线匹配）：**
  > 将图1中的角色自然融入图2的场景中，根据场景的环境光源方向调整角色身上的受光面、背光面和边缘光，统一角色与环境的色温、色调和空气透视感，在角色脚下生成自然的接触阴影与地面反光，达到电影级合成效果，虚幻引擎5渲染，Lumen全局光照，光线追踪反射，极致的细节刻画。
- **场景正反打：** "根据参考图生成该场景的正面和反面视角，两张图光线、陈设一致，标注所有家具和道具的位置。"
- **机位推演：** "保持图1 的场景与光影风格，把镜头切换到人物背后，反打他的脸。"
- **导演台构图：** "按图2 的构图与人物站位，在图1 的场景中生成对应人物，透视与图2 一致。"
- **修光影割裂：** "保持构图和人物不变，调整人物光线，所有光源来自环境。"

## 5. 九宫格叙事【课程第5节】
"把这场戏拆成 3×3 九宫格分镜，九格依次为：……（每格写景别、视角、动作）。九格色调、光影、人物服装一致。" 出图后裁成单张，再逐张高清化。

## 6. 三类生图模型的否定词隔离表（铁律，勿混用）
| 模型类型 | 正向结构 | 否定词（Negative）写法 |
|---|---|---|
| **GPT-Image-2（2026）** | 五模块自然语言：主体与动作 → 场景与空间 → 光线与色调 → 镜头与画幅 → 质感收尾 | **支持且推荐句尾 `Avoid:` 段**，点名排除 3–5 个具体伪影（如 `Avoid: plastic skin, oversaturated neon, HDR halo`） |
| **GPT-4o / Nano Banana 2** | 风格写第一句＋对比句（"像胶片电影剧照，而不是高清数码照片"） | **严禁在主提示词写"不要 X / NOT"**（易触发反向激活），一律改写为正向物理属性 |
| **即梦 Image 2.0 / Midjourney** | 逗号分隔标签流：`[景别+视角], [主体+服装材质], [场景+光影], [胶片型号+渲染词]` | 负面词放入独立负面栏，或在末尾追加 `NOT xxx` 短语段 |
