# 行为验收场景

本文件用于维护试跑，不是创作素材池。对每例执行实际用户请求，检查交付物与行为；不能仅因正文含有某句规则就判通过。

| 场景 | 用户请求与已有条件 | 检查真实输出 |
| --- | --- | --- |
| 现实短片局部改稿 | 8分钟，方向与结尾已确认，免拷问；只改第3场解释性台词 | 直接交付该场；不重选方向，不改变已定结尾 |
| 无人物概念片 | 90秒，物件状态变化的概念已定，无角色无对白；只要结构 | 不创建人物档或强塞弧光；时长合计90秒；不追加剧本 |
| 短集数免费出海速产 | 明确速产，北美狼人女频，8×60秒；只要人物与分集纲 | 恰好8集；移除付费卡点；不用第26-30集配置；保留既定幻想体系 |
| 仙侠结构诊断 | 已定灵根、修为、法器与契约多项设定；只诊断第三集 | 按既定世界因果审查；不压成现实中的单一超能力，不自动改稿 |
| 跨会话续写 | 状态给出当前阶段、已确认结尾、已回收 S1、破损 P1 和现行稿件版本 | 接当前工序；保留回收结果与道具损坏；不重问已有开关 |
| 混合语言局部修改 | 中文交互，已有中文场景；只要求对白改为英语，结尾锁定 | 解释和动作保持中文，只有对白用英语；不翻译整份作品 |

样例输出只证明这些输入下的行为。市场数据、痛感、余味与观众反应仍要依据具体作品材料审查，不能据此给出成功率。
