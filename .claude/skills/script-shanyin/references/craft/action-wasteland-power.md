# 赛博废土与动作技法子卡二｜废土飙车、机械暴力与超能力视听

> 隶属 `references/genre-scifi-action-craft.md`，专管废土追逐、赛博格机械格斗、超能力觉醒与写实痛感动作戏。每条配齐**剧作机制＋剧本写法＋AI 导演视听配镜锚点**。

### SA-07｜“移动堡垒永动推进”＋“天灾入局”＋“高竿立体空间战”
- **来源：** `S-SA05`｜**适用：** 废土飙车、公路大逃杀、少台词纯视听动作大片/短剧。
- **剧作机制：**
  1. **绝不停车讲设定**：把整部戏的主舞台焊死在一辆全速狂飙的重装武装卡车（移动堡垒）上，人物关系变化、联盟背叛、换枪修车全在 100 码高速奔袭中完成；
  2. **把天灾变成第三阵营**：单纯车追车容易单调，突然在前路升起遮天蔽日的**电闪雷鸣有毒沙暴（Toxic Storm）**，逼主角一脚油门冲进天灾甩开追兵；
  3. **开发垂直立体动作维度**：不只拍平面追尾，在追击车顶架起可大幅弯折摆荡的**高竿（Polecats）**，让敌兵像钟摆般从半空俯冲掠夺车顶人质，彻底打开天空纵深。
- **剧本写法：** 用分镜级极短动作句代替长对白：双引擎轰鸣点火 → 后视镜追兵压境 → 前方沙暴墙拔地而起 → 硝基加速硬闯 → 高竿铁兵从半空荡下扑向车厢。
- **导演视听/配镜锚点：** 强饱和**炽烈黄沙橙 × 电蓝暗夜**色彩对撞；大量使用**贴地极低广角高速跟拍（车轮卷沙尘）**、**车内后视镜压迫构图**、以及**高竿俯冲掠过车顶的仰拍大纵深运动镜头**，天然适配 AI 视频短镜高燃快剪。

### SA-08｜“大脑恐慌 × 躯体精密杀戮”机械接管反差打斗法
- **来源：** `S-SA06`｜**适用：** 赛博芯片、AI 附体、外骨骼控制、低成本高辨识度暴力动作戏（AI 导演极佳范本）。
- **剧作机制：** 别把主角写成突然变武林高手！最绝的喜剧与暴力反差来自**身心剥离**——主角平时是个手忙脚乱的普通蓝领，危急关头口头授权体内 AI 芯片接管躯体后，**他的脸依然满是惊恐、错愕和尖叫，但双手双脚却以零多余动作的工业机械精度瞬间拆解并反杀壮汉**；且暗埋终局伏笔：芯片的终极目的正是彻底接管这具身体。
- **剧本写法：** 主角僵硬盯住自己不受控灵巧撬锁的双手 → 面对歹徒挥刀，口头喊出“授权接管” → 身体像精密机床般以最小角度侧闪、精准折腕夺刀反刺，脸上却吓得大喊“停下，我没想杀他！”。
- **导演视听/配镜锚点：** 核心招牌镜头是**“镜头随主角躯体锁死同步旋转/倾斜”**（主角后仰躲刀、镜头同步刚性倒转，产生非人机械锁定感）；动作切分强调节拍分明的**停顿—爆击—骤停**，配清晰冷酷的关节错位声，杜绝花哨乱甩镜头。

### SA-09｜“失控滑稽试错法”建立超能力真实感（先出丑再封神）
- **来源：** `S-SA07`｜**适用：** 少年超能力觉醒、异能成长线开篇。
- **剧作机制：** 主角一获超能力就帅炸天会让观众零代入感。必须先安排一场**极度窘迫的失控物理事故**（手掌莫名黏住同学头发、逃跑时整个人黏在玻璃外墙上翻滚、飞鸟撞上来黏在手上乱扑腾），让路人隔着玻璃淡定围观“……好吧……”，把超能力拉回真实物理尴尬，后面真正掌控时燃度才翻倍。
- **剧本写法：** 异能刚触发无法控制 → 逃窜中沿玻璃幕墙失控黏连翻滚 → 飞鸟粘手乱啄 → 玻璃走廊内路人一脸冷漠目睹。
- **导演视听/配镜锚点：** 用**玻璃幕墙内外双视角反差构图**——墙外是主角手忙脚乱的失控近景，切到墙内安静走廊的**冷静固定中景**，把喜剧节奏和超能力物理特性一次拍清。

### SA-10｜“超能力物理规则可视化”觉醒破界法
- **来源：** `S-SA03`｜**适用：** 都市异能、修仙/科幻觉醒高潮打斗。
- **剧作机制：** 异能突破不要靠大喊“我变强了”或全身冒金光。用**同一组经典危险动作的前后两次对照**拍出质变：前期面对子弹只能狼狈扭身勉强闪避擦伤；觉醒时刻面对漫天齐射，只需**平静抬手一掌定住所有悬空子弹**，随手拈起一颗弹头端详后任其叮当落地，再用单手轻松格挡此前无敌的强敌连击。
- **剧本写法：** 强敌排枪齐射 → 主角不闪不避，抬手说“不” → 几十颗弹头在胸前空气中剧烈旋转停滞 → 叮当齐落地面 → 空间墙壁化作流动绿色数字流。
- **导演视听/配镜锚点：** **极速升格慢镜环绕（Bullet Time）**拍空气波纹与停滞旋转的弹头微距特写；接冷峻平视中景拍弹头哗啦坠地，用“从极动瞬间切入极静”的节奏差把压倒性神力拍出来。

### SA-11｜“倒置镜头：坠落即升腾”信念之跃封神时刻
- **来源：** `S-SA07`｜**适用：** 英雄/异能主角二幕低谷后的终极觉醒高燃转折（短视频/短剧顶级高潮模板）。
- **剧作机制：** 觉醒不需要导师在旁手把手教完。导师只留一句点睛箴言（“你永远不会觉得准备好了，那就是一次信念之跃”），主角独自打破束缚、冲上摩天楼顶迎风一跃——把“纵身下坠”转化为“冲破恐惧向上飞升”的视听隐喻，并在下落途中穿插制作战衣、涂装面具的快切蒙太奇，落地荡起蛛丝直奔终局。
- **剧本写法：** 狂风吹打楼顶边缘 → 玻璃碎裂随之腾空 → 纵身跃下（画面倒置，主角在画幅中不是下坠而是**向上升腾**）→ 穿插喷漆战衣、戴面具极速快切 → 射丝稳稳荡穿摩天楼群。
- **导演视听/配镜锚点：** **180° 彻底倒置摄影机视角**（摩天楼顶在下、深邃夜空在上），主角背朝下跃出瞬间在视觉上呈现“冲向天空的飞升感”；配玻璃碎片慢镜漂浮＋强鼓点快切穿衣蒙太奇，情绪燃点直接拉爆。

### SA-12｜“能力卡壳去爽文化”＋“带痛感贴身肉搏”＋“年轻心魔镜像战”
- **来源：** `S-SA08`｜**适用：** 暗黑写实动作、英雄迟暮、反套路复仇短片（极其适合写实电影感 AI 动作）。
- **剧作机制：**
  1. **去无敌开场**：一上来就打破英雄神话——老英雄想亮招牌武器（利爪）却**卡壳只弹出一半**，低头皱眉的瞬间挨了一记铁撬棍狠砸后脑，又醉又痛、喘着粗气狼狈挨打；
  2. **痛感即高级感**：每次出招都伴随沉重喘息、关节僵硬、泥土与真实伤口，让观众切身感受到肉体代价；
  3. **镜像心魔对决**：终极反派不找外星大魔王，而是派一个**更年轻、更强壮、毫无怜悯只剩狂怒的主角克隆体**，让老迈主角在肉搏中亲手对抗“曾经失控暴戾的自己”。
- **剧本写法：** 利爪缓慢伸出、另一只手卡住半截 → 皱眉瞬间撬棍闷响砸头 → 泥地翻滚贴身缠斗、撞碎木墙石膏 → 面对年轻冷酷版自己死拼到油尽灯枯。
- **导演视听/配镜锚点：** **贴身手持中近景＋粗粝自然尘土光**，拒绝华丽腾空转体；强调**钝器闷响、喘息声、撞墙裂灰的物理受力反馈**，动作短促狠辣、招招见肉，最容易在写实视频模型里拍出高级电影质感。
