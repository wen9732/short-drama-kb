# 惊悚恐怖技法子卡一｜单场视听吓点与空间压迫

> 隶属 `references/genre-horror-craft.md`，专管阶段 2（音叉场景）与阶段 4（单场恐怖戏写作）。每条配齐**剧作机制＋剧本写法＋AI 导演视听配镜锚点**，严禁洗成无画面感的流水线文字。

---

### HT-01｜间歇遮挡滴灌法（遮蔽 70% 信息）
- **来源：** `S-H01`｜**适用：** 远程目击惨案、门缝窥视、空间外围突发危机。
- **剧作机制：** 用周期性摆动的物理遮挡物把暴力/异常切成碎片，每次闪开只露一格升级恶果，中间过程交给脑补。
- **剧本写法：** 四拍短句：`遮挡掀开（异常）→ 合拢 → 远方尖叫 → 再掀开（满墙血迹/黑影退回）→ 合拢 → 主角亲手拉开时漆黑如常`。
- **导演视听/配镜锚点：** 锁定**单一固定观察机位**（窗框/门框作天然画中画），借风帘/频闪路灯作物理黑场切点；最后主角亲手拉开切冷静平视构图，用“一无所有”锁死信息差。

### HT-02｜日常高频声 × 致命危机“双线交叉剪辑”（声场掩盖法）
- **来源：** `S-H01`、`S-H06`｜**适用：** 居家独处戏、无台词高张力段落、前 15–30 秒硬控。
- **剧作机制：** 把主角视线内的高频小风险（A 线）与无人空间逼近爆炸的危机（B 线）交叉互切；在临界点用合理日常噪音源盖住 B 线警报声。
- **剧本写法：** A 线高频逼近险境 → B 线无人自启升温 → A 线小意外（扎破手）→ 主角开水龙头冲水制造大噪音，刚好吞掉 B 线爆裂警报 → 关水瞬间 B 线轰然引爆。
- **导演视听/配镜锚点：** A 线**极近微距特写**盯接触点，B 线**冷峻固定特写**拍无人自转旋钮/鼓胀容器；随倒计时缩短两线互切时长，以水流特写声盖过爆裂声做声画错位切点。

### HT-03｜视觉递减剥夺 → 听觉接管追魂（三拍衰减公式）
- **来源：** `S-H01`、`S-H02`｜**适用：** 夜间楼梯、地下室、长走廊逃生。
- **剧作机制：** 光源按固定节律衰减，第三拍彻底剥夺视觉并瞬间切入高频递增听觉追逼，最后在安全门前插一把日常小障碍（丢钥匙/门反锁）制造二次绝望。
- **剧本写法：** 短句控呼吸：`一步·灯暗·拍打·灯亮` ×2 → 第 3 拍彻底全黑 → 死寂 2 秒 → 贴耳低语 → 脚步声倍速叠加（`咚→咚咚→咚咚咚咚`）→ 抵门摸空口袋狂砸门。
- **导演视听/配镜锚点：** **狭长纵深＋局部点光源**，四周沉入纯黑；熄灭后仅留微弱轮廓或暗处两道微光，灯骤亮走廊空无一人，随即接屋内器物碎响做二次惊吓。

### HT-04｜“高能假吓 → 松懈瞬间静物微位移 / 离场移焦”双拍错位法
- **来源：** `S-H01`、`S-H02`、`S-H03`｜**适用：** 破除 Jump Scare 疲劳、建立非人窥视感。
- **剧作机制：** 先用合理假惊吓把神经拉满再泄气，趁主角卸防 1–2 秒内在背景给出零音效静物位移；或借人物离场后的移焦暗示邪物全程在场。
- **剧本写法：** 假吓揭晓为虚惊 → 主角低头松口气 → 背景静物已无声坐起/转头；或角色说完秘密转身出屋，留空 1 秒露出阴影深处的媒介物。
- **导演视听/配镜锚点：** 写清**前后景景深**：第二拍切**静止中景＋零配乐留白**让背景异物清晰可辨（主角不知、观众毛骨悚然）；离场戏明确标注**移焦（Rack Focus）**，前景出画瞬间焦点平滑切向后景暗处媒介物。

### HT-09｜密闭逃生“循环回返”＋纵深暗区骤近压迫法
- **来源：** `S-H02`｜**适用：** 电梯、楼梯间、地下室、长廊等密闭困局（AI 极好拍）。
- **剧作机制：** 逃生机械运行完一遍开门却把主角原封不动送回危险起点，随即在深廊暗区让威胁以反物理速度骤近。
- **剧本写法：** 冲进电梯狂按高层 → 门合、楼层灯闪烁停顿 → 门滑开仍是漆黑地下室（再关再开，危险物离门更近）→ 弃梯冲楼梯，深廊黑影静止一秒后猛然贴面扑近。
- **导演视听/配镜锚点：** 电梯内用**密闭正面/过肩中近景**，以电梯门开合作“翻页揭示器”；深廊强调**单点透视＋顶灯逐盏熄灭**，先让黑影稳立极远小点给 1–2 秒确认感，再突进贴脸。

### HT-10｜“局部静止遮挡 → 呼唤无应 → 迈步揭全貌”三拍惨状揭示
- **来源：** `S-H03`｜**适用：** 发现宠物/同伴惨死、恐怖异象初次实锤。
- **剧作机制：** 不直接把血腥全貌甩脸上；先用低矮前景遮挡物只露出**一小截毫无异常的局部**，让角色用轻松日常语气呼唤试探，直到跨过最后一道遮挡才暴露死状。
- **剧本写法：** 灌木/桌角后只露出一截静止的宠物尾巴或垂落的手 → 角色走近、拍手轻唤日常词（“开饭了/起床了”）→ 毫无回应 → 走下最后一级台阶，脸色骤白，露出被铁链绞死的僵硬全貌。
- **导演视听/配镜锚点：** **前景遮挡缓推/跟拍**，先用明亮平和的晨光/日景与轻松拍手声建立安全错觉；角色越过遮挡物停步时先切**角色嘴唇发抖的反应特写**，再切一秒冷峻全貌惨状，借尖叫声硬切黑场/转场。

### HT-11｜“全屋时间同步凝固 ＋ 唯物排查归零后当面反击”
- **来源：** `S-H03`｜**适用：** 鬼屋/灵异规则确立、击穿理性角色防线。
- **剧作机制：** 用一个**完全无法用巧合解释的物理同步异常**（全屋所有挂钟同时停在凌晨同一分钟）立住超自然存在；再让最理性的角色持械逐寸搜查无窗密闭地下室并宣布“空无一人”，紧接着在其转身瞬间当面猛烈摔门打脸。
- **剧本写法：** 客厅与走廊时钟同停于诡异时刻 → 理性者持枪搜查无窗地下室，踹翻纸箱、翻遍柜后确认无出口无外人 → 众人松气转身欲关门 → 房门在众人面前**轰然自行砸关**。
- **导演视听/配镜锚点：** 排查段用**慢节奏手电/弱黄光主观推进**，扳机指泛白拉满紧张却故意给空结果；摔门一击用**全员入画的冷静中景固定机位**直接拍门在人脸前猛砸，不靠剪辑作弊，震撼感成倍放大。

### HT-12｜“事后精密惨案现场”留白式暴戾法（不拍行凶拍结果）
- **来源：** `S-H05`｜**适用：** 犯罪惊悚、仪式连环案、规避过审/AI 血腥崩坏。
- **剧作机制：** 真正的残忍不在于拍挥刀过程，而在于**只拍事后如艺术品般精密病态的现场残留**＋法医/老刑警极度克制的低声复盘，让观众自己在脑海里重演受害者生前遭受的折磨。
- **剧本写法：** 阴雨连绵、霉暗房间、满地细节证物（奇异道具、墙后隐藏血字、被强迫留下的诡异姿态）→ 跳过行凶，只借检查物品与低声对话拼出受害者生前漫长痛苦。
- **导演视听/配镜锚点：** **低饱和湿冷雨夜影调＋强手电光束扫过昏暗脏污细节**（反光墙纸、散落证物、滴水声）；人物面部常半隐于阴影中，镜头如冷漠尸检般缓慢扫过现场，严禁廉价惊悚配乐。

### HT-13｜“极噪暴力 → 极静空城苏醒”极端声画反差 ＋ “一滴液体的微距毁灭”
- **来源：** `S-H07`｜**适用：** 末日/生化开场建奇观、绝境中突发不可逆悲剧（极适合 AI 拍大空镜与微距）。
- **剧作机制：**
  1. **声画极差开场**：开篇用极高噪音的暴力监控墙/失控实验室引爆危机，下一秒直切**连鸟叫都没有的纯静音空城**，让主角穿病号服独自穿行地标街道，用绝对的“空”取代丧尸堆砌制造寒意；
  2. **微距宿命一击**：历经九死一生刚以为安全时，不必派怪兽大军，只需一处极微小的物理偶然（仰头看树上腐尸，**一滴黑血精准滴进眼睛**），20 秒内把至亲变成失控怪物。
- **导演视听/配镜锚点：** 空城段大胆给**烈日暴晒下的超广角大远景**（主角渺小孤立于空荡地标与废弃车辆间，只留脚步与塑料袋沙沙声）；“滴血毁灭”用**仰拍微距慢镜**死锁那滴坠落的黑血入眼，随后瞬间切剧烈抽搐与撕裂嘶吼，悲剧冲击力远超千军万马。

### HT-20｜“生理脆弱安全区破防法”（洗头后脑鬼手 / 被窝隆起拖人）
- **来源：** `S-H08`｜**适用：** 日式居家心理恐怖、打破观众日常安全感（极强心理残留后劲）。
- **剧作机制：** 相比废墟与地下室，人类防备心最低的两个日常瞬间是**闭眼洗头起泡**与**躲进棉被拉到下巴**。在这两处绝对私密安全区直接发动“贴身零距离接触”，能制造最刺骨的生理级恐慌。
- **剧本写法：**
  1. **洗头破防**：镜面蒙雾→低头揉搓洗发水起泡→一只苍白的手深埋在长发底下按住后脑→手指触碰的刹那尖叫回头，浴室空无一人；
  2. **被窝破防**：主角逃回床上把被子拉到下巴以为脱险→手探枕下摸出先前丢在险地的随身物→床尾被面骤然鼓起硕大隆起，顺着身体缓缓上爬→掀开被角一闪贴脸现身，将主角猛拖入被窝。
- **导演视听/配镜锚点：** 洗头戏必须走**正后方近景固定机位**（先让观众清晰看见白手藏在发丝间，延迟 2 秒再让主角指尖碰到）；被窝戏用**侧面低平视中景**拍鼓包沿躯干缓慢蠕动，被角掀开只给**半秒高对比度惨白贴脸闪现**，随即硬切黑场，不给完整看清的机会。

### HT-21｜“电梯逐层贴近”＋“监控黑屏双目锁定跟随”（击穿屏幕安全墙）
- **来源：** `S-H08`｜**适用：** 现代都市写字楼/公寓灵异、监控视角惊悚、打破“隔着玻璃/屏幕很安全”的心理预期。
- **剧作机制：**
  1. **逐层递增逼近**：主角逃进电梯闭目喘息，每升一层，电梯门小窗外都站着同一个苍白身影，且**每过一层就离玻璃更近一步**，最后几乎贴面——可抵达目标楼层开门却突然消失；
  2. **录像破壁锁定**：借监控回放制造安全距离（看保安排查完走廊空走、松口气），随即画面爆雪花、黑影自行步出、浓黑从屏幕底端翻涌吞满整块电视，黑暗中**一双眼睛睁开死盯观影者，哪怕观影者起身换位，屏幕里的视线依然精准跟随锁定**。
- **导演视听/配镜锚点：** 电梯戏用**轿厢内斜侧双焦构图**（前景是闭眼喘气的主角，后景是小窗外随楼层亮灭逐帧放大的苍白身影）；监控戏先走**低清颗粒感屏摄画中画**，待浓黑吞屏后切**角色走位 ↔ 屏幕双目微转持续对视**的正反打，击穿第四面墙。

### HT-22｜“标志性听觉符号先行”＋“非人关节顿挫与恐怖谷反差”
- **来源：** `S-H08`｜**适用：** 打造高辨识度恶灵/怪物 IP、规避廉价张牙舞爪怪兽演法。
- **剧作机制：**
  1. **听觉条件反射**：给威胁绑定一种极易识别的独特非人怪声（断颈喉咙咯咯声、吊尸撞墙咚咚声），全片反复**未见其人先闻其声**，甚至通过电话听筒/失真耳机传出；
  2. **非人物理仪态＋恐怖谷**：拒绝让幽灵像活人一样走路——写死**提线木偶般关节咯吱顿挫挪步**、**裹塑料膜断颈歪头如巨虫般爬下楼梯**，再配一处生理恐怖谷反差（男童大张嘴发出凶戾猫叫、熟悉同事抬头露出缺失的下颌与垂挂断舌）。
- **导演视听/配镜锚点：** 爬楼梯戏用**楼梯底端仰拍长镜**拍扭曲肢体与塑料膜摩擦反光，配高频咯咯声与骨裂脆响；“男童猫叫”必须走**窗外向内透视机位**（前景主角皱眉望向院外寻猫，后景肩后阴影里男童圆睁双眼大张着嘴发出猫嚎），错位构图毛骨悚然。
