## 三、后续新剧本入库永久标注规范（SOP）

后续只要你投喂新剧本或喊口令 **`拆解电影剧本` / `入库电影剧本`**，一律严格按以下 5 条标准执行：
1. **先查上表防重**：核对片名、年份、编剧与稿件版本；若已存在同版本则直接提醒并调用，若为新片或关键异本则启动拆解。
2. **全本零跳读通读**：必须从第 1 页读到最后一页，所有名场面、镜头指令与伏笔必须标注精确页码（`p.xx`）或行号（`L.xxx`），绝不凭印象瞎编；若读到的是早期原稿与公映成片有差异，必须实事求是单列「原稿 vs 成片版本演化对照」。
3. **零省略、禁压缩**：除非你明确下令限制字数，否则**绝不擅自压低字符数**（单部标准体量 1.2 万～3 万字符），必须完整保留原剧本的摄影机运动、景别、焦平面、第一人称 `POV` 视角切换、跨媒介/游戏机制联动、声音/静默切点与喜剧/恐怖反差细节。
4. **金标六大维度结构（对齐 `references/scripts/resident_evil_2026.md`）**：
   - ① **剧本独门核心引擎与跨媒介/类型联动**
