# 概念超短片格式指南 v2（1-3分钟）

## Reference Language Scope

本文件中的中文标题、字段名、结构型名称、固定句、Prompt 式示例和批次名只定义原有结构、顺序、业务语义、内容密度与创作规则，不定义最终输出语言。阶段性方案与周边交互默认使用主 Skill 确定的当前交互语言；最终剧本使用作品交付语言，台词和其他作品内文字遵循各自语言。本 Skill 不因本文件中的示例新增媒体生成 Prompt 或工具调用。不得因本地化改变 What-If/How-to-Tell 两条路径、结构、时长、确认、交付方式、批次数量或写作要求。

## 什么是概念超短片

1-3分钟内用一个高概念或一种讲法击中观众。武器不是故事的厚度，是**概念的锐度**或**形式的创意**。

两条路径，第一步就不同：

- **What-If 型**：一个反常识的前提 + 它的推演。武器是概念。
- **How-to-Tell 型**：用出人意料的方式重新讲一个已知的事。武器是叙事形式本身（见 narrative-arsenal.md）。

进入创作前先确认路径。

## 核心特征

- **角色**：功能性载体即可，不需要深度弧光；可以没有角色。
- **世界规则**：即插即用，前5秒观众必须理解规则或产生强烈好奇。
- **节奏**：从第一帧开始传递信息，零废镜头。
- **基调纪律**：按地基3区分现实、现实偏移和已选幻想体系。现实偏移型集中推演单一规则；已有幻想体系不强行改为现实世界，但90秒或3分钟的可用信息有限，应聚焦本片真正使用的规则与后果。

# Part A：What-If 型

## What-If 的本质

不是"假设一个奇怪的前提"，而是**用一个虚构的规则，让观众看到现实中他们视而不见的东西**。好的What-If是现实的放大镜——把某个真实存在但被忽视的机制、弱点、荒诞放大到不可忽视。

## 概念从哪来

**优先级：真素材 > 组合工具 > 凭空。** 先走反庸俗层1.5的素材驱动——从用户给的一句话、一个画面、一条新闻里长概念，这是最不容易撞车的路。

素材不足时，用组合工具碰撞（以下是**方法**，不附方向性示例——任何现成示例都已进入公共池，对照反庸俗层1.6）：

- **概念嫁接**：取A的运行机制 + B的应用场景。操作：列出A的核心规则→列出B领域里人们最在意什么→把规则塞进去→检验是否揭示了B中真实存在的问题。
- **时空错置**：把人物/技术/制度放进不属于它的时代或地点。力量在于双向照镜——理解当代的荒诞需要一面别处的镜子。
- **隐喻具象化**：取一个抽象焦虑→找到它在行为层面的最小动作→把这个动作变成强制性的物理规则。
- **反转并置**：找两个表面相似、本质矛盾的事物，放进同一场景共存，让它们互相照出荒诞。
- **规则反转**：取一条人们习以为常的现实规则，翻转它，推演后果。

**组合工具的反庸俗规则：** 工具跑出的第一批结果默认是所有AI都会想到的——它们正是反庸俗层1.2要划进禁区的东西。必须在第一批结果之上再推一层（换一个更小的切口、换一个没人选的领域、把规则再拧一圈），才有资格进入交付。

**概念检验：**
- [ ] 一句话说得清规则吗？5秒内能用画面呈现吗？
- [ ] 指向一个真实的社会情绪或人性弱点吗？
- [ ] 有推演空间吗（至少3个递进的后果切片）？有翻转潜力吗？
- [ ] 过了反庸俗层两道必答题吗（候选比较 + 生命迹象细节）？
- [ ] 3分钟讲得完吗？（太复杂→升格短片）

## What-If 的推演纪律

超短片的中段是"推演"——展示概念的2-5个后果切片。纪律：

- **递进不平铺**：每个切片比上一个更极端、更荒诞、或更日常（往日常推同样是递进——最荒诞的形态被所有人习以为常，比崩溃更狠）。
- **零解释**：不解释规则，直接展示后果。有台词在解释概念 → 删，换画面。
- **翻转是逻辑的延伸**：最后的翻转必须从概念自身的规则里长出来，不是硬转。最好的翻转让观众想回头重看一遍。

## 结构整形工具（阶段3使用，不是生成模板）

剧情创意（300-600字）成形后，用五种结构型给它找最合身的形状：

- **A 三段式**：概念呈现（15-30秒）→ 推演切片（30-90秒）→ 翻转（15-30秒）。最通用。
- **B 递进崩塌**：规则建立→一次次升级、人们一次次适应→崩溃点（崩的可以是系统，也可以是观众的认知——所有人已完全适应最荒诞的状态）→余像（废墟中的日常）。
- **C 双线并置**：两条线平行推进，观众突然意识到两线是同一件事的两面。"意识到"的瞬间即翻转，不需要角色说出来。
- **D 循环/Loop**：起点→发展→看似解决→回到起点。第二次的起点从"开始"变成"牢笼"。
- **E 倒叙揭示**：先给不可理解的结果，倒推原因，每步揭示更合理也更荒诞，最后重看第一个画面含义全变。

整形时同步标注：每段时长、双轨节奏、选用的叙事武器（如有）。

# Part B：How-to-Tell 型

## 本质

不改变"讲什么"，彻底改变"怎么讲"。前提：内容是已知或速懂的，**叙事方式本身才是卖点**。当一个已知的事被用全新方式重讲时，观众被迫从从未有过的角度重新理解它。形式即内容。

## 形式发现

从 narrative-arsenal.md（叙事武器库）中寻找与内容深度契合的武器——视角类、形式类、时间类、并置类、限制类都可作为How-to-Tell的骨架。

## 形式检验（比What-If的概念检验更严）：**
- [ ] 形式与内容是否**只能如此**？（不是"这样讲挺酷"，而是"不这样讲就丢掉核心"）——去掉形式用常规方式讲，冲击力不丧失 → 换形式。
- [ ] 形式有递进空间吗？同一手法从头用到尾不变化就会失效——手法要升级、变异、或在结尾被打破。
- [ ] 形式本身有翻转潜力吗？最好的How-to-Tell结尾，是**形式自己完成了翻转**。
- [ ] 观众15秒内能理解这个讲法吗？

## How-to-Tell 的结构

结构由形式本身决定，通用节奏：

1. **形式建立**（前20-30秒）：让观众理解"这个片子在用什么方式讲"，第一反应应该是"哦？这样讲？"
2. **形式深入**（中间60-120秒）：在形式框架内展开内容，形式本身同步递进——升级、变异、或暴露新含义。
3. **形式与内容交汇**（最后15-30秒）：观众意识到形式不是包装，它本身就是故事的一部分。

## 超短片工作流备注

按主 Skill 的任务入口进入，体量小只减少不适用的产物，不默认越过用户要求的阶段。

- 无人物或纯物件／形式概念片：人物档、Want/Need、Ghost与人物弧光记“不适用”；检查物理状态、规则后果和观众理解是否有变化。
- 用户方向与概念已定时，直接进入剧情创意、结构或正文等所请求工序；不再给三四个选题让用户重选。
- 只要结构与时长时，交付分段预算后停在结构阶段；只有用户明确要求一口气写完或已授权自主推进，才在内部整形后继续正文。
- 正文可一批写完；采用主流程批次名和约10,000字符上限，必要时在场景边界拆批。
- 替代翻转或替代讲法只在用户要求探索或现方案有具体问题时提供；不在已确认概念的局部维护任务中重新开放结尾。

**写作要求：** 极致精简，每个字都存在于画面中；台词极少甚至没有；翻转落在最后一个画面或最后一句话上；叙事方式的描述要具体到编剧层面（信息何时给、何序给），镜头执行留给导演大师。

## 概念超短片常见陷阱

- ❌ 概念需要大量解释 → 换概念或升格短片
- ❌ 组合工具的第一批结果直接交付 → 那是公共池，再推一层
- ❌ 推演切片平铺不递进 → 每片比上一片更进一步
- ❌ 翻转是硬转 → 必须是概念自身逻辑的延伸
- ❌ 偏移升级堆叠（靠不断加设定推进）→ 单一偏移，戏在现实的消化里
- ❌ 台词在解释概念 → 删掉换画面
- ❌ 形式只是包装（去掉照样成立）→ 形式必须不可替代
- ❌ 3分钟塞完整弧光 → 放弃弧光，聚焦概念
- ❌ 概念很好但跳过推演直奔翻转 → 推演是观众入戏的过程，不能省
