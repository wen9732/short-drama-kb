### 6.2 冲突裁决
| 冲突 | 裁决 | 依据 |
|---|---|---|
| C 的章节字卡要在画面里出字 | Seedance 不生成文字，只出黑场或空镜，字在后期加 | 执行层优先（防字幕） |
| C 的音乐桥要背景音乐跨切点 | Seedance 默认无 BGM，音乐在后期铺 | 执行层优先 |
| C 写"前后各留 0.5 秒""提前 1–3 帧" | 改为整数秒；帧级需求交给后期 | 官方：时间戳只认整数秒 |
| C 第 9 节"每次生成后把断点回写到条目风险栏" | 单次结果只记 `日志/生成实验日志.md`；同一现象 ≥2 次才写进条目 | CLAUDE.md 第七节升级门槛 |
| C 的 Bridge State＝状态胶囊＋转场设计 | 拆层：状态胶囊（人物、道具、环境状态）归 `exec-seedance25` 的段间接口；转场设计归本库 | 一个库只管一个维度 |
| C 的"机型辞典"管镜内怎么动 | 对应本仓库将来的运镜库 | 镜头层子域分库 |

### 6.3 案例订正（已联网核对）
- **《战栗空间》：** C 写"穿过垃圾桶把手"。核对后为：镜头穿过茶壶／咖啡壶的把手、钥匙孔，并在整栋房子里游走（befores & afters 对视效团队的访谈）。全集已改。
- **《超时空接触》镜子镜头：** C 归为"推入物体"。实际是镜头在小艾莉前方一路后退，最后揭示整个画面是药柜镜子里的倒影（/Film）。已移到 T11 画中画／镜面揭示。
- **《老男孩》"横移穿越墙壁完成时间跳跃"：** 未能核实。能查到的是走廊打斗为一镜到底（只有刀插背部做了处理），与时间跳跃无关。全集未收录此说法，待用户提供具体镜头时间点再补。
- **芬奇《社交网络》"宿舍季节跳切"：** 未能核实，全集未收录，T24 只保留王家卫《重庆森林》作为思路参照。
- **《辛德勒的名单》红衣女孩：** 是色彩线索而非转场本身，T28 未收为转场案例。
