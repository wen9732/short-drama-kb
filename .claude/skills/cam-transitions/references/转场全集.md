# 转场全集（34 类）

> 本文件是 `cam-transitions` 技能的详细参考。合并了三份素材：两份教学视频报告（13 类创意转场、六类转场提示词）和《电影级转场知识库·好莱坞导演方法版》（下称 C），并扩充了好莱坞、韩国、日本导演的转场手法。合并与来源说明见同目录 `来源与合并说明.md`。
>
> **每一类都按同一格式写：** 职务（为什么切）→ 切点（在哪个瞬间切）→ Seedance 句式（可直接复制改写）→ 执行方式 → 翻车点 → 案例。

---

## 〇、通用语法：转场是一对镜头的接口合同

### 反无脑三原则（来自 C）
1. **转场必须有工作**：说不出这一刀在交代什么（时间过了？换地方了？情绪反了？主题扣上了？），就用硬切。**硬切是默认设计**，花式转场是标点，标点多了就没有句子。
2. **元素必须在场**：遮挡要有真实遮挡物，匹配要有真实可匹配的形状、动作、颜色，声桥要有真实声源。为转场凭空变出烟雾、黑影、光斑，是生成翻车的头号来源。
3. **成对书写**：前镜负责"把元素送到位"，后镜负责"从元素里出来"。只写后镜，转场必断。

**导演共识：** 斯皮尔伯格把转场藏在动作与遮挡里；芬奇的转场可以走物理上不可能的路径，但动机是追踪信息；诺兰把切点压在节奏与悬念的结构位上；埃德加·赖特让转场本身成为笑点、爽点，靠速度与声音对位；维伦纽瓦用声音与尺度慢慢把观众"沉"进下一场。方法不同，共通点只有一个：每个转场都有明确的叙事职务。

转场不是一个特效名，而是**前后两镜在同一条提示词里同时写死的交接**。每一条转场都写成四段：

| 段 | 写什么 |
|---|---|
| ① 前镜尾态 | 前一镜把转场元素送到切点状态（动作到一半、遮满画面、照至全白） |
| ② 切点条件 | 在哪个瞬间切（相位一半、全遮挡、模糊峰值、全白） |
| ③ 后镜首态 | 后一镜从什么状态开始、怎么动（接着完成动作、遮挡物沿原方向移出、续甩后减速） |
| ④ 对应约束＋禁令 | 什么必须对应（姿态、方向、大小、位置），什么不许（不重复、不停顿、不变形、不叠化、不频闪） |

### 执行方式（Seedance 2.5）

| 代号 | 方式 | 适用 |
|---|---|---|
| **A｜单段内** | 一条提示词写两个时间段，在指定整数秒切换 | 大多数转场；前后两镜都在本次生成里 |
| **B｜首尾帧／关键帧** | 先用图像模型做出对齐的两张关键帧，再用首尾帧或关键帧参考生成 | 形状匹配、构图匹配等要求精确对位的转场 |
| **C｜衔接／延长** | 分别生成两段，用官方的视频延长或两段衔接任务接起来 | 跨越 30 秒上限的长镜头、两个独立生成的场次 |
| **D｜后期** | 生成干净的前后两镜，转场在剪辑软件里做 | 划像、精确叠化、拼贴撕纸、碎屏、手势界面 |

**通用纪律：**
- 切点落在整数秒上（官方只认整数秒）；秒以内的相位用先后顺序描述。
- 转场的光、物、动作必须**来自场景内部**（车灯、门、路人），不凭空出现。
- 转场服务叙事：同一段戏里视觉转场不超过 2 种（声音桥不计）；对白戏默认硬切。
- 首尾帧任务和延长任务的画幅随输入，`ratio` 需设为 `adaptive`（官方）。

### 转场的七种职务（先定职务，再选类型）

| 职务 | 首选类型 |
|---|---|
| **隐形连续**：让观众感觉不到切了 | T01 动作匹配、T05 遮挡、T19 隐藏剪辑长镜 |
| **跳空间**：同一时刻换地方 | T03 视线匹配、T05 遮挡、T27 门、T06 甩镜、T09 快速变焦、T10 穿越 |
| **跳时间**：过去↔现在、跨越年月 | T02 形状匹配、T15 意义匹配、T17 叠化、T07 闪白、T24 同机位时间流逝、T25 跳切、T26 定格 |
| **情绪突变**：气氛一刀切断 | T33 硬切重音、T09 快速变焦、T08 闪切、T21 轴向切、T31 静默 |
| **揭示／反转**：原来刚才的一切是…… | T11 画中画、T22 空间叠合 |
| **意义连接**：两件事被并置出新含义 | T15 意义匹配、T32 构图匹配／镜像反转、T28 色彩匹配、T16 声音桥、T23 交叉蒙太奇 |
| **节奏与呼吸**：停一下、喘口气 | T20 空镜、T29 焦点接力、T18 划像、T30 音乐桥、T34 章节字卡 |
| **什么都没跨**（同一场连续动作） | 硬切或 T01 动作匹配，没有例外 |

## 一、匹配类：靠前后两镜的某样东西对上

### T01｜动作匹配（Action Match）
- **职务：** 隐形连续；也可跨越巨大的空间、媒介差异（真人→游戏画面），动作不断。
- **切点：** 动作相位的**一半**，不是动作完成时。
- **Seedance 句式：**
  > X–Y秒：[前镜] 拳手被重拳击中，身体后仰到一半。第Y秒切换到 [新场景]。Y–Z秒：同一拳手保持后仰姿态在水中继续倒下，再稳住身形。动作进行到一半时切换，下一镜接着完成动作，不重复、不停顿。前后姿态、方向、主体大小和画面位置对应。
- **执行方式：** A。
- **翻车点：** 后镜把动作从头再演一遍 → 写"不重复"；后镜起幅静止 → 写"接着完成、不停顿"；**动作方向在切点反了**，观众立刻出戏（与打斗"不反轴"同源）→ 写明方向。
- **切点相位可以调：** 默认"一半"；挥砍、出拳这类快动作可写"挥到大约六成处切换"。前后两镜写同一条"切点动作"：动作名、方向、速度、相位。【C】
- **打斗拆镜的接缝也靠它：** 出招镜结尾的武器轨迹方向和速度，必须在打中镜开头延续（打斗细节归 `fight-`）。【C】
- **门转场是它的特例：** 前镜手落在门把上，后镜门已推开、人物跨过门槛，见 T27。
- **案例：**
  - 教学演示：一巴掌扇中，切点压在命中瞬间，下一镜同一受击姿态在深海里继续。
  - 《毕业生》（迈克·尼科尔斯）：本杰明从泳池扑上充气垫，落下时已扑到酒店床上，一个动作跨越两个空间和两段关系。
  - 足球广告：真人带球射门 → 游戏画面扑救 → 回到真人倒钩，媒介全换、动作不断。

### T02｜形状匹配（Shape / Graphic Match）
- **职务：** 跳时间、跳空间，同时建立视觉隐喻。
- **切点：** 不藏，硬切对齐。
- **Seedance 句式：**
  > 用前后两个主体的相似形状连接场景。X–Y秒：俯拍一只咖啡杯，圆形杯口位于画面上方中央。第Y秒直接切到夜空中的圆月，月亮的大小、位置与杯口一致。让轮廓、大小、位置和朝向尽量对应。直接匹配切换，物体不变形，画面不叠化。
- **执行方式：** A 可用；要求精确对位时用 B（先出两张对齐的关键帧）。
- **翻车点：** 模型用变形（morph）或溶解糊过去 → 必须写"不变形、不叠化"；大小位置漂移 → 改用 B。
- **对位标准（C）：** 形状、占画面的大小、画面坐标三项至少对上两项；对不上就降级为普通硬切，不要"差不多像"。最稳的做法是先把前后两帧当作一对图设计好，再写动作（执行方式 B）。
- **剂量：** 一部短片最多 1 次，是全片级的重音。
- **进阶：** 一条链只用一个形状元素串到底（圆：仰躺旋转的构图 → 洗衣机滚筒 → 红色圆凳 → 高尔夫球洞 → 俯瞰圆光圈）。
- **案例：**
  - 《惊魂记》（希区柯克）：浴缸排水口的旋涡，接死者瞪大的眼睛，旋转的圆匹配旋转的圆。
  - 教学演示：两把长剑交叉成 X → 火锅桌上两双筷子交叉夹肉。

### T03｜视线匹配（Eyeline Match）
- **职务：** 跳空间，建立"看的人—被看之物"的因果；叙事和对话的基础语法。
- **切点：** 人物注视、转头或指向的动作完成时。
- **Seedance 句式：**
  > X–Y秒：女主近景，她突然停下，视线投向画面左上方，眼睛微微睁大。第Y秒切到她看到的画面：[被看之物]，构图从画面左上方的方向呈现。
- **执行方式：** A。
- **翻车点：** 后镜方向与视线方向对不上（她看左上，后镜却是平视）→ 写明被看之物的角度与方位。
- **几何（C）：** 他向左看，被看之物就必须从他左侧的机位方向拍；高度差要在被看之物的景别里交代。
- **压迫感用法（C）：** 视线先行、延迟兑现：先让人物看见并变脸，下一镜才给观众看他看见了什么。
- **案例：** 洗衣房歌舞片按视线方向拆段：男士仰头指向左上 → 被抛起、向左飞的衬衫。

### T04｜焦点位置匹配（Focal Point Match，原称"视点匹配"）
- **职务：** 隐形连续；切点前后观众眼睛不用重新找焦点。注意：这不是主观镜头（POV）。
- **切点：** 焦点物体在画面同一位置时。
- **Seedance 句式：**
  > X–Y秒：红色心形棒棒糖位于画面右上三分之一处，人物含着它。第Y秒切到新场景，同一颗棒棒糖仍在画面右上三分之一处，被另一只手拾起。切换前后，棒棒糖在画面中的位置、大小保持一致，人物和场景改变。
- **执行方式：** A；精确时用 B。
- **案例：** 偶像短片，心形棒棒糖始终在画面同一焦点位置，人物与场景全换。

### T15｜意义匹配（Idea Match，跨时间的形状或动作匹配）〔扩充〕
- **职务：** 意义连接；用一次匹配跨越极长的时间，同时说出一个"道理"，但不用台词。
- **切点：** 动作或形状达到最强的那一刻。
- **Seedance 句式：**
  > X–Y秒：[人物] 把手中的火柴吹灭，火焰熄灭的瞬间。第Y秒直接切到 [远方的地平线]，太阳正从同一画面位置升起。两镜之间没有过渡，火焰与太阳在画面中的位置和大小对应。直接切换，不叠化。
- **执行方式：** A 或 B。
- **案例：**
  - 《2001 太空漫游》（库布里克）：猿人把骨头抛向天空，切到太空中形状相似的卫星，一刀跨越几百万年的人类工具史。
  - 《阿拉伯的劳伦斯》（大卫·里恩）：劳伦斯吹灭火柴，硬切到沙漠日出，从室内一跃进入他命运所在的沙漠。
- **剂量：** 一部短片最多 1 次，与 T02 形状匹配共用这个名额。对位不准就降级为硬切。【C】
- **写给短剧：** 适合"多年后"的跳转：少年把纸飞机扔出窗外 → 成年后的他在机场看着飞机起飞。

## 二、遮蔽类：把切点藏起来

### T05｜遮挡（Occlusion / Wipe-by）
- **职务：** 隐形连续或跳空间。
- **切点：** 遮挡物**完全遮满画面**的瞬间。
- **Seedance 句式：**
  > X–Y秒：[人物] 转身贴近镜头走过，衣服在最近处完全遮满整个画面。第Y秒在完全遮挡时切换到下一场景。Y–Z秒：遮挡物沿原方向继续移出画面，速度和动作连贯，露出 [新场景]。
- **执行方式：** A。
- **翻车点：** 后镜静止揭开 → 必须写"沿原方向继续移出"；遮挡不完全 → 写"完全遮满整个画面"。
- **两个子类：** 物品遮挡（手提包、托盘、门板）；场景遮挡（墙面、柱子、驶过的车）。
- **方向与色调（C）：** 遮挡物的运动方向决定擦镜方向，后镜遮挡物同方向退出；前后遮挡物色调接近时接缝最隐形。
- **剂量与禁用（C）：** 一段戏最多 3 次，多了观众会开始等遮挡；空旷、没有前景物的场景禁用，不要凭空"召唤一块黑布"。
- **案例：**
  - 斯皮尔伯格（《夺宝奇兵》系列）：前景人物过镜即换场，观众察觉不到剪辑。【C】
  - 《夺魂索》（希区柯克）：用人物深色西装后背遮满镜头来藏剪辑点，整部片看起来像一镜到底。

### T06｜甩镜／快速摇镜（Whip Pan）
- **职务：** 跳空间，带速度感和喜感。
- **切点：** 运动模糊**最强**的一帧。
- **Seedance 句式：**
  > X–Y秒：[前镜主体] 静止亮相，随后镜头向右快速横甩，画面成全幅运动模糊。第Y秒在运动模糊最强时切换场景，保持模糊方向一致。Y–Z秒：下一镜接着向右甩动，速度接近，再逐渐减速露出 [新场景]。
- **执行方式：** A。
- **翻车点：** 后镜从静止起幅 → 写"接着甩动，再逐渐减速"；方向反了 → 写同一方向。
- **声音同帧（C）：** 甩镜也是一个音效事件，"呼"的风声与模糊峰值同时到达；落点主体在甩停的第一刻就要看得清。
- **剂量与禁用（C）：** 一段戏最多 2 次；文戏、悲伤段禁用，甩镜天生亢奋。
- **案例：** 埃德加·赖特（《热血警探》《僵尸肖恩》）把甩镜、快速变焦、超短插入镜头组合成喜剧节奏，日常小事被剪得像动作片。

### T07｜闪白（Flash to White）
- **职务：** 跳时间（现实↔回忆）、强烈情绪冲击。
- **切点：** 画面全白的瞬间。
- **Seedance 句式：**
  > X–Y秒：远处车灯驶近，强光迅速把画面照至全白。第Y秒全白时切换场景，下一镜从同样的全白开始。Y–Z秒：逐渐恢复曝光，露出 [新场景]。全白短暂，不频闪。
- **执行方式：** A。
- **翻车点：** 凭空白闪 → 强光必须来自场景内部（车灯、阳光、闪光灯、窗）；频闪 → 写"不频闪"。
- **变体：** 闪黑（关灯、闭眼、进隧道）同样写法，把"全白"换成"全黑"。
- **分工（C）：** 闪黑＝章节、死亡、昏迷、时间大跳；闪白＝神性、爆炸、顿悟、记忆灼伤。
- **剂量（C）：** 这是段落级分隔，不是镜与镜之间的转场。一部短片闪黑最多 3 次、闪白最多 1 次；镜间滥用闪白，等于每句话都加感叹号。

### T08｜闪切（Flash Cut）
- **职务：** 情绪突变、紧张、混乱；观众感受到节奏，而不是信息。
- **切点：** 节奏点（灯光闪烁、心跳、枪声）。
- **Seedance 句式：**
  > X–Y秒：灯光开始闪烁。每一次灯光亮起，画面都快速跳切一次：先是全景，再是半身，最后压到为首男子的脸部特写。切换节奏跟随灯光闪烁，越来越近。
- **执行方式：** A；单个镜头不短于 1 秒（整数秒限制），更碎的节奏交给后期。
- **翻车点：** 跳切之间人物换脸、换衣 → 每个镜头重复锁定人物参考。
- **子类：闪帧（C）。** 在切点插入一两帧白帧、爆闪帧或漫画帧作标点。Seedance 只认整数秒，做不到帧级 → 只能 D。展示型、风格化段落可以成组使用（重复即风格），组与组之间要有不闪的正文段；真实攻防段只许出现在命中帧和切点，不进动作正文。

### T19｜隐藏剪辑长镜（Hidden-Cut Long Take）〔扩充，AI 视频最实用〕
- **职务：** 把多段生成缝成"一镜到底"，突破单段 30 秒上限。
- **缝合点：** 黑暗（进门、进隧道、夜里没灯的地方）、遮挡（人或物经过镜头）、快速运动、主体出画再入画。
- **Seedance 做法：**
  1. 第一段结尾写好缝合点：`最后2秒，镜头跟随人物走进没有灯的门洞，画面逐渐全黑。`
  2. 第二段用官方延长任务（或首帧接上一段末帧），开头写：`从全黑开始，镜头跟随人物从门洞另一侧走出，光线逐渐恢复。`
  3. 两段的运动方向、速度、人物服装与状态写成一样。
- **执行方式：** C。
- **案例：**
  - 《1917》（萨姆·门德斯、罗杰·迪金斯）：约 30 个镜头缝成一镜到底的错觉；全片唯一明显的断点是主角昏迷黑场，恰好是他视角唯一的中断。
  - 《夺魂索》：用演员的深色后背遮镜头接片。
- **翻车点：** 缝合前后光线、方向不一致 → 两段写同一句光线和运动描述。

## 三、空间穿越类：镜头"进入"另一个空间

### T09｜快速变焦（Crash Zoom）
- **职务：** 情绪突变、一镜跨越多层空间。
- **切点：** 变焦最快的时刻；或不切，一镜完成。
- **Seedance 句式：**
  > X–Y秒：女子张嘴呐喊的面部特写。随着喊声，镜头瞬间快速拉远，穿出窗户，沿着街道高速后退，最后落在空地上踢球的小女孩身上，她回头一笑。
- **执行方式：** A（一镜内完成）。
- **翻车点：** 拉远过程中空间被跳过或乱接 → 写清楚依次穿过的每一层空间。
- **案例：** 埃德加·赖特的喜剧快速推近，用来"砸"出一个笑点或一个决定。

### T10｜物体传送门／穿越（Object Portal / Fly-through）
- **职务：** 跳空间，让两个毫无关联的地方产生奇妙连接。
- **切点：** 镜头进入物体内部、画面全黑或全满的瞬间。
- **Seedance 句式：**
  > X–Y秒：镜头推近老人张开的嘴，直到嘴的黑暗占满画面。第Y秒在全黑时切换。Y–Z秒：镜头从另一位老太太张开的嘴里退出来，她正坐在夜市摊位前。
- **执行方式：** A；穿越过程复杂时拆成独立的过桥镜头，不指望单镜完成穿越。
- **常用物体：** 嘴、钥匙孔、隧道口、杯口、眼睛、门缝、水面、屏幕、镜子、照片。
- **两个子类（C）：**
  - **推入界面**：推进屏幕、镜子、水面、瞳孔、照片，直到它占满画面，从内部出来已是新时空。适合进入回忆、进入屏幕内容、进入异世界。物体表面要有"界面感"（反光、发光、液面、纹理），推进时纹理持续放大不跳变。
  - **穿越通道**：镜头连续穿过门洞、窗口、隧道、把手的孔洞，空间在穿越中替换。
- **硬条件（C）：** 物体和新空间必须有关系；推进茶杯却出来一个战场，观众会当穿帮笑。穿越点在前后两镜都要存在并对位，穿越路径上不能有第二层实体。
- **AI 生成写法（C）：** 拆成三段：前镜正常结尾 → **独立生成的过桥镜**（纯穿越，3–5 秒）→ 后镜正常开场，剪辑拼接。穿模是重灾区；降级方案：推到洞口前硬切，后镜从洞口内反打出来。
- **剂量：** 一段戏最多 1 次。
- **案例：** 芬奇《战栗空间》开场的数字长镜：镜头在整栋房子里游走，穿过咖啡壶的把手、钥匙孔；芬奇《搏击俱乐部》也有类似的"不可能运镜"。动机是追踪信息，不是炫技。

### T11｜画中画／媒介切换（Screen Reveal / Medium Transition）
- **职务：** 揭示、反转："原来刚才的一切都在屏幕里／照片里／镜子里"。
- **切点：** 无切点，连续后拉一镜揭示；或前镜内容换一种载体再现。
- **Seedance 句式：**
  > X–Z秒：暴风雨海面搜救艇的画面铺满全屏，镜头连续后拉，逐渐露出电视屏幕的边框，再露出周围的客厅和沙发上吃爆米花的女人。屏幕内原视频持续播放，不定格、不变形。
- **执行方式：** A。
- **常用载体：** 电视、手机、后视镜、照片、报纸、画作、窗户反光。
- **翻车点：** 屏幕里的画面定格或被拉扯变形 → 写"持续播放、不定格、不变形"。
- **案例：**
  - 白棚女子面部特写，拉开发现映在摩托后视镜里，再拉开是她骑车上路的全身。
  - 《超时空接触》（罗伯特·泽米吉斯）：小艾莉跑上楼梯去拿药，镜头在她前方一路后退，最后才发现整个画面是浴室药柜镜子里的倒影。镜面揭示的经典案例（C 把它归入推入物体，实为后退揭示，归在这里）。

### T22｜空间叠合（观察者进入被观察的空间）〔扩充〕
- **职务：** 揭示心理：一个人对另一个人的执念，让他"出现"在对方的空间里。
- **做法：** 观察者在 A 地（车里、对面楼），镜头随他的视线推进，下一刻他已经站在 B 地（对方家里）与对方面对面，台词照常进行；最后再切回他其实还在 A 地。
- **Seedance 句式：**
  > X–Y秒：男主坐在车里，举着望远镜看向对面公寓的窗户。镜头沿他的视线推向那扇窗。Y–Z秒：男主站在女主的客厅里，离她一步远，两人对视；他手里没有望远镜。Z–W秒：硬切回车里，他仍举着望远镜，一个人。
- **执行方式：** A。
- **案例：**
  - 《分手的决心》（朴赞郁，摄影金志勇）：刑警盯梢时想象自己进入她的公寓，与她面对面说话，现实中他其实只是在车里打电话。片中还有从手机屏幕内部往外看的机位、透过鱼眼的视角。
  - 今敏（《千年女优》《红辣椒》《未麻的部屋》）：以匹配剪辑贯穿现实、电影、梦与回忆，人物一个动作没做完，就已经从一个时代跑进另一个时代。
- **写给短剧：** 前任回忆、暗恋、执念类戏的利器；比闪回更省时、更有心理感。

## 四、时间与节奏类〔扩充〕

### T16｜声音桥（Sound Bridge，J-cut／L-cut）
- **职务：** 意义连接、跳时空时让观众提前准备好。
- **做法：** 下一场的声音**提前**在上一场结尾出现（J-cut）；或上一场的声音**延续**到下一场开头（L-cut）。
- **Seedance 句式：**
  > X–Y秒：女主在安静的化妆间里戴上戒指。最后一秒，画面还在化妆间，却提前传来密集的雨声和公交车的报站声。第Y秒切到七年前雨夜的公交站，雨声和报站声继续，自然衔接。
- **执行方式：** A（Seedance 原生生成音频，可在提示词里写声音的先后）；精确对位时 D。
- **硬条件（C）：** 先行的声音必须有明确声源，并在后镜兑现；故意不兑现来制造悬念，一段戏只许骗一次。前镜结尾的对白不要顶到切点，给先行的声音留白。
- **L-cut 用于余韵（C）：** 本场的声音拖进下一场的画面，让情绪多停一会儿。
- **子类：撞击声桥（C）。** 后镜的巨响（爆炸、枪声、摔门）提前一两帧砸进前镜尾巴，画面随声切。声桥是"拉"，撞击声桥是"砸"。帧级对位只能 D；A 里可以写"枪声响起的同一秒切换"来近似。动作段可连用两三次成节奏组。
- **剂量（C）：** 钩子型声桥（爆炸、尖叫）一段戏最多 1 次。
- **案例：**
  - 维伦纽瓦（《降临》《沙丘》）：大量用声音先行把观众"吸"进下一场。【C】
  - 《三十九级台阶》（希区柯克）：房东太太发现尸体时张嘴尖叫，声音被火车汽笛取代，切到疾驰的火车。
  - 《现代启示录》（科波拉）：吊扇的转动声与直升机螺旋桨声交叠，形状和声音同时匹配，把酒店房间和越南丛林连在一起。

### T17｜叠化（Dissolve）
- **职务：** 跳时间、回忆、两个画面在情感上相连。
- **注意：** 叠化有自己的职务（回忆、时间流逝），但**不能拿来代替形状匹配**：形状匹配禁叠化。
- **Seedance 句式：**
  > X–Y秒：老人看着桌上妻子的照片。第Y秒画面缓慢叠化，照片的轮廓淡出，同时淡入多年前葬礼那天的同一个房间。叠化过程两三秒，平稳，不变形。
- **执行方式：** D 最稳；A 可以尝试，但容易出现画面融化变形。
- **生成端的准备（C，按整数秒改写）：** 前镜最后 1 秒、后镜最初 1 秒保持稳定画面，叠化吃的是素材的头尾；剪辑时叠化长度约半秒到一秒。
- **素材条件（C）：** 叠合瞬间两画面的亮区和暗区最好互补（前镜亮处压后镜暗处），否则叠合段会糊成一团。
- **剂量与禁用（C）：** 一段戏最多 2 次；快节奏动作段、动作高潮段禁用（叠化泄力）。当代短片里叠化自带怀旧滤镜，没有这个意图时慎用。
- **案例：** 《生之欲》（黑泽明）：开场胃部 X 光片叠化到主角本人；主角看妻子遗照，叠化进她葬礼那天的回忆。

### T18｜划像（Wipe）
- **职务：** 节奏、时间流逝、有意保持距离感（比叠化冷静、客观）。
- **做法：** 新画面像一条边线扫过旧画面。自然划像用场景里的运动完成（车、门、人横穿画面），即 T05 遮挡的变体。
- **Seedance 句式（自然划像）：**
  > X–Y秒：一辆货车从画面右侧横穿到左侧，车身像一条边线扫过画面。第Y秒切换，货车驶出后露出新场景，划过的方向与货车运动方向一致。
- **执行方式：** 自然划像用 A；图形划像用 D。
- **案例：** 黑泽明（《七武士》《生之欲》）常用划像，方向随人物或车的运动；乔治·卢卡斯受他影响，在《星球大战》里大量使用划像。

### T20｜空镜过渡（Pillow Shot）
- **职务：** 节奏与呼吸；场景之间停一下，让人物没说出口的情绪留在空气里。
- **做法：** 两场戏之间插 2–4 秒没有人物的空镜：海岸、电线杆、晾着的衣服、空了的椅子、窗外的列车。
- **Seedance 句式：**
  > X–Y秒：空镜。医院走廊尽头的窗户，窗外是阴天的楼群，一只鸟从窗前飞过。固定机位，没有人物，只有远处的车声。
- **执行方式：** A（可以单独生成，也可以插在一段中间）。
- **案例：** 小津安二郎（《东京物语》《晚春》）：场景之间的海岸、码头、火车、花瓶空镜，既标记换场，也替人物说出说不出口的情绪；《晚春》里那只花瓶是影史上被讨论最多的空镜之一。

### T21｜轴向切（Axial Cut）
- **职务：** 情绪突变、强调某个物件或表情；"砸"进去。
- **做法：** 机位和角度不变，沿同一条轴线直接从远切近（或从近切远）。
- **Seedance 句式：**
  > X–Y秒：全景，男主站在玄关，门口挂着一顶旧帽子。第Y秒沿同一机位轴线直接切近，变成帽子的特写，角度不变。
- **执行方式：** A。
- **案例：** 《生之欲》：一顶帽子用轴向切强调出来，平凡的物件因此标记出主角所剩时日的新的一天。

### T23｜交叉蒙太奇（Parallel / Cross-Cutting Montage）
- **职务：** 意义连接、节奏推进、把计划与执行、两个地方的同一时刻并置。
- **做法：** 两条线交替切；用音乐统一节奏；关键细节先埋后收。
- **Seedance 句式：**
  > 0–2秒：昏暗的半地下室，一家人围坐排练台词。2–4秒：明亮的豪宅客厅，母亲照着排练过的话对女主人说出同一句台词。4–6秒：回到半地下室，父亲举起一颗桃子。6–8秒：豪宅里，桃子的绒毛在阳光里慢动作飘落。两条线交替出现，每次切换都在台词或动作的呼应处。
- **执行方式：** A（一段里 4–6 个镜头为宜）；更长的蒙太奇分段生成后 D。
- **案例：** 《寄生虫》（奉俊昊）"桃子蒙太奇"：约 60 个镜头、5 分钟，把一家人排练谎言与执行谎言交叉剪辑，配古典乐和慢动作，桃毛像雪一样飘落；平静的节奏让观众放松，结尾的门铃声成为反转。

## 五、设计与特效类（多数交给后期）

### T12｜手势交互（Gesture Interaction）
- **职务：** 短视频、产品演示的互动感。
- **做法：** 第一人称手部对实景做捏合、放大、滑动，画面随手势缩放或滑走。
- **执行方式：** D 为主；A 只能做"手推开画面、下一镜从同方向滑入"这类简单版本。
- **只用于：** 展示段、广告段。不用于叙事和情感戏。

### T13｜拼贴／撕纸（Collage / Tear）
- **职务：** 平面设计感、风格化开场。
- **做法：** 后一镜的元素提前像贴纸一样贴进前一镜；或前一镜像照片一样被撕开露出后一镜。
- **执行方式：** D。
- **只用于：** 片头、MV、广告。不用于叙事和情感戏。

### T14｜特效转场（Effect Transition）
- **职务：** 风格塑造：光效、粒子、故障、烟雾、火焰、液态、碎屏。
- **执行方式：** D；或在 A 里写成场景内部的真实事件（例如"玻璃被砸碎，碎片飞向镜头遮满画面"＝用 T05 遮挡完成）。
- **纪律：** 特效只作标点，只进展示段和短视频段，不进叙事和打斗段。

## 六、补充九类（来自 C 的导演方法版，按 Seedance 改写执行方式）

### T24｜同机位时间流逝（Locked-off Time Pass）
- **职务：** 跳时间；同一地点的等待、岁月、物是人非，基调是怅然或命运感。
- **做法：** 机位、构图完全不动，画面里的光线、季节、人群、陈设跳变，时间在同一个"框"里流过去。
- **素材条件：** 场景里至少两项可跳变的时间证据（光色、人流、陈设、积雪、枯荣）。
- **Seedance 句式：**
  > 固定机位，构图全程不变。0-3秒：白天，小面馆里坐满客人，女主坐在靠窗的位置。第3秒直接跳切：傍晚，客人少了一半，她还坐在原位，面前的面已经凉了。第6秒再跳切：深夜，店里只剩她一个人，窗外下起了雨。建筑、桌椅、窗框的位置纹丝不动，只有光线、客人和窗外天气变化。
- **执行方式：** A（一条提示词内）；最稳的是 B：用同一张首帧图分别生成多段。
- **翻车点：** 机位有任何漂移就破功 → 写"固定机位、构图全程不变"；建筑结构跟着变 → 写"纹丝不动"。
- **案例：** 王家卫《重庆森林》用抽帧让人流加速、人物不动，是"框不动、世界动"的同一思路。【C】

### T25｜跳切（Jump Cut）
- **职务：** 跳时间；焦躁、重复、无聊被加速，或喜剧性的笨拙时间压缩。
- **做法：** 同一机位、同一景别、同一主体，中间抽掉一截时间，人物在画面里"瞬移"一小步，每次姿态变一档。
- **Seedance 句式：**
  > 固定机位，同一景别。0-2秒：男主坐在床边盯着手机。第2秒跳切：他躺倒在床上，手机举在脸上方。第4秒跳切：他坐在地板上，背靠着床，手机扔在一边。第6秒跳切：他站在窗前，又拿起手机。每次跳切只换姿态和位置，机位与房间不变。
- **执行方式：** A；每一跳不短于 1 秒。
- **禁用：** 庄重、悲伤、浪漫段落（跳切天生带轻佻和神经质）。
- **案例：** 戈达尔《筋疲力尽》开创，王家卫、盖·里奇继承。【C】

### T26｜定格（Freeze Frame）
- **职务：** 把人物命运的钉子（决定、被捕、死亡、顿悟）从时间里单独拎出来。
- **做法：** 画面在某一帧冻结半秒到两秒，再切走或继续；定格期间只留环境声或旁白。
- **执行方式：** D（后期定格）。生成端负责把峰值做出来：`第X秒，他回头的瞬间表情到达顶点并保持1秒，身体静止。`
- **翻车点：** 定格帧必须是动作或表情的峰值帧，不是过渡帧；选错等于把废帧裱起来。
- **剂量：** 全片最多 2 次，且不挨着。
- **案例：** 斯科塞斯《好家伙》定格加旁白，作为人生节点的句号；特吕弗《四百击》结尾的定格。【C】

### T27｜门转场（Door Transition）
- **职务：** 跳空间，同时伴随关系或权限变化：进入禁区、被拒之门外、回家、离家。门开是新世界，门关是章节终结。
- **素材条件：** 门在剧情里有实际功能，不是布景；开门方向与人物进出方向一致。
- **Seedance 句式（动作匹配版）：**
  > 3-5秒：走廊，女主停在病房门前，右手落在门把上，往下压。第5秒切换。5-7秒：病房内，门正被推开，女主跨过门槛走进来，推门的方向和速度与上一镜连贯。
- **Seedance 句式（关门收束版）：**
  > 固定机位，从室内拍向门口。女主站在门外看着屋里，男主在门内背对她，伸手把门慢慢合上。门缝越来越窄，最后只剩她的半张脸，门完全关上，画面里只剩门板。
- **执行方式：** A。
- **案例：** 《教父》结尾，门在凯的面前缓缓合上，她被关在家族之外，门即隐喻。【C】

### T28｜色彩匹配（Color Match）
- **职务：** 意义连接；两场情绪同频或主题同色，追求诗意而不是逻辑的连接。
- **素材条件：** 前镜尾、后镜首的主色占画面三成以上，色块位置接近更好。
- **Seedance 句式：**
  > 0-3秒：女主的红色围巾在风里扬起，占满画面下半部分。第3秒直接切换到夕阳下的红色沙丘，红色占据画面下半部分的同一区域。
- **执行方式：** A；色块要对位时用 B。前后两镜的影调锁定里写同一个主色锚（例如"暗红色"），主色锚归 `genre-` 的影像段，本库只负责切点。
- **案例：** 张艺谋、王家卫的色彩跳场；当代短视频的"色彩转场"源于此。【C】

### T29｜焦点接力（Rack Focus Bridge）
- **职务：** 节奏与呼吸；凝视、沉思这类情绪绵延不断的换场，或从一个人的眼睛换到另一个人的眼睛。
- **Seedance 句式：**
  > 2-4秒：女主近景，她看着窗外，焦点慢慢从她的脸上虚掉，最后画面完全失焦，只剩模糊的光斑。第4秒切换。4-6秒：从同样的失焦光斑开始，焦点慢慢拉实，露出另一座城市里站在车站的男主。
- **执行方式：** A。
- **素材条件：** 两镜都要有可虚可实的主体层，虚焦程度在切点对齐。
- **禁用：** 快节奏段（焦点接力是慢转场，用在动作段会泄力）。

### T30｜音乐桥／节拍转场（Music / Beat Bridge）
- **职务：** 节奏；蒙太奇、多地点并置、训练和准备段落，情绪要"流动向前"。
- **做法：** 同一段音乐跨越切点，切点压在重拍上；歌不断，场可跳。与声音桥的区别：声音桥是"声音先行"，音乐桥是"音乐不断、画面跳"。
- **执行方式：** D。`exec-seedance25` 默认无背景音乐，音乐在剪辑时铺。生成端负责把切点两侧的动作峰值（落脚、关门、击发）落在整数秒上，方便卡拍。
- **案例：** 埃德加·赖特《极盗车神》全片如此；昆汀的歌曲跨场同理。【C】

### T31｜静默转场（Silence Cut）
- **职务：** 情绪突变；巨响之后、死亡瞬间、顿悟瞬间，让观众"喘不过气"的一拍。
- **Seedance 句式：**
  > 第5秒，爆炸声响起的同时，所有声音瞬间消失，只剩微弱的高频耳鸣。5-8秒：男主慢慢转过头，嘴在动，但听不见他说什么，周围的人在跑，没有脚步声。第8秒声音猛地回来。
- **执行方式：** A；精确控制时 D。
- **剂量：** 全片最多 2 次，静默 1–3 秒，长了变事故。没有巨响、没有顿悟的平段禁用。
- **案例：** 《拯救大兵瑞恩》奥马哈海滩的耳鸣式静默；维伦纽瓦用大段静默分隔章节。【C】

### T32｜构图匹配／镜像反转（Composition Match / Inversion）
- **职务：** 意义连接；主题是重复、轮回、对立、继承。
- **做法：** 两镜构图相同而内容不同（同构不同义＝命运重演）；或构图左右镜像反转（同构反义＝立场对调）。和 T04 焦点位置匹配的区别：T04 为了让眼睛不用重新找焦点，本条是为了让观众看出"同一个牢笼"。
- **Seedance 句式：**
  > 0-3秒：对称构图，少年时的男主跪在祠堂正中，父亲站在他面前。第3秒直接切换。3-6秒：同样的对称构图、同一位置，多年后的男主站在父亲当年的位置，他的儿子跪在面前。
- **执行方式：** A；精确对位时 B。
- **剂量：** 作者性最强的转场，一部短片一组足矣。
- **案例：** 朴赞郁常用对称构图的场景跳切，制造"同一牢笼、不同时间"；《阿拉伯的劳伦斯》火柴与日出也是构图与光亮的匹配（见 T15）。【C】

### T33｜硬切重音（Smash Cut）
- **职务：** 情绪突变；两个极端反差的画面直接硬切（宁静→爆炸、婚礼→葬礼、梦境→惊醒），反差即笑点或痛点。
- **Seedance 句式：**
  > 0-4秒：阳光很好的婚礼草坪，女主笑着接过捧花，宾客鼓掌。第4秒没有任何过渡，直接硬切。4-6秒：阴雨的墓地，同一个女主穿着黑衣，一动不动地站着。
- **执行方式：** A。
- **条件：** 前后两镜单独看都成立，撞在一起才有第三层意思。
- **剂量：** 一段戏最多 1 次，连用会让观众对反差脱敏。
- **案例：** 科恩兄弟、埃德加·赖特的喜剧重音；惊悚片的"安静一秒后巨响"。【C】

### T34｜章节字卡（Chapter Card）
- **职务：** 节奏；长片分段、时间地点大跳，让观众"翻页"。
- **执行方式：** **只能 D**。Seedance 里不生成任何文字（`exec-seedance25` 的防字幕规则优先），生成端只做一段干净的黑场或空镜，字在后期加。
- **注意：** 短视频里字卡会打断沉浸，只在结构确实分章时用。
- **案例：** 昆汀的章节体、韦斯·安德森的书页体。【C】
