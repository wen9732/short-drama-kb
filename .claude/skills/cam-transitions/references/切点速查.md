# 切点速查｜每一类转场在哪一刻切、后镜第一个动作是什么

> 从 `cam-transitions` 的 SKILL.md 拆出（v3.3），导演工位必读。接缝怎么选见 `exec-seedance25/references/导演语法.md` 第四节；每一类的完整句式、翻车点见 `转场全集.md`；直出型情绪音效（`BRAAM / Riser / Swish / Muffled` 等）与 `J-cut / L-cut` 声音桥设计按需见 `情绪音效与声音桥设计库.md`。

| 类型 | 切点 | 后镜第一个动作 | 执行 |
|---|---|---|---|
| T01 动作匹配 | 动作相位一半（快动作可写六成） | 接着完成同一动作，方向不反 | A |
| T02 形状匹配 | 不藏，硬切对齐 | 对应形状直接起幅 | A／B |
| T03 视线匹配 | 注视完成 | 被看之物，方位与视线一致 | A |
| T04 焦点位置匹配 | 焦点物在同一位置 | 同位置换人或换场景 | A／B |
| T05 遮挡 | 完全遮满 | 遮挡物沿原方向移出 | A |
| T06 甩镜 | 运动模糊峰值（风声同时到） | 同向续甩，再减速 | A |
| T07 闪白／闪黑 | 全白（全黑） | 从全白恢复曝光 | A |
| T08 闪切（含闪帧） | 节奏点（闪灯、心跳） | 景别逐级推近 | A＋D |
| T09 快速变焦 | 一镜内完成 | 逐层穿过空间 | A |
| T10 物体传送门／穿越 | 进入物体、占满画面 | 从物体内部或另一物体里出来 | A；复杂穿越拆过桥镜 |
| T11 画中画／镜面揭示 | 无切点，连续后拉 | 边框与新场景逐层露出 | A |
| T15 意义匹配 | 动作或形状最强时 | 远隔时空的对应物 | A／B |
| T16 声音桥（含撞击声桥） | 声音先到（J）或后留（L） | 画面跟上声音 | A／D |
| T17 叠化 | 前后各留 1 秒稳定画面 | — | D 优先 |
| T18 划像 | 场景内物体横扫 | 新场景随扫过方向露出 | A／D |
| T19 隐藏剪辑长镜 | 黑暗、遮挡、出画 | 下一段从同一状态接续 | C |
| T20 空镜 | 场与场之间 | 2–4 秒无人物 | A |
| T21 轴向切 | 同一轴线直接切近或切远 | 角度不变 | A |
| T22 空间叠合 | 视线推进 | 观察者已在对方空间里 | A |
| T23 交叉蒙太奇 | 台词或动作呼应处 | 两条线交替 | A／D |
| T24 同机位时间流逝 | 机位锁死，整数秒跳 | 只变时间证据 | A／B |
| T25 跳切 | 同机位抽掉一截时间 | 姿态变一档 | A |
| T26 定格 | 动作或表情峰值 | — | D（生成端做峰值） |
| T27 门 | 手落门把 | 门已开、跨过门槛 | A |
| T28 色彩匹配 | 主色占三成以上 | 同色块同位置 | A／B |
| T29 焦点接力 | 完全失焦 | 从失焦中对焦 | A |
| T30 音乐桥 | 重拍 | — | D |
| T31 静默 | 巨响或顿悟的同一秒 | 声音抽空 1–3 秒 | A |
| T32 构图匹配／镜像反转 | 硬切对齐 | 同构图不同内容 | A／B |
| T33 硬切重音 | 反差处，无过渡 | 极端反差的画面 | A |
| T34 章节字卡 | — | — | 只能 D |
| T12–T14 手势、拼贴、特效 | — | — | D |
