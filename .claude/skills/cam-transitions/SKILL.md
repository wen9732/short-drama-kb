# 镜头层·转场

## 边界
- **负责：** 两镜之间的交接：切点选在哪一刻、前镜怎么收、后镜怎么起、什么必须对应、什么禁止；跨段生成的缝合点（延长、衔接任务）。
- **不负责：**
  - 单镜内的景别、运镜、构图 → 未来的 `cam-` 运镜库（目前写在 `genre-korean-noir` 的镜头倾向里）。
  - 平台格式、时间戳、参考编号 → `exec-seedance25`。
  - 转场处人物的表情和情绪 → `perf-`。
  - 为什么要跳到回忆、跳到哪一年 → `script-`。
  - 闪光、粒子、故障这些特效的质感 → `genre-`。
- **互斥：** 无。与运镜、构图等镜头层其他子域的库可以叠加（见 CLAUDE.md 组合规则）。
- **常搭配：** `perf-restrained`（回忆戏、空镜呼吸）、`perf-explosive`（轴向切、快速变焦砸情绪）、`genre-korean-noir`。

## 一句话原则
**转场是一对镜头的接口合同**：前镜的尾态和后镜的首态必须写在同一条提示词里，同时写死。只写一个转场名，模型就会用叠化或变形糊过去。【经验：教学报告 B】

## 核心规则

### 1. 先定职务，再选类型
同一个转场类型可以服务不同职务，但职务决定选型。先回答"这一刀要干什么"：

| 职务 | 首选 |
|---|---|
| 隐形连续 | T01 动作匹配、T05 遮挡、T19 隐藏剪辑长镜 |
| 跳空间 | T03 视线匹配、T06 甩镜、T09 快速变焦、T10 物体传送门 |
| 跳时间 | T15 意义匹配、T02 形状匹配、T17 叠化、T07 闪白 |
| 情绪突变 | T21 轴向切、T09 快速变焦、T08 闪切 |
| 揭示、反转 | T11 画中画、T22 空间叠合 |
| 意义连接 | T15 意义匹配、T16 声音桥、T23 交叉蒙太奇 |
| 节奏、呼吸 | T20 空镜、T18 划像 |

### 2. 四段式句式（每个转场都要写满四段）
1. **前镜尾态**：把转场元素送到切点状态（动作到一半、遮满画面、照至全白）。
2. **切点条件**：第几秒、在什么瞬间切。
3. **后镜首态**：从什么状态开始、怎么动（接着完成、沿原方向移出、续甩后减速、从全白恢复）。
4. **对应约束＋禁令**：姿态、方向、主体大小、画面位置对应；不重复、不停顿、不变形、不叠化、不频闪、不定格。

### 3. 切点速查

| 类型 | 切点 | 后镜第一个动作 | 执行 |
|---|---|---|---|
| T01 动作匹配 | 动作相位一半 | 接着完成同一动作 | A |
| T02 形状匹配 | 不藏，硬切对齐 | 对应形状直接起幅 | A／B |
| T03 视线匹配 | 注视完成 | 被看之物，方位与视线一致 | A |
| T04 焦点位置匹配 | 焦点物在同一位置 | 同位置换人或换场景 | A／B |
| T05 遮挡 | 完全遮满 | 遮挡物沿原方向移出 | A |
| T06 甩镜 | 运动模糊峰值 | 同向续甩，再减速 | A |
| T07 闪白／闪黑 | 全白（全黑） | 从全白恢复曝光 | A |
| T08 闪切 | 节奏点（闪灯、心跳） | 景别逐级推近 | A＋D |
| T09 快速变焦 | 一镜内完成 | 逐层穿过空间 | A |
| T10 物体传送门 | 进入物体、全黑 | 从另一物体里退出 | A |
| T11 画中画 | 无切点，连续后拉 | 边框与新场景逐层露出 | A |
| T15 意义匹配 | 动作或形状最强时 | 远隔时空的对应物 | A／B |
| T16 声音桥 | 声音先到（J）或后留（L） | 画面跟上声音 | A／D |
| T17 叠化 | 两三秒平稳交叠 | — | D 优先 |
| T18 划像 | 场景内物体横扫 | 新场景随扫过方向露出 | A／D |
| T19 隐藏剪辑长镜 | 黑暗、遮挡、出画 | 下一段从同一状态接续 | C |
| T20 空镜 | 场与场之间 | 2–4 秒无人物 | A |
| T21 轴向切 | 同一轴线直接切近或切远 | 角度不变 | A |
| T22 空间叠合 | 视线推进 | 观察者已在对方空间里 | A |
| T23 交叉蒙太奇 | 台词或动作呼应处 | 两条线交替 | A／D |
| T12–T14 手势、拼贴、特效 | — | — | D |

每一类的完整句式、翻车点和案例见 `references/转场全集.md`。

### 4. 执行方式（Seedance 2.5）
- **A 单段内**：一条提示词写两个时间段，在指定整数秒切。默认选它。
- **B 首尾帧／关键帧**：先用图像模型做出对齐的两张关键帧，再生成。用于需要精确对位的形状匹配和焦点位置匹配。
- **C 延长／衔接**：分段生成，用官方的视频延长或两段衔接任务接起来。用于超过 30 秒的一镜到底。缝合点前后的光线、方向、速度、服装写成一样。
- **D 后期**：生成干净的前后两镜，转场交给剪辑软件。用于精确叠化、图形划像、拼贴、碎屏和手势界面。

### 5. 纪律
- 切点落在整数秒上；秒以内的先后关系用语序描述。【官方】
- 转场用的光、物、遮挡必须**来自场景内部**（车灯、门、路过的人），不凭空出现。【经验：教学报告 B】
- 同一条提示词里视觉转场类型不超过 2 种（声音桥是声音层的，不计入）。对白戏默认硬切，转场留给换场、换时空和情绪转折。【经验】
- 形状匹配和动作匹配必须写"不叠化、不变形"，否则模型默认融化过渡。【经验：教学报告 B】
- 后镜不能从静止起幅，除非转场本身就是硬切。遮挡、甩镜、动作匹配的后镜都必须**带着前镜的运动**进来。【经验：教学报告 B】
- 声音桥只用环境声和音效（雨声、汽笛、刹车声），不另加人声，以免违反"严格按台词生成"。【经验】
- 特效类只作标点，只进展示段、广告段，不进叙事和情感戏。【经验：教学报告 A】

## 写进提示词的哪里
- 时间轴：转场写在**前镜段的结尾和后镜段的开头**，两段都要写，不单独起一行"【转场】"。
- 【排除内容】：补上该转场的禁令，例如"禁止叠化，禁止画面变形，禁止频闪"。
- 跨段（执行方式 C）：在两条提示词里各写一次缝合状态，措辞相同。

## 写法示例
**AI 感写法：**
> 5秒：转场到回忆，七年前的雨夜。

模型会随手叠化或变形，前后两镜互不相干。

**正确写法（动作匹配）：**
> 3-4秒：女主抬起右手掀开头纱，手抬到额前一半时，第4秒切换。4-6秒：七年前雨夜的公交站，同一个女主抬着右手，接着把贴在额前的湿发拨开，动作不重复、不停顿。前后手的高度、方向、人物在画面中的大小和位置一致。

## 自检
- [ ] 这一刀的职务写得出来吗？写不出来就不要转场，用硬切。
- [ ] 四段都写了吗？尤其是后镜首态和禁令。
- [ ] 切点在整数秒上吗？
- [ ] 转场用的光、物来自场景内部吗？
- [ ] 一条提示词里视觉转场超过 2 种了吗？（声音桥不计）
- [ ] 跨段缝合时，两条提示词的缝合状态措辞一致吗？
- [ ] 有没有越界写了表演细节或单镜运镜？→ 交给 `perf-`／运镜库
