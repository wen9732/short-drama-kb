## 一、导演思维：设计一场戏之前先问这 15 个问题

| 编号 | 思维 | 问自己 |
|---|---|---|
| M01 | 观众先知道（希区柯克） | 张力能不能靠"观众知道、人物不知道"撑住？ |
| M02 | 视角归属 | 这是谁的戏？观众知道的和谁一样多？ |
| M03 | 画外比画内大 | 最重的东西一定要拍出来吗？ |
| M04 | 先效果后原因 | 反应先给，还是被看的东西先给？ |
| M05 | 母题与回响 | 哪样东西出现三次、每次意思都变？ |
| M06 | 对比与释放 | 最静的一拍在哪？张力在哪里释放？ |
| M07 | 空间即关系 | 关系变的那一拍，距离、高低、分割线变了吗？ |
| M08 | 摄影机的身份与动机 | 摄影机是谁的眼睛？凭什么动？ |
| M09 | 情绪交给身体和物件 | 手上有什么事？哪个动作漏出情绪？ |
| M10 | 时间可以剪 | 这一拍要省、压、拉，还是重放？ |
| M11 | 声音是结构 | 节奏声源是什么？哪个声音先到？ |
| M12 | 光是时间与立场 | 光从哪来？怎么变？谁在亮处？ |
| M13 | 珍贵的只用一次 | 全场的那一个高光手法放在哪？ |
| M14 | 形式即世界观 | 这个世界是秩序、混乱，还是冷漠？ |
| M15 | 留白 | 结论有没有留给观众自己完成？ |

不是每场都要全答。至少答 M02（视角）、M06（节奏）、M13（主接缝放哪），其余挑和本场相关的。

## 四、用法纪律

1. **先定任务，再找导演。** 从节奏曲线上每一拍的任务出发查第二节，不先想"用哪个导演"。
2. **主手法一到两位，美学统一。** 其他导演只贡献一个镜头或一个接缝。芬奇的锁定机位和迈克尔·贝的环绕不放进同一场安静的戏。
3. **抄机制，不抄外形。** 条目里的"机制"才是要学的；环绕少了"人物从下方升进画面、背景打开"，就只是转圈。
4. **"别用在"是硬约束。** 选中的手法和本场冲突，就换一条。
5. **【公认】级不当铁证。** 拿去写教程、说服别人之前先补出处。
