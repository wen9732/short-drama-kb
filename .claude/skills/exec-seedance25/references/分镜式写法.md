# 执行层·第二种默认写法：分镜镜头语义式（无时间戳）

> 导演提示词有两种默认写法。本页是第二种；第一种（叙事七段式、带时间戳）在 `../SKILL.md` 的「编译结构」。

## 两种怎么选
- **第一种·叙事七段式（带时间戳）**：有对白、讲剧情、要跨镜连续性和轴线的戏。时间戳用来分配节奏。
- **第二种·分镜镜头语义式（无时间戳，本页）**：视觉、质感、氛围主导的片子——TVC、产品/概念片、意象蒙太奇、无对白或弱对白、以微距和特写堆叠的段落。节奏靠镜头数量和推进描述，不靠秒。
- 拿不准：有对白、要剧情连续 → 第一种；只为看、为氛围 → 第二种。两者都守下面「仍要守的纪律」和执行层硬规则（`{}` 台词、不要字幕/BGM、正常人眼不发光、文字用参考图或后期、主体 1–8 个）。

## 骨架
- 用「镜头1 / 镜头2 / 镜头3…」列分镜，**不写时间戳、不分配秒数**。要强调某个瞬间短促，写「0.8 秒」「一瞬」「随即」这类词，不写时间码。
- 每个镜头一句到数句，按这个顺序写：**景别/机位 → 运镜 → 画面主体在干什么 → 质感与光影细节**。
- 参考素材**就近行内绑定**（「（蜘蛛设定图）」「场景参考」「主角长相发型参考」「主角服装参考」），不必单独起【人物与场景锁定】段；开头可用一句写素材职责（「场景参考只用作氛围」）。
- 光影、音效、禁止、风格可以在**结尾统一成块**写（【光影】【音效】【禁止】【风格】），不必逐镜重复。

## 这一派特有的写法（可借）
- **质感是主角**：皮肤纹理与毛孔、次表面散射（皮下透光）、硬质毛茸、水下变色、反光高光、玻璃折射光斑、体积光、运动模糊——把"看起来真"写细。
- **微距与极致特写推进**：从全景/中景一路推到微距（手、瞳孔、虫豸、液面），用推进本身做节奏。
- **参照物给尺度**：微小主体用「体长约量杯高度的 1/6」这类比例写死大小。
- **运镜连续**：手持摇晃、环绕、快速横移偷窥、强推，一镜到底或镜间强推。
- **一个贯穿物件穿线**：一只虫、一滴液、一道光，从一个镜头带到下一个，替代对白做连续性。
- **材质质量分层风场 ＋ 移动相对气流叠加（源自 `V03《特别的人》`）**：不写空泛的“微风吹拂”，而是按材质重量分层——轻薄头纱/发丝自由边缘先扬起飘向下风侧再回落，厚重缎面/大衣只在外缘低幅起伏且落回有重量；奔跑/骑行带来的迎面相对气流与横向自然风矢量叠加；飘落花瓣/雪粒按前中后景距离分层速度与清晰度，严禁像贴图一样同步飘动。
- **局部规则覆盖全局优先级（冲突仲裁句式，源自 `V03`）**：当全局写了“面部五官清晰”，但某镜刻意需要焦外柔焦氛围时，必须在总纲写明仲裁句——`镜04按时间线指定保留有意焦外人物层，该局部处理优先于全局面部清晰规则`，防止模型指令打架。
- **多套装与道具跨镜归属台账（源自 `V03`）**：20–30 秒多场景旅拍/时尚混剪若切换 2–3 套穿搭或道具，开篇按镜号列清归属表（如 `造型一用于镜01/06/08；造型二用于镜02–05/07；花束镜04左手持、镜07放车篮、镜08拿回`），镜内严禁串装。
- **商业精密饰品/美妆 TVC 允许顶部外貌与饰品细节保底锚定（【用户】实测成片确认，源自 `V04《光与风》`）**：多角色剧情短剧严禁把生图五官长句照搬进视频分镜以防 Token 稀释；但**商业珠宝、美甲、美妆、高定穿搭类 TVC**（单主体＋频繁 85mm/100mm 微距特写），**允许且推荐在每条顶部【人物与资产】保留精炼的妆容、美甲与饰品结构锚定段**（例如珍珠排列层级、受光面/暗面/体积珠光、美甲甲型与通透水光），配合参考图双重锁定微距一致性；纯自然情绪转场空境可单列 4–6 秒逆光叶脉透光＋溪流高光扩散＋奶油化圆形散景段落。

## 仍要守的纪律（别继承 TVC 原稿的毛病）
- **运镜写机制，不写导演名**：别只写「希区柯克运镜」，写出机制（极致特写锁定、推近压迫、主观偷窥，允许单写精准 `rack focus / push in / macro` 并附中文起止轨）。导演出处归 `cam-director`。
- **风格写画面，不堆参数**：允许单用精准光学/胶片词（如 `anamorphic / Kodak Vision3 500T / skip-bleach`）立质感，禁止盲目堆砌无指向静态词（`8K、masterpiece、UE5、render`）或中英双写复读。借用的视觉归 `genre-` 层。
- **"不是X、像Y"不写进台词**；台词仍按硬规则用 `{}`。
- 一段里别把两版时长的总纲拼在一起；一场只维护一个定稿。
- 每段仍**自成一体**：不写「下一段」「同上一段」。
