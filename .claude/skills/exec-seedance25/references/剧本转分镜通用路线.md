# 剧本转 AI 视频分镜｜常规通用版设计调用路线（Seedance 2.5 适配）

> **定位：** 面向豆包 Seedance 2.5 的**常规默认起手式**——用「自然语言 + 导演思维」把完整剧本直接转译为可生成的分组视频提示词；同时内置**按信号自动增强路由**，当剧本或用户要求命中特定强化方向（如情绪化导演、打斗、复杂运镜、TVC、特定题材案例）时，自动挂载对应专家库与案例写法，不命中时不额外读重库。
> **与本库其他文件的关系：** 执行铁律见 `../SKILL.md`；完整深度调度见 `导演语法.md`；无对白质感片见 `分镜式写法.md`；本文件定义从「收到剧本」到「交付提示词」的常规工作流与自动增强开关。

---

## 一、触发与前置确认（Phase 0 · 收到剧本先拦这两件事）

### 1. 识别输入成色（只改分镜，不越权写剧本）
- **完整剧本（含场次、人物、动作、对白）：** 自动切入本路线。
- **只有大纲/想法（无具体动作与对白）：** 停下指出“缺可拍动作和台词，镜头落不下去”，让用户选：① 回 `工位/编剧.md` 补全剧本；② 授权按大纲代补动作与对白（补写部分须显式标注）。
- **明显情绪断点或多人灾难（如冷漠秒变生死表白、4 人以上同框密聊）：** 反捧杀，直接点破会生成翻车，等用户拍板“硬补过渡镜”还是“回剧本先改”。

### 2. 上手双确认（缺一项问一句，不瞎猜）
1. **参考图映射（`@图N` 档案）：** 确认环境图 `@图1`、角色定妆 `@图2/@图3...`。没有也能拍，但要明说“无参考图人物一致性会掉”；有参考图则严格执行双轨隔离，五官穿搭只在【人物与场景锁定】绑定一次，分镜正文直接写人名。
2. **输出路线、影调预设与产线隔离：**
   - **全局影调前置定调（必做）：** 绝不直接复贴其他案例的【全局影像】，按本片情绪温度、媒介与真实光源查 `cam-shot/references/情境化全局影调与器材美学库.md` 锁定预设 **A–H** 之一，再改写为贴合本场光源的【全局影像与风格】。
   - **默认产线：** 真人实拍电影质感（禁写 `CG/3D/渲染`）+ 带整数秒切点（`0-3秒`）的叙事七段式。
   - 若明显是**无对白/纯视觉质感/产品广告**：提示可一键切到 `分镜式写法.md`（无时间戳）。
   - 若用户附带特殊设定（如“加点情绪化导演的克制感”“拍成港片动作”“用3A过场CG感”）：当场锁定对应**第四节增强路由**。

## 二、剧情快诊与抽象转译（Phase 1–2 · 导演思维先落位）

### 1. 简短剧情分析（控制 100–180 字，给用户看）
只写四行：**核心戏剧变化**（谁从 A 变成 B）→ **情绪曲线** → **本场建议切几组**（每组 10–15 秒，长剧本单批最多出 4 组防降质）→ **已激活的增强档（如有）**。

### 2. 双视角内部对齐（内部思考，不写进正文）
- **演员视点：** 角色此刻真正没说出口的潜台词，靠身体哪一处（手指、眼神停顿、喉结、肩颈、搅拌节奏差）漏出来？
- **观众视点：** 观众需要靠哪一镜的景别和声音才能看懂？两视角对不上，立刻加反应镜或换近景。

### 3. 抽象心理强制转译（绝不允许心理词直接进提示词）
凡剧本出现“内心崩溃、心动、决心、杀气、时间停滞”等拍不到的词，先按「身体微动作 + 物件状态变化 + 声场触发」拆成可见画面：
- *内心崩溃* → 桌下指节发白掐紧衣角 / 呼吸急促但脸面强装平静 / 环境嘈杂略沉
- *试探心动* → 抬头比对手晚半拍 / 手指无意识摩挲杯沿 / 吸管碰杯声透出
- *决断时刻* → 按熄烟头、合上书、放杯的动作标点近景（清脆拟音收拍）

## 三、自然语言情境节拍表与镜头硬底线（Phase 3）

按每一拍的**剧情任务**（查 `cam-director/references/导演库总表.md`）定出本组骨架。对外输出一张简洁的**【情绪节拍与镜头方案表】**（主镜头锁定 80% 核心视听组合；辅助镜头补充空间/反应/物件；快切镜头只作动作或节奏标点，但要素仍完整）。

**★ 转译为 Seedance 2.5 原生自然语言（防与其他软件规则打架）：**
1. **去掉英文卡标签与死板器材参数：** 不用 `f/1.8 / Dolly In / Zoom In / Cut In`；全部写成自然中文视听句，例如：`中长焦人文视角、极浅景深将背景柔化、缓慢稳步向前推进`；`200mm` 及以上长焦强制写清 `超大光圈、极浅景深、背景压成不可辨柔化色块`。
2. **严守幕后实体零入画铁律：** 不得写成“摄影机位于某人左后方”，一律转译为 `观察视角位于甲左后方肩侧，过甲右肩平视看向乙`；正文与【保护项】均禁出现 `摄影师/摄影机/相机/三脚架/无人机`。
3. **机位四要素自然写入句中：** 谁的哪一侧 + 观察高度（眼高/胸口/低角度）+ 朝向与主体部位 + 景别，杜绝“仰拍近景”四个字打发。
4. **A/B 两类构图红线：**
   - **B 类工程错（永不妥协）：** 物件穿头穿身、服装发型突变、道具水量/烟头长度前后打架、多余手部乱动 → 在【人物与场景锁定】或镜头描述正向写死（如`半杯余量始终不变`），高风险进【保护项】。
   - **A 类表达性构图（默认避开，仅情绪白名单解锁）：** 正面居中压中线（仅审讯对峙/仪式威严/精神异化）、头顶压边（仅被困压抑）、无眼神留白（仅凝视虚空）、断关节极微距（仅强调手眼局部）、强逆光黑剪影过曝（仅神性顿悟）。一旦启用，在表中写明解锁理由，不搞无理由破格。

## 四、★ 动态信号触发自动强化路由（常规版 → 按需自动加料）

日常保持轻装；只要**剧本内容**或**用户口头/附带设定**命中下表任一信号，**自动叠加对应专业技能，并按 `启动.md` 三档机制挂接案例库写法**（回复开头一行明示已激活模块与借鉴出处）：

| 触发信号（剧本特征 / 用户明确设定） | 自动升级加载 Skill（增强层） | 自动检索/推荐加强案例（`范例/`） |
|---|---|---|
| **普通对话 / 叙事过场 / 无特殊风格要求** | **只跑本路线（常规通用版）** + `导演语法.md`核心 + `导演库总表.md` + `切点速查.md` | **不读 `范例/`**，零负担快速直出 |
| **情绪化导演设定 / 克制哭戏 / 分手冷战 / 暗恋试探 / 非人微表情** | 自动切入/叠加 `perf-restrained/SKILL.md`（克制五拍、边缘漏情、非人AI微表情边界）+ `cam-shot/references/镜头配方.md` | 读 `范例/真人情绪表演/索引.md`（优先对齐 `B01《空枪》`、`K02–K08` 机制） |
| **爆发对峙 / 嘶吼吵架 / 脏话摊牌 / 韩黑压抑感** | 自动叠加 `perf-explosive/SKILL.md` + 按需 `genre-korean-noir/SKILL.md` | 读 `范例/真人情绪表演/索引.md`（列出 `B01/B02/C01` 供选或直接取机制） |
| **动作打斗 / 追逐逃亡 / 斗法超能力 / 巨兽破墙** | 自动叠加 `fight-combat/SKILL.md`（拆三镜、打击五件套、影视母题）+ `cam-shot/references/空间与调度.md` | 读 `范例/动作-打斗/索引.md`（按匹配列出 `A01–A06/G03/S03/S04` 供用户选定） |

## 五、分组切片（10–15s）＋ 段外跨组衔接台账（Phase 4）

AI 视频是逐组独立生成的，跨组最容易轴线翻转、服装突变、道具消失。但**提示词代码块内部绝不准出现“承接上一组/同上一段”**，解决办法是把台账留在**代码块外面**：

1. **组内五维核对：** 180° 轴线同侧、视线左右匹配、动作衔接保留 60–80%、关键道具连续、景别有梯级变化（不连切三镜同景别）；运镜按同向/反向/静切动/动切静/同质五选一，不乱炫技。
2. **组间【跨组衔接台账】（附在回复设计表内，不进生成提示词）：** 每组结束必须记录 8 项交接状态——`① 轴线侧与屏幕方向 ｜ ② 末镜景别与运镜余势 ｜ ③ 视线去向 ｜ ④ 人物姿态与站位 ｜ ⑤ 服装配饰实况 ｜ ⑥ 道具具体余量（如“半杯水、燃剩三分之一烟”）｜ ⑦ 光源色温与转场类型（同场景延续/跳秒/硬切）｜ ⑧ 出口→下组入口载体`。
3. **下组编译：** 下组提示词只在【镜头1】自然写出入口载体状态，并把⑤⑥锁死进【人物与场景锁定】，实现“组内自足、组间零漂移”。

## 六、编译前内部四问与标准交付格式（Phase 5）

**内部快检四问（不输出）：**
1. 本组每一镜都对应锚点表上的真实节拍吗？（为切而切直接删）
2. 抽象情绪都转成可见行为、物件、台词 `{}` 与纯世界内现场声了吗？
3. 是否通过「四删 Pass」（删双语重复、删生图外观长句、删不在场物体否定词、拆空泛形容词）＋ 幕后实体零入画 + 英文 WPM 估时核验？
4. 若是局部修改一镜，是否已完整回传当前整组？

**交付顺序（干净利落，不写水字数论文）：**
1. **导演判断与激活路线：** 2–4 句讲清戏核、默认走通用版还是已叠加哪几个增强模块/案例骨架（若替大纲补过戏、或删改过原镜，在此透明说明）。
2. **情绪节拍与情境方案表：** 含节拍、剧情任务、核心自然语言语法、出处与 A/B 雷区交代。
3. **站位轴线与跨组衔接台账：** 多组输出时给出站位与交接台账（**明确标出不复制到生成框**）。
4. **Seedance 2.5 分组提示词（代码块）：** 按 `../SKILL.md` 七段结构（开头总述 → 全局影像与风格 → 人物与场景锁定 → 镜头与表演原则 → 分镜 → 结尾与转场 → 保护项），单组控制在 `≤3000字`。
5. **翻车排雷与自审：** 点出最易崩的一镜和修法；运行 `python3 tools/check_errors.py 草稿 --script 剧本 --review` 后附 `自审：……`。
