# 导演语法 v3.1｜从一句想法到可拍的 Seedance 2.5 提示词

> 【用户】2026-10-28：给一句模糊的想法，导演自动补全情绪、镜头、运镜、构图、声音和分镜；下一个镜头怎么切、怎么运镜、怎么转场都提前规划好，保证整段的一致性和连续性。
> v3.1 推翻了 v3.0 的"每段首帧、尾帧、连续性锁"写法【用户】2026-10-28：那是把剪辑做成了首尾帧接龙，又把服装重复写了三遍。连续性来自导演设计：资产、站位、镜头表、切点。
> 来源：【官方】Seedance 2.5 发布页与提示词指南；【第三方】Higgsfield 等平台指南、用户提供的导演手册；【案例】只取机制，出处见第七节。

## 一、核心思维

1. **先导演，后提示词。** 提示词是导演方案的编译结果。没有想清楚这场戏改变了什么、观众从哪里得到信息，就不动笔。
2. **最小单位是"拍"（Beat），不是关键词。** 一拍＝一次状态变化。镜头是拍的容器，运镜是观众读取这一拍的方式，声音是触发或反馈。
3. **镜头是信息机制，不是装饰。** 每一镜、每一次运动、每一个前景都要回答：它让观众此刻看见了什么、看见了谁、改变了什么关系。
4. **举一反三，不背镜头名。** 遇到任何镜头说法（腿间框景、过腰、环绕、俯拍……），先拆出它背后的机制：前景在干什么、摄影机站在谁身边、信息在哪一刻改变、观看权最后交给谁。机制拆出来，就能换一个前景、换一个题材、换一个方向，自己长出新镜头。方法和示例见 `cam-shot` 的 `references/叙事运镜机制.md`。
5. **连续性靠设计，不靠锁帧。** 同一套参考素材、一份全局合同（站位、轴线、屏幕方向、道具归属）、一张整场镜头表、每个切点都有切的理由。这四样做到了，分几次生成也是一部片子。
6. **导演锁关键，模型补普通。** 关键接触、受力、道具交接、表演枢纽、台词、切点必须写清；普通走路、坐下、回头、身体协调交给模型，不写成关节说明书。
7. **篇幅以讲清为准。** 导演语境完整写出来，一段 1500–3000 字都可以；删空泛形容词，不删导演变量。【用户】

## 二、导演设计（写在回复里，给用户看）

按顺序做，复杂的戏每项都写，简单的戏可以合并：

1. **戏核与一句话方向：** 这场戏唯一的主要变化是什么——谁在什么处境里，因为什么，从 A 变成 B。观众看完带走什么。
2. **发散后选定：** 按发散协议想 2–3 条机制不同的拍法，选一条，其余一行带过。
3. **节奏曲线：** 建立 → 加压 → 枢纽 → 后果 → 余波。每一拍写：这一拍改变什么、谁触发、谁先反应、观众从哪个镜头读到。不平均切秒，有的拍短促，有的拍靠停顿撑住。
4. **站位图与轴线：** 人物在哪、朝哪、关系轴在哪、摄影机在轴线哪一侧、屏幕方向（谁从左往右）、主光从哪来、关键道具在谁手里或在哪。整场只定一次。
5. **素材合同：** 每份素材只担一个主职责，写清采用什么、不采用什么。需要什么参考图，交给美学图像工位出。
6. **整场镜头表**（核心交付）：

| 镜号 | 职责（这一镜为什么存在） | 景别｜焦段感｜机位（相对站位图） | 运镜：因为什么动 → 路线 → 停在哪 | 画面与表演（谁先动、谁的反应） | 声音 | 切点与切法（为什么此刻切、怎么切） |
|---|---|---|---|---|---|---|

- **切点理由**只有几种：动作完成或被打断、表演的决定出现、新信息进入、视线或声音或遮挡提供了连接、这一镜的职责已经完成。"每三秒切一次"不是理由。
- **切法**从 `cam-transitions` 选：硬切、在动作中切（动作匹配）、随视线切、前景遮挡、声音先进、甩镜、焦点交接……一个切点只选一种主接法，最多再加一个声音桥。
- **景别和机位要有变化的逻辑**：跳 1–2 级最顺，跳 3 级以上只用来强调；同机位换景别要跳够；关键反应出现时摄影机要落稳，留出可读的一拍。

7. **生成分组：** 把镜头表分组，一组就是一次生成，**默认 10–15 秒**（最稳），组里可以有多个镜头和切点；只有必须连续不断的段落才写到 20–30 秒。【用户】分组的边界放在**本来就要硬切的地方**（换角度、换空间、跳时间），不要放在一个连续动作的中间。

## 三、编译成提示词

按 `exec-seedance25` 的编译结构写：开头总述 → 【全局影像与风格】→ 【人物与场景锁定】→ 【镜头与表演原则】→ 【分镜】→ 【结尾与转场】→ 保护项。人物名只在锁定段绑定一次，之后直接写名字。要点：

- **每个镜头写导演变量：** 这一镜的职责、景别、机位（在谁的哪一侧、什么高度、看向哪里）、焦段感、运镜（触发、路线、速度变化、停止的条件）、前景在做什么、人物先后反应、声音 `<>`、台词 `{}`，结尾写切法。
- **运镜写成机制，不写名词：** 不写"迈克尔·贝环绕，很燃"，写摄影机从哪开始、绕哪个中心、每经过一个角度背景出现什么、在哪个新的剧情状态停下。
- **20–30 秒一组时**（少用）按阶段写"开始时 → 主要事件 → 结束时画面里能看到什么"【官方】；这是本组的剧情落点，不是逼着最后两秒静止。
- **组与组之间不写"承接上一段"的状态复述。** 下一组的开场照样按镜头表写它自己的机位和画面；连续性由全局合同和参考素材保证。
- **全局合同只写镜头之间必须一致、参考图又管不到的东西：** 站位、轴线、屏幕方向、道具在谁手里、主光方向、天气、声场。服装、发型、长相交给参考图，不重复。

## 四、跨生成的衔接

| 情况 | 做法 |
|---|---|
| 下一组换了角度、空间或时间（最常见） | **有动机的硬切**：镜头表里已经写了为什么切；守住轴线和屏幕方向，换景别或机位跳够，不需要复刻上一组的最后姿势 |
| 两组之间要做动作匹配、遮挡、声音桥 | 按 `cam-transitions` 把出口和入口成对设计：前一组在动作进行中或遮挡完成时退出，后一组从同一方向、同一动作阶段或同一声音进入 |
| 同一个镜头必须不断（一镜到底超过 30 秒、动作正在进行） | **延长任务**：等前一组生成完，看真实结尾，再写"向后延长"——接缝处人物位置、朝向、动作阶段、摄影机方向和速度、光和声音照实写。计划中的结尾不等于真实结尾 |
| 必须精确到某个构图、某个关键帧 | 首帧／首尾帧或宫格分镜、白模，作为专门工具用 |

失败信号：切点处人物换边、屏幕方向反了、道具换手、摄影机无缘无故换高度或方向、声音无原因断掉、下一组还没让观众认出主体就发动新高潮。

## 五、生成与验收

1. 复杂调度先出低分辨率样片，只看结构、动作、切点、运镜是否服务剧情。
2. 每组看：主要变化发生了没有；关键反应摄影机有没有落稳；切点理由能不能被看懂。
3. 把几组连起来看接缝：站位、方向、道具归属、光。哪组出问题只改那一组、改那一个变量。
4. 结果用 `记录：` 写进生成实验日志。

## 六、交付格式

导演判断（戏核、选了哪条路线、替用户补了什么）→ 本场配方 → 站位图与全局合同 → 整场镜头表 → 分组提示词（每组一个代码块）→ 风险（最可能崩的一镜和修法）。
