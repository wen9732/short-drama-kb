# 导演语法 v3.4｜从剧本到可拍的 Seedance 2.5 提示词

> 【用户】2026-10-28：导演自动补全情绪、镜头、运镜、构图、声音和分镜；下一个镜头怎么切、怎么运镜、怎么转场都提前规划好，保证整段的一致性和连续性。
> 输入是剧本（一般来自编剧工位）。用户明确说"跳过剧本、直接出提示词"时，输入可以是一段想法，导演判断里要写明替用户补了哪些剧情。
> 历次推翻：v3.1 取消"每段首帧、尾帧、连续性锁"；v3.3 取消"组间默认硬切"。原因见 `CHANGELOG.md`。
> 来源：【官方】Seedance 2.5 发布页与提示词指南；【第三方】Higgsfield 等平台指南、用户提供的导演手册、导演访谈与影评（见 `cam-director` 各条出处）；【案例】只取机制，出处见第七节。

## 一、核心思维

1. **先导演，后提示词。** 提示词是导演方案的编译结果。没想清楚这场戏改变了什么、观众从哪里得到信息，就不动笔。
2. **最小单位是"拍"（Beat），不是关键词。** 一拍＝一次状态变化。镜头是拍的容器，运镜是观众读取这一拍的方式，声音是触发或反馈。
3. **镜头是信息机制，不是装饰。** 每一镜、每一次运动、每一个前景都要回答：它让观众此刻看见了什么、看见了谁、改变了什么关系。
4. **用验证过的导演方案，举一反三，不背镜头名。** 按每一拍的剧情任务查 `cam-director` 的 `references/导演库总表.md`，看哪位导演用什么机制解决过同样的问题，再拆成机制改写到自己的戏里：换前景、换题材、换方向，自己长出新镜头。拆镜头的方法见 `cam-shot` 的 `references/叙事运镜机制.md`。
5. **接缝是导演设计的一半。** 两镜之间跨过去的是什么（声音、视线、动作、形状、光、焦点、黑暗、因果），观众在那一刀感觉到什么，和镜头本身同等重要。没有设计过的接缝，就是新手的硬切。
6. **连续性靠设计，不靠锁帧。** 同一套参考素材、一份全局合同（站位、轴线、屏幕方向、道具归属）、一张整场镜头表、每个接缝都有载体或断裂的理由。做到这四样，分几次生成也是一部片子。
7. **导演锁关键，模型补普通。** 关键接触、受力、道具交接、表演枢纽、台词、接缝必须写清；普通的走路、坐下、回头、身体协调交给模型，不写成关节说明书。
8. **篇幅以讲清为准。** 一段提示词 1500–3000 字都可以。删空泛形容词，不删导演变量。【用户】

## 二、导演设计（写在回复里，给用户看）

按顺序做。复杂的戏每项都写，简单的戏可以合并：

1. **戏核与一句话方向：** 这场戏唯一的主要变化是什么：谁在什么处境里，因为什么，从 A 变成 B；观众看完带走什么。输入是剧本时，剧情事实、人物关系和台词以剧本为准，不改写；觉得剧本有问题，单独提出，不在提示词里偷偷改。
2. **节奏曲线：** 建立 → 加压 → 枢纽 → 后果 → 余波。每一拍写清楚：这一拍改变什么、谁触发、谁先反应、观众从哪个镜头读到，以及它的**剧情任务**（揭示、内爆、两地相连……，即导演库总表第二节第一列）。不平均切秒，有的拍短促，有的拍靠停顿撑住。
3. **导演思维过一遍：** 按导演库总表第一节的问题过一遍，至少回答 M02（这是谁的戏）、M06（最静的一拍和释放在哪）、M13（全场唯一的高光手法放在哪）。
4. **发散后选定，写出导演出处：** 按发散协议想 2–3 条机制不同的拍法，每条按枢纽那一拍的任务，从导演库总表第二节找出处（例如"是枝的家常动作＋朴赞郁的空间叠合"），选一条，其余一行带过。主手法的数量与搭配按导演库总表第四节。
5. **站位图与轴线：** 人物在哪、朝哪，关系轴在哪，摄影机在轴线哪一侧，屏幕方向（谁从左往右），主光从哪来，关键道具在谁手里或在哪。整场只定一次。
6. **素材合同：** 每份素材只担一个主职责，写清采用什么、不采用什么。需要参考图就交给美学图像工位出。
7. **整场镜头表（核心交付）：**

| 镜号 | 职责（这一镜为什么存在） | 景别｜焦段感｜机位（相对站位图） | 运镜：因为什么动 → 路线 → 停在哪 | 画面与表演（谁先动、谁的反应） | 声音 | 接缝：载体 → 观众的感觉 → 接法编号（出处） |
|---|---|---|---|---|---|---|

- **切点理由**只有几种：动作完成或被打断、表演里出现了决定、新信息进入、视线或声音或遮挡提供了连接、这一镜的职责已经完成。"每三秒切一次"不是理由。
- **接法**按第四节设计。每一类在哪一刻切、后镜第一个动作是什么，查 `cam-transitions` 的 `references/切点速查.md`。一个切点只选一种主接法，最多再加一个声音桥。
- **景别和机位的变化要有逻辑**：跳一到两级最顺，跳三级以上只用来强调；同机位换景别要跳够；关键反应出现时摄影机要落稳，留出可读的一拍。

8. **接缝表与分组（一起定，定完互相复查）：**
   - 先把整场接缝单独列一遍，标出主接缝、支撑接缝、冲击接缝（第四节第 2 条）。
   - 再分组：一组就是一次生成，**默认 10–15 秒**（最稳），组里可以有多个镜头和接缝；只有必须连续不断的段落才写到 20–30 秒。【用户】组的边界不放在连续动作的中间，优先放在跨生成稳定的接缝上（第四节第 3 条）。主接缝尽量留在组内，让模型一次生成两边。
   - 分完组回头复查：落在组边界上的接缝如果是"风险高"的那一档，就挪边界或换接法。

## 三、编译成提示词

按 `exec-seedance25` 的编译结构写：开头总述 → 【全局影像与风格】→ 【人物与场景锁定】→ 【镜头与表演原则】→ 【分镜】→ 【结尾与转场】→ 保护项。要点：

- **每个镜头写导演变量：** 这一镜的职责、景别、机位（在谁的哪一侧、什么高度、看向哪里）、焦段感、运镜（触发、路线、速度变化、停止的条件）、前景在做什么、人物先后反应、声音（用自然句写声源、远近、何时进来）、台词 `{}`，结尾写接法。
- **运镜写成机制，不写名词或导演名：** 不写"迈克尔·贝环绕，很燃"，写摄影机从哪开始、绕哪个中心、每经过一个角度背景出现什么、在哪个新的剧情状态停下。导演名只出现在给用户看的导演判断和接缝表里。
- **【结尾与转场】写出口：** 跨过去的载体是什么，它在画面里最后是什么状态（在哪个位置、多大、往哪个方向动、声音延续还是戛然而止）。下一组镜头 1 的开头写对应的入口。出口入口的配对只写进接缝表，提示词里不写下一段（见执行层编译结构第 6 条）。最后一组写全片怎么收。
- **20–30 秒一组时**（少用），按阶段写"开始时 → 主要事件 → 结束时画面里能看到什么"【官方】。这是本组的剧情落点，不是要求最后两秒静止。
- **组与组之间不写"承接上一段"的状态复述。** 入口只写接缝需要的那一个载体，其余照镜头表写；连续性由全局合同和参考素材保证。
- **全局合同只写镜头之间必须一致、参考图又管不到的东西：** 站位、轴线、屏幕方向、道具在谁手里、主光方向、天气、声场。服装、发型、长相交给参考图，不重复。

## 四、接缝设计（每个切点都做，组与组之间尤其要做）

### 1. 三问
1. **什么东西跨过这一刀（载体）？** 声音、视线、动作、形状、颜色、颗粒、光、焦点、黑暗或遮挡、时间证据、因果。如果什么都不跨，就是一次有意的断裂，要写出为什么要断。
2. **观众在这一刀该感觉到什么？**

| 感觉 | 接法（编号见 `cam-transitions`） | 导演出处（见 `cam-director`） |
|---|---|---|
| 看不见切，同一时空继续 | T01 动作匹配、T03 视线、T05 遮挡、T06 甩镜、T19 隐藏剪辑长镜 | HW11 斯皮尔伯格、HW14 伊纳里图、HW21 门德斯、JP07 黑泽明（在运动上切） |
| 联想：两个时空因为一样东西连起来 | T02 形状、T15 意义、T28 色彩、T32 构图、T22 空间叠合 | JP02 岩井粒子、HW10 诺兰跨层因果、KR01 和 KR03 朴赞郁 |
| 冲击：断裂、真相、暴力 | T33 硬切重音、T31 静默、T07 闪白 | JP08 北野武、HW05 迈克尔·贝、JP10 黑泽清 |
| 时间过去了 | T24 同机位时间流逝、T25 跳切、T17 叠化、T20 空镜 | JP06 小津、KR07 李沧东、JP03 岩井、CN06 贾樟柯 |
| 沉一下，让情绪落地 | T20 空镜、T16 L 剪（声音留下）、T29 焦点接力 | JP06 小津、JP05 是枝、KR02 朴赞郁、HW19 维伦纽瓦 |
| 两地同时发生 | T23 交叉蒙太奇、T16 J 剪（声音先到）、T22 | HW08 和 HW09 诺兰、KR01 朴赞郁 |

3. **谁发起？** 前一镜的出口发起：动作带走，或声音留下（L 剪）。或者后一镜的入口发起：声音先到（J 剪），或新信息闯进来。

### 2. 整场接缝的配比
- **一个主接缝：** 放在情绪枢纽上，是整场最有设计感的一刀，出处从导演库里找。
- **其余是支撑接缝：** 观众感觉不到的有动机的切（动作、视线、遮挡、声音）。
- **冲击接缝最多一个，** 留给真正的断裂。
- 剂量上限见 `cam-transitions` 剂量表。
- **失败信号：** 整场的接缝都是同一种（全是硬切、全是叠化）；主接缝不在情绪枢纽上；硬切的理由只写了"换个角度"。

### 3. 跨两次生成怎么接
模型一次生成只看得见一边，所以组与组之间的接缝要**成对写**：前一组的【结尾与转场】写出口，后一组的镜头 1 写入口，两边对着同一个载体。按跨生成时的稳定程度排：

| 稳定度 | 接法 | 前一组出口 | 后一组入口 |
|---|---|---|---|
| 最稳 | 经过一个"没有特征的状态"：全黑遮挡（T05、T19）、全白（T07）、完全虚焦（T29）、颗粒占满画面（JP02）、物体挡满画面（HW21） | 摄影机掠过暗墙；车灯迎面照满画面；焦点完全化开；颗粒占满画面中段；一列人从镜头前横穿 | 从同一个状态里出来，运动方向和速度一致 |
| 稳 | 声音桥（T16） | L 剪：写清楚声音延续到结尾 | J 剪：开场就是那个声音的源头。精确的提前量交给剪辑（执行方式 D） |
| 要对位 | 形状、色彩、构图匹配（T02、T28、T32），空间叠合（T22） | 落幅写清楚形状在画面的哪个位置、多大 | 同一位置、同样大小起幅；要精确就用首帧（执行方式 B） |
| 风险高 | 跨组的动作匹配（T01） | 动作做到一半 | 换新角度把动作做完。最好放在组内；或者等前一组的真实结尾出来，再写延长 |

**有动机的硬切**仍然是选项：换角度不需要载体、要的就是断裂感的时候用。它在接缝表里必须写出理由，并且要守住轴线和屏幕方向，景别或机位跳够。

### 4. 必须无缝或必须精确时

| 情况 | 做法 |
|---|---|
| 同一个镜头不能断（一镜到底超过 30 秒、动作正在进行） | **延长任务**：等前一组生成完，看真实结尾，再写"向后延长"。接缝处人物的位置、朝向、动作阶段、摄影机方向和速度、光和声音照实写。计划中的结尾不等于真实结尾 |
| 必须精确到某个构图、某个关键帧 | 首帧／首尾帧、宫格分镜或白模，作为专门工具使用 |

失败信号：
- 切点处人物换了边，屏幕方向反了；
- 道具换了手；
- 摄影机无缘无故换了高度或方向；
- 声音无原因断掉；
- 出口和入口对的不是同一个载体；
- 下一组还没让观众认出主体，就发动新的高潮。

## 五、生成与验收

1. 复杂调度先出低分辨率样片，只看结构、动作、接缝、运镜是否服务剧情。
2. 每组看三件事：主要变化发生了没有；关键反应出现时摄影机有没有落稳；接缝的载体在画面里出现了没有。
3. 把几组连起来看接缝：站位、方向、道具归属、光；出口和入口的载体对不对得上。哪组出问题，只改那一组、那一个变量。
4. 用户要求记录时，用 `记录：` 写进生成实验日志；用户说"只是测试、不记录"就不写。

## 六、交付格式

1. **导演判断**（几句）：戏核、视角、选了哪条路线、导演出处、替用户补了什么。
2. **本场配方。**
3. **设计表**（表格，不写成论文）：站位图与全局合同、整场镜头表、接缝表。
4. **分组提示词**，每组一个代码块。
5. **风险**：最可能崩的一镜、最可能接不上的一个接缝，各自的修法。

只有一组、两三个镜头的小戏，第 3 项可以压成一张镜头表。

## 七、写法借鉴出处（只取机制）

| 机制 | 出处 |
|---|---|
| 一次生成里写多个分镜，每镜写清机位相对站位在哪、怎么动、焦点追谁；站位和唯一道具的位置写死 | D01《反相之地》第 8 集 |
| 镜头表单列"切镜过渡"一栏 | S01《新数码宝贝》 |
| 多人站位用方位锁定 | G01《封神》 |
| 分区写法（全局风格、角色、地点、开场站位、逐镜、光学、摄影、声音）；"两人始终不换边"；屏幕方向全程固定 | 【第三方】Higgsfield 指南 |
| 长段按"开始时、主要事件、结束时"；素材"只采用、不采用"；延长与首尾帧的写法 | 【官方】2.5 提示词指南 |
| 拍、节奏曲线、切点理由、模型自治与导演锁定的分界 | 【第三方】用户提供的导演手册 |
| 导演思维与手法的出处（50 条手法、15 条思维） | `cam-director` |
