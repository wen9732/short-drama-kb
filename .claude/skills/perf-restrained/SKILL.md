# 表演层·克制型

## 边界
- **负责：** 克制型情绪表演——微表情、情绪五拍、听者表演、台词处理（重音/尾音/断点）、情绪天花板、余波。
- **不负责：** 故事机制与台词内容（→ `script-`）、视觉质感（→ `genre-`）、平台格式（→ `exec-seedance25`）。下方"编剧层面的高级手法""镜头与剪辑"两节为暂存，剧本库、运镜库建成后迁出。
- **互斥：** `perf-explosive`（同一时间段只能用一种）。
- **常搭配：** 任意 `genre-`；需要韩国写实质感时搭 `genre-korean-noir`。

## 一句话原则
**AI 感来自"表达情绪"；真人感来自"压住情绪，但压不住"。**
不写"她很伤心"，写她怎样努力不让伤心出现，以及从哪里漏了出来。

## AI 感的 8 个来源与对策
| AI 感 | 真人做法 | 写法示例 |
|---|---|---|
| 情绪是贴上去的 | 先压，再泄露 | 嘴角努力维持浅笑，但笑意不到达眼睛 |
| 全脸同时变 | 有先后、不对称 | 一侧嘴角略早抬起；目光先改变方向，头部紧接着小幅跟随 |
| 情绪一条直线 | 被对方的某个词触发 | 她听完最后三个字，鼻翼快速翕动一次 |
| 听者像木头 | 听也是演 | 嘴唇张开想插话，又咽回去，始终插不进话 |
| 台词朗读腔 | 有重音、卡壳、抢话、吞字 | 三遍 "I'm not" 三种处理；"sai—" 未说完被接走 |
| 动作是装饰 | 每个动作有功能 | 低头喝粥是为了给自己找一个掩饰情绪的动作 |
| 说完就结束 | 情绪有尾巴 | 说完才发现伤到了人的后怕；结尾 2–3 秒无对白余波 |
| 越激动越好 | 有天花板 | 不要让他哭出来；冷比响更伤人 |

## 核心公式：情绪五拍
每个情绪节拍按此顺序写：

**触发 → 泄露 → 压制 → 台词处理 → 余波**

| 拍 | 写什么 | 例（"有啊，你占了一大半"） |
|---|---|---|
| 触发 | 对方哪句话、哪个词 | 听完女主的指责 |
| 泄露 | 不自觉的边缘部位变化 | 原有浅笑消失，垂下眼帘 |
| 压制 | 用身体盖住 | 低头看地面，喉结滚动一次，下颌略绷紧 |
| 台词处理 | 重音、尾音、断点、气口 | "有啊"尾音微扬装不在意；"你占了一大半"音调降低 |
| 余波 | 说完后残留什么 | 笑容只撑一瞬没展开，眼睛没有笑意 |

**泄露写在脸的边缘部位**：下眼睑、鼻翼、喉结、下颌、嘴角、手指。眉毛和嘴巴的大动作模型最容易演过火。

## 8 个技巧
1. **写被咽回去的那句话**："上唇压向下唇，喉结滑动一次，那是把'我错了吗'咽回去的动作。"
2. **台词与脸说相反的话**：表面"嗯，超赞"，脸上是心碎。
3. **把变化绑在具体词上**：哪个词加重、哪个词触发反应、哪个词收尾。
4. **给手一件事做**：攥抹布、绞紧抹布、按住胃、扶碗沿、悬在半空的手。手比脸更难控制，所以更真。
5. **施压的一方也用生活动作**：争吵里反击、指责的一方，用抿嘴、摸鼻、叉腰、摊手、短促吐气推进情绪，不咆哮、不大幅挥臂。【用户】画布1评语
6. **点名禁止具体套路**："禁止偶像剧式慢推/绿茶式表演/瞪眼咆哮式表情/泪流满面式表演"，而非笼统"不要夸张"。
7. **一次触发只开一个主反应通道，最多再加一个辅助通道**：看见异常先动的是聚焦，被一句话击中先断的是呼吸或语流，身体受威胁先变的是重心。眼、眉、嘴、肩、手同时启动是最重的 AI 味。反应慢要写因果（"她先看见他步子变短，确认不对，才顺着他的视线转头"），不写万能的"慢半拍"；不按秒数安排眨眼。【第三方：用户提供的导演手册】
8. **写情绪天花板**："眼眶泛红但不落泪""音量控制住，不喊破"。
9. **非人/AI/仿生机器人角色的微表情边界法（刚性克制）**：拍觉醒前的仿生人、AI 宿主或神性傀儡时，用**"动极小一格＋焊死绝对边界"**制造非人精密感——例：`上眼皮微动半毫米但全程绝不眨眼`、`嘴角极轻微上扬但不是人类微笑`、`双唇微张一条细缝但不露齿`、`眼球平缓转向目标后定住，面部其余肌肉无任何连带形变`。【经验：S04《元启录》】

## 编剧层面的高级手法（暂存，剧本库建成后迁出）
- **道具贯穿情绪弧线**：同一道具在不同场次改变含义（粥：被嫌弃的养胃粥 → 盛进别人碗里 → "嗯，超赞"）。写明道具在每段结尾的状态。
- **反派去恶意化**：第三者越坦荡大方，主角越疼。
- **最轻的台词放在最重的位置**："好""挺好的""嗯，超赞"。
- **不接招的温柔**：一方用尽全力划界限，另一方用一句日常化解（"知道，天气预报有雨"）。
- **同机位冷暖切换**：现实冷色/回忆暖色在同一构图内硬切，空间位置完全重合，只有光色和人物关系变。

## 镜头与剪辑（暂存，运镜库建成后迁出）
- 反应镜头比说话镜头值钱：说话者用画外音延续，镜头给听者。
- 结尾留 2.5–3 秒无台词情绪余波，写明"镜头停住，不许提前切"。【用户】画布1评语：这是该模板最对的设计
- 有台词的镜头至少 1.5–2 秒；不出现 0.6 秒这类演不完的镜头。
- 以近景、过肩正反打、面部特写为主；禁止炫技运镜和慢动作。

## 示范：AI 感 → 演员级
AI 感：
> 女主听到男主说"我们分手吧"，十分震惊和伤心，眼泪流了下来，难过地说："为什么？"

演员级：
```
男主说完"我们分手吧"。女主正在剥橘子的手停住，没有抬头。
她先把剥了一半的橘子放回桌上，指尖在橘子皮上停了一下，像是没听清，又像是在等他收回这句话。
下眼睑先微微收紧，鼻翼快速翕动一次，嘴唇抿住，下巴绷紧，没有立刻哭。
她抬眼看他，视线只停留一瞬就移向他的肩膀外侧。
女主用中文说，声音很轻，语速平稳，"为什么"尾音下沉不上扬：{为什么。}
说完后她低头继续剥那半个橘子，手指用力过度，橘子汁溅到手背上。眼眶这才开始泛红，泪水蓄在下眼睑，不落下。
人物为正常人眼，不发光。禁止瞪眼、张嘴愣住、捂嘴、泪流满面式表演。
```
"伤心"一词一次都没出现。
