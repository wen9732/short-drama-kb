# 动作语言｜角色到底怎么打（fight-combat 参考，按需读）

> 来源：用户《真人/CG 高燃打斗导演·动作强化版 v2》第 8A 节，去英文术语、去重后整理。【用户】
> 用法：先选体系，再把招式编译成可见路径。专业名只是消歧义的锚点，**每个节拍最多留一两个，并立刻补上身体路径**。

## 一、任何一招都按这条链编译
`动作体系 → 起始距离与支点 → 身体或武器走的路径 → 打哪里／封哪条线 → 碰到、被截、擦过还是避开 → 对方的受力、反震或失衡 → 新的距离、角度、攻击权或伤势`

只有"攻击、格挡、反击、挥剑、快速拼刀、猛烈打斗"而没有上面这条链，算没设计完。名字和路径冲突时，以路径为准。

## 二、选体系：一个主体系，最多叠一个辅助

| 类型 | 核心动作 | 观众主要看什么 |
|---|---|---|
| 拳击 | 刺拳、后手直拳、摆拳、上勾拳、侧闪、下潜摆头、轴转步 | 拳路、肩髋传力、头部移动、角度变化 |
| 泰拳 | 扫踢、正蹬、肘、膝、箍颈、扫绊 | 中距腿法 → 近距肘膝，距离被压缩 |
| 散打 | 直拳组合、侧踹、鞭腿、迎击、打转摔 | 拳腿进入、快速换距、站立打击接摔 |
| 摔跤/柔道 | 缠抱、下潜、抱躯干、绊、投、破平衡 | 谁控制谁、重心怎么被破、往哪摔、落在哪 |
| 地面控制 | 防守位、侧压、骑乘、拿背、翻滚争位 | 谁在上、谁控制躯干、位置怎么翻转 |
| 中国剑术 | 点、刺、劈、挂、撩、云、抹、截、格、带 | 剑尖与刃线、腕肘肩协调、短促改线、攻防同势 |
| 中国刀术 | 劈、砍、斩、撩、扫、格、缠裹、反撩 | 单刃大弧、腰胯驱动、惯性与回收 |
| 枪矛 | 扎、刺、拦、拿、缠、挑、扫、崩 | 枪尖目标、长兵器的工作距离、前后手握距 |
| 棍术 | 劈、扫、戳、崩、拨、压、架、抡 | 两端都是威胁、握点转换、借反震换向 |
| 重兵器 | 过顶劈、斜劈、横扫、硬架、拖回 | 支点、出手后不能瞬间改向、制动与地面承压 |
| 双持/短兵 | 前手试探、交叉切、拨挡还击、交替压迫 | 主副手分工、两条攻击线，不许双手同步乱挥 |
| 仙侠/异能 | 真实武术骨架＋爆发换位、踏空、瞬移、自由飞行 | 位移改变空间优势，实体动作完成接触，特效解释力量 |

别把拳击、剑术、轻功、摔投、飞行全混成"万能高手动作"。

## 三、几类体系的要点

**徒手短打**
- 刺拳：前手走最短直线，肩轻送，碰到即收；用来抢节奏、测距、逼对方先动。
- 后手直拳：后脚蹬地，髋肩一起转入，后手沿中线直进；对方头肩沿力的方向后移，攻击者借余势压近或转步改角度。
- 摆拳：肩髋同转，拳走短横弧；对方头肩先横偏，再带动上身失衡。不是手臂单独抡圆。
- 上勾拳：重心先短降，腿髋向上放，拳走近身上升弧；对方头肩或胸口被抬起、重心断开，不默认把人垂直打飞。
- 侧闪：头肩短距离离开直线，脚基本不动；来拳从原位置旁掠过，闪完自然有反击角度。
- 轴转步：一脚做轴，另一脚换朝向；位置变化小，攻击线变化大。专治"两人永远正面对砍"。
- 组合优先"抢线 → 逼出防守 → 改角度 → 重击或摔 → 受力"，不是连续随机拳脚。

**泰拳与散打的距离转换**
- 泰拳：中距离用扫踢和正蹬立威胁，距离一短就换短拳、肘、膝或箍颈。扫踢要看得见支撑脚和髋的转动，整条腿横向扫入。
- 散打：腿法断距或改距 → 拳组合逼近 → 进入近身 → 控制与重心变化 → 一次明确的摔。摔不是"碰一下自动飞出去"。

**摔投与地面**
`进入控制距离 → 建立对上身、躯干或腿的控制 → 对方支撑或重心被破 → 投摔方向明确 → 落点明确 → 谁在上、谁在下、谁脱离`

**剑（剑不是光棒）**
- 刺：剑尖沿明确直线进，身体和前脚一起推；对方必须截、侧移或后撤，不能等剑停了再反应。
- 劈：肩背和躯干带剑走纵向或斜向大弧；被挡有反震，余势进入下一次换线。
- 撩：从低位沿上升斜线进，用来夺回中线或逼开对方兵器。
- 挂、带：剑身贴着对方兵器侧面改它的线，重点是"借接触改线"，不是硬碰停死。
- 点：剑尖短促地打具体目标或来剑侧面，接触极短，用来打断节奏。
- 截：对方攻击还没完成就切进它的路径。
- 云剑：剑绕身体或头肩走圆弧，用来换线、护身、衔接，不写成没有目标的花式旋转。
- 连续攻防：`试探抢线 → 对方改线 → 第一次相接 → 借反震换位 → 一次明确的刺或劈 → 闪或截 → 新距离`。上一剑的余势就是下一剑的起点。

**刀**：腰胯驱动、大的切削弧、有惯性。被截后不能瞬间违反惯性反向，要经过回收、转体、换步或借反震。

**枪矛（先锁枪尖，再锁身体）**
- 扎刺：前后手共同控杆，枪尖走直线，身体推进方向和枪尖目标一致。
- 拦拿：用杆身侧向接触改来兵的线，一侧封住，另一侧立刻有反击通道。
- 缠：两件长兵已经相接时用连续圆弧争中线，不许隔空画圈。
- 挑：由低向高挑开对方兵器或上身。扫：横向大弧，必须给完整路径和制动空间。
- 太近时别假装枪尖还管用：退步拉距、换握、用杆身或尾端。长兵器默认用中景到中全景，保住枪尖可读。

**棍**：不只有横扫。被挡后可借反震直接转另一端打；换握发生在余势允许的时机。

**重兵器**：一旦进入主弧，身体对路径做出承诺：脚下支点 → 腿髋 → 躯干 → 肩背 → 武器头。打空时武器沿原弧继续并砸出地面或环境结果，回收慢，给对方留反击窗口。

**双持**：主手负责主攻击线，副手负责截线、短补、控空隙或第二威胁；攻击权变了可以交换分工。

## 四、防守不是"刻意格挡"：七种

| 防守 | 怎么回事 |
|---|---|
| 拨挡 | 短接触改掉攻击线，自己的动作余势保留 |
| 偏转 | 借角度让来力擦过，不正面扛全部力量 |
| 截击 | 在对方攻击完成前先占住线路 |
| 硬架 | 躲不开时立支点硬吃，身体和器物必须出现压缩和后移 |
| 闪避 | 让目标离开攻击线，攻击本身从原位置掠过 |
| 卸力 | 顺着来力移动或转体，把力带向侧面，再借对方余势夺权 |
| 兵刃黏接 | 兵器已相接后短暂争线，随后必须有人脱离或改角度 |

"顺势而上"的写法：对方攻击进入 → 不后退等招，用偏转、卸力或截线让它擦过 → 身体同步进入新的攻击角度 → 上一次接触的反震或余势直接成为反击的启动。

## 五、高速位移和战斗的接口
高速移动不能代替攻击动作。先分清是哪一种：

| 位移 | 要写清 | 纪律 |
|---|---|---|
| 连续高速跑 | 起点、启动、路径、转向依据、制动、终点 | 身体和环境都要有速度证据 |
| 轻功借力 | 借力点、长弧跨越、轻落 | 不等于自由飞行；重新进入有效距离后才出兵器 |
| 自由飞行 | 高度层、行进方向、身体朝向、武器工作距离 | 行进方向可以和身体朝向不同（面对对手侧向平移） |
| 爆发换位 | 从 A 到 B，只负责改攻击角度 | 到 B 后必须有一次实体或能力动作兑现这个优势 |
| 真瞬移 | 消失点、出现点、朝向、姿态、速度是否继承 | 不伪造中间飞行轨迹；也不用闪烁剪辑冒充 |

- 残影只证明原位置和速度，真身必须在新位置被明确重新看到。
- 高速转向：连续飞行用弧形倾转或"急停 → 重新定向 → 再爆发"。
- 被撞后从竖直下坠无因变成水平横飞是错的；方向改变要有碰撞面、主动能力或反弹来源。
- 御剑：分清站剑、踏剑滑行、人剑分离；脚下的剑和手里的剑是不是同一把必须写明。

## 六、专业词怎么进提示词
- **错：** 女剑客使用点剑、挂剑、云剑、撩剑、截剑高速连招。
- **对：** 女剑客先以短促的点剑抢进来剑侧面，把对方的斩击拨离胸前；她不后撤，顺着兵刃的反震向外侧滑出一步，剑身从低位上升一记撩剑逼开对方的重剑，随即沿打开的中线直刺对方右肩。
- **验收：** 删掉专业名，单看路径仍然懂"谁打谁、怎么应、哪里碰到、攻击权为什么变了"；留着专业名，风格和武器用法更准。
- 英文招式名（Jab、Hook 这类）只当内部查询词，不进提示词。
