# 高能写法｜动画与仙侠（fight-combat 参考，按需读）

> 每条 = **出处事实 → 机制 → 可直接改写的句式**。作品名、导演名只在"出处"里，**不进提示词**；句式里的〔〕换成本场事实；句式不带拟声词和比喻。
> 证据等级：【已核】＝联网读到制作方或专业媒体原文；【公认】＝影评与观众普遍认可，没找到制作方原文；【推断】＝按成片特征归纳，待实测。【2026-11-11 联网】

## 一、咒术式近战与大场面（出处：日漫《咒术回战》）

| 编号 | 出处事实 | 机制 |
|---|---|---|
| JJ-01【已核】 | 剧场版战斗段原计划只有两三个三维镜头，导演要求"一直在动"后大量增加；背景贴到三维模型上，摄影机才能大幅运动 | **空间是立体的，摄影机可以绕着打斗走** |
| JJ-02【已核】 | 三维组把构图改宽以增加纵深和冲击力；有的镜头从贴近起、再拉开 | **贴近起幅 → 拉开见全貌**：先给冲击，再给空间 |
| JJ-03【已核】 | 三维组主动提出"向前推进并加纵深"的运镜 | **沿冲击方向推进** |
| JJ-04【公认】 | 第二季大战段落整集压成灰、白、黑，只留红色鲜艳；战斗时出现上下黑边，破坏结束后黑边消失 | **色彩和画幅当开关**：进入"领域级"战斗时世界变色 |
| JJ-05【公认】 | 从细节丰富的城市背景突然切进纯白空间，作为毁灭之后的静 | **满 → 空的反差**给高强度段落一个喘息点 |
| JJ-06【公认】 | 浅景深把暗色楼群虚掉，突出前景物件；一片碎玻璃自己烧成一团小火 | **前景小物件承接大招的余波** |
| JJ-07【公认】 | 强者用俯视和宽景表现支配，弱者用紧构图表现被困 | **景别跟着强弱关系走** |

**句式**
- JJ-01/02：`镜头贴在〔A〕的拳头旁起幅，拳击中〔B〕腹部的同时镜头沿受力方向急速后拉，拉成全景：〔B〕倒飞着撞穿〔两根水泥柱〕，〔整条地下通道〕的纵深在画面里展开。`
- JJ-03：`摄影机贴着地面沿〔A〕的冲刺方向向前推进，两侧的〔立柱和广告灯箱〕以很快的速度向后掠过，尽头的〔B〕在画面中心越来越大。`
- JJ-04：`〔A〕双手结印的一瞬，画面上下收进两条黑边，环境的颜色褪成灰白，只有〔血迹和他眼角的纹路〕保持鲜红。`
- JJ-05：`爆炸的强光吞没整个画面后，光没有散去，直接变成一片没有任何物体的纯白空间；两人相隔〔十步〕站在白色里，只听得见各自的呼吸。`

## 二、体术快攻（出处：日漫《火影忍者》）

| 编号 | 出处事实 | 机制 |
|---|---|---|
| NR-01【已核】 | 把场地做成三维，手绘人物放进去，摄影机得以环绕；有一段是人物原地跑、背景向后退 | **背景动得比人多**：靠环境的相对运动卖速度 |
| NR-02【已核】 | 人物摆出扭曲夸张的姿势，四肢拉长并强透视 | **强透视的肢体**：冲向镜头的拳脚放大 |
| NR-03【已核】 | 特写是动作的"重置点"，用来把连续动作断开再起 | **特写用来换气**：一个眼神之后接下一轮 |
| NR-04【已核】 | 快速移动时脸和眼睛像橡皮一样被拉长；挨拳的脸按"水球高速落地"变形 | **速度靠形变，不靠细节** |
| NR-05【已核】 | 用地下涌出的大水和蒸汽来增强速度感 | **借环境流体给速度做参照** |
| NR-06【已核】 | 一个人绕着愣住的对手高速穿梭，用模糊引导视线 | **快的人绕着慢的人**：强弱差一眼可见 |

**句式**
- NR-01：`低机位侧跟。〔A〕贴地疾跑，身体在画面里的位置几乎不变，身后的〔林木和碎石〕连成横向的流线向后飞退。`
- NR-02：`〔A〕的右脚正对镜头踢来，脚底在画面前景迅速放大到占去三分之一，身体在后方因强透视而缩小。`
- NR-03：`两人各自滑退〔三步〕拉开。近景，〔A〕抬起眼，喘了一口气，重心重新压低——下一瞬他再次扑入对方的内线。`
- NR-06：`〔B〕站在原地转头寻找，〔A〕的身影在他左侧、身后、右上方接连闪现，每个位置只留下一道带方向的残影和被踩起的尘土；〔B〕的头始终慢一步。`

> AI 视频提醒：NR-04 的夸张形变在真人或写实 CG 里容易被生成成肢体畸形。写实制式改用"运动模糊加残影"，只在二维动画风格下才写形变。【推断】

## 三、仙侠斗法 × 超能力（出处：国漫《凡人修仙传》《灵笼》）

**先说证据：这一组是本轮最薄的。** 《凡人修仙传》我只核到"全程动作捕捉、三维加真人 CG 结合"【已核】，没找到讲斗法设计的制作方原文（B 站和知乎的解析页读不到）。下面的斗法机制是【公认】加【推断】。《灵笼》的动作流程是【已核】。

| 编号 | 出处事实 | 机制 |
|---|---|---|
| XX-01【公认】 | 凡人式斗法靠法宝、符箓、阵法和灵力储备，主角谨慎、先算后动 | **斗法是资源战**：每件法宝有用途、有代价、有次数 |
| XX-02【公认】 | 常见打法：先试探、再设伏、留后手，一击定胜负后立即脱身 | **试探 → 设局 → 翻牌 → 收割** |
| XX-03【推断】 | 人站得远，法宝在中间交锋；人本身动作小 | **人是指挥者，法宝是拳头**：手诀对应法宝的转向 |
| LL-01【已核】 | 动作导演先自己打一遍：编好套路，逐招拆开，并预先设定对手的闪躲或中招姿势；参考拳击比赛和武打片 | **每一招都先定好对手怎么应** |
| LL-02【已核】 | 镜头做完后和总导演一起过：缺的补，密的删 | **疏密检查** |
| LL-03【已核】 | 长枪戏由擅长枪术的运动员动捕，再做夸张和风格化 | **真实武术骨架 + 放大** |
| LL-04【已核】 | 怪物设计取"和人有八成半相似时最恐怖"的思路，所以加了人手；机甲必须能让人穿进去 | **怪物带人的局部；装备要合人体** |

**仙侠与超能力怎么合（写法规则）**
1. **一人一套能力，能力有归属**：谁的光是什么颜色、从身体哪个部位发出，全段不换。
2. **实体动作完成接触，能力解释力量**：剑、拳、枪先碰到，光和气浪是结果，不替代接触。
3. **法宝写成有重量的实物**：有大小、材质、飞行轨迹和转向原因（手诀、指向、目光）。
4. **远近交替**：远程斗法一轮后，必有一方破开距离贴身，强度才不掉。
5. **代价可见**：每次大招后有可见的消耗——嘴角渗血、法宝光泽变暗、握剑的手发抖。

**句式**
- XX-01/03：`〔A〕左手并指一引，悬在他肩侧的〔三柄巴掌长的青色小剑〕依次调转剑尖，沿三条不同高度的弧线射向〔B〕；他本人只后退半步，右手始终按在腰间〔另一只未打开的玉匣〕上。`
- XX-02：`〔B〕挥袖震碎三柄小剑，大步逼近。他踏进〔那片碎石地〕的第二步，脚下四角同时亮起〔四面埋好的阵旗〕，淡金色的光壁从地面升起把他围住——〔A〕这才松开玉匣。`
- 远近交替：`光壁被〔B〕一拳打裂，他从裂口冲出，三步之内贴到〔A〕面前，右拳带着赤红的热浪直取胸口；〔A〕来不及掐诀，横剑硬接，整个人被推得双脚在地上犁出两道沟。`
- 代价：`〔A〕稳住身形，嘴角有一线血，身前仅剩的一柄小剑光泽明显暗了下去，剑身出现细裂。`
- LL-04：`〔怪物〕从雾里探出前肢，末端是一只比例过大的、五指分明的人手，手指缓慢地一根根扣住〔断墙的边缘〕。`

## 四、跨作品共通的七条（最值得进主文件）

1. **速度要给参照**：尘土、残影、气浪环、背景流线、慢半拍的摄影机。（SH-01、SH-03、NR-01、WT-04）
2. **起点和落点清楚，中间可以只有一瞬**。（SH-04、WT-04）
3. **一镜一事，每次交换换一样东西**（距离、高度、攻击权、武器）。（JW-04、JW-05、LL-02）
4. **每一招都预先定好对手怎么应**。（LL-01、JW-05）
5. **强度靠反差维持**：稳与乱、满与空、彩色与褪色、远程与贴身交替。（JJ-04、JJ-05、仙侠规则 4）
6. **破坏按材料、按顺序发生，并留在场景里**。（SH-05、SH-06、GZ-03）
7. **强弱关系写进景别和表情**：强者宽景、俯视、脸放松；弱者紧构图、慢一步。（JJ-07、NR-06、WT-02）
