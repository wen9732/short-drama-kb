## 一、密度红线与防漂移总纲（先防崩，再谈炫）

1. **单条黄金镜头密度上限（防乱切错乱）：**
   - `15 秒` ＝ **4–6 镜**；`25–30 秒` ＝ **8–10 镜**（每镜 2–4 秒，只吃透 1 次完整攻防或力学过渡）。
   - **硬拒超密堆叠：** 若构想超过 12 个独立招式相位（或需要连续 30 秒高密连战），必须拆为**上下两条 15 秒接力**或延长生成，严禁在单条里每 1 秒硬塞 3 招，更严禁强求“30 秒绝对禁止硬切一镜到底”致中后段算力崩塌溜冰（`错38 / 错47`）。
2. **移动目的铁律（防无目的循环奔跑）：**
   - 跑动、跃起、踏壁、空中变向只能用于：**躲避攻击、追击目标、借地形改落点、拉开施法距或逃离爆区**。每次位移必写清起点、目标与落点；位移结束立刻转入蹬踏、格挡、出招或急停，绝不原地兜圈。
3. **本体尺度 vs 独立能量体尺度锁：**
   - 参战双方身高体格全程恒定；巨型法相、兽魂、龙首、风暴均明确声明为**独立能量结构，不改变施术者本体比例**；同时按 `错30 / N5` 避免把主角缩成千分之一微尘，用**中景/广角中全景同框**或**前景残楼/巨柱尺度参照**立住巨物压迫。

## 二、3A 级镜头角度阶梯、机位惯性与震动配额（治镜头短板）

严禁脱离人物动量空喊摇镜导致主体漂移打空气。每镜必须落实**起幅 → 绑定动量轨迹 → 落幅**，并优先调用以下 **7 套高阶机位语法**：

| 编号 | 机位与角度语法 | 解决什么痛点 | 实战执行要点（零幕后机器词） |
|---|---|---|---|
| **AD-01** | **焦段暴差硬切＋声不断切** | 打破平淡中景连切，瞬间炸出体量感 | 低位近景拍兵器猛扎/拔刀，**撞击声不断直接硬切超广角高位斜俯全景**看整片地面环爆 |
| **AD-02** | **镜内二段连续轨迹** | 告别呆板固定视角，一镜打通高低维度 | ① 低位惯性追尾→沿坡面/阶梯顺势抬升为空中侧跟；② 侧面平行→沿转身弧线前移至侧前方；③ 绕至主角背后→沿仰望视线抬升借十层残楼揭示巨物 |
| **AD-03** | **武器/技能主体化伴飞与绕前倒退** | 打破只围着人转的局限，卖出极限速度与穿透感 | 视点直接**贴着飞枪/持续剑气侧面高速伴飞**、**钻入剑雨群俯冲**，或**绕到剑气前方倒退拍其剖开巨浪/风暴**，必要时切入风眼内部视角 |
| **AD-04** | **背面俯拍立体纵深压迫** | 拍清高空压制与多飞剑立体落点 | 主角稳居画中上方背影，下方巨怪抬头迎击，成束附魔飞剑/水剑由近及远层层铺开压顶俯冲 |

| **AD-06** | **视点物理惯性（回弹＋延时震颤＋掠框失焦）** | 消除“机械滑轨”塑料感，拉满临场重量 | ① 兵器骤停时视点顺惯性刹住回弹；② 爆炸后**冲击波晚半拍抵达视点才触发约 0.3 秒由强转弱衰减微震**；③ 风刃/飞剑贴框掠过瞬时失焦再立刻锁实 |
| **AD-07** | **乱后骤停跨纵深 `rack focus`** | 极动转极静的顶级终局仪式感 | 急停前景 60° 纯侧影稳住归鞘，剑格合锁脆响同刹那移焦至后景延迟引爆目标 |

**【震动配额与零震动留白纪律】**（防全程乱抖视觉麻木）：
- 单条 25–30 秒严格分配震级：**轻震 4–6 次**（常规格挡/掠击）、**中震 2–3 次**（劈岩/撞墙/蓄力爆冲）、**重震 1–2 次**（大招贯穿/终局爆碎）、**零震动绝对稳停留白 1–2 处**（蓄力完成大全景或归鞘合锁前一瞬完全静止，仅画面内部能量与衣发流动）。

## 三、武器朝向控制、真武术拆招与物理打击链

### 1. 武器状态与朝向铁律（防穿模与对空气打架）
- **状态账本全程可追踪：** 每镜写死兵器在谁哪只手、握距（常规握杆 / 收短握距用尾撞）、刃锋/剑尖/枪尖**唯一进攻指向**、出鞘/换手/抛掷/截停/归鞘状态。
- **零废帧咬合（尾势即下镜起势）：** 严禁每招打完回站姿！写法：`高速跑动中拔刀同时转髋带肩，镜尾刀刃完全出鞘直接接下一镜斜上挥斩，不重新停顿摆姿`；`枪花最后四分之一圈收至右腰，左脚落前右脚蓄力，直接接蹬地冲刺`。
- **极速位移物理证据 6 件套（防慢漂）：** 速度线/风切光痕 ＋ 滞留轨迹里的锥形音爆环 ＋ 气压先行压出水面/地面凹坑 ＋ 远景到近景极速放大 ＋ 碎石衣发逆向卷扬 ＋ **极短瞬时 `speed-ramp` 仅放发力或抓停 1 瞬，出手立刻弹回原速**。

### 2. 四套可裂变真兵器拆招原型（拒绝空话平砍）
- **长兵近身短打链（矛/枪/戟）：** 扎地环爆 → 地缝错位松脱枪尖、靴尖挑踢枪尾翻起接花收腰起跑 → 枪杆斜架撞开顺势横切 → **收短握距枪尾撞碎面甲** → **交叉步转髋腰侧送出回马枪** → **低扫削前排双腿倒下阻住后排**，借低扫余势上挑劈开越顶追敌。
- **掷兵瞬移截停反震链（高燃名场面）：** 踏坡腾空拧腰掷出实体长兵贯穿敌群 → 瞬移至远端路径侧方错步踏实、**身体避开枪尖**，单手扣死全速杆尾骤停 → **惯性分层爆发**：杆身骤停震颤，链饰飘带与焰尾因惯性继续向前甩出越过枪身再被收拢，**双脚不后滑、水泥地面从鞋底向外压陷放射开裂**，积聚动能爆成环形气浪震退外围。
- **疾跑拔刀跨屏延迟斩链（刀/剑）：** 贴地疾跑不顿步拔刀 → 一刀横贯掠过敌侧滑步卸力停稳 → **跨屏多道延迟空间斩线**（以不同高度角度接连横贯整个画幅交错覆盖目标，**主角绝不追加挥刀，全部斩线皆为上一刀遗留**）→ 归鞘合锁同刹那全线收紧引爆。
- **立体交叉剑雨拆解巨物链（御剑/远程）：** 跃过巨物头顶、成束附魔飞剑由近及远层层铺开压顶俯冲 → 切贴地低位拍**低空贴地扫腿剑雨 × 高空俯冲剑雨立体交叉** → 逐层剥离拆解（先砸偏重臂 → 断裂下盘结构失衡砸碎残楼 → 切开护甲暴露失稳核心 → 落地收刀引爆）。

### 3. 硬核打击感：先实体后特效 ＋ 分层时间差毁伤
- **接触时序：** 永远写 **`实体刃尖/拳锋先贯入压陷，高能火焰/雷电/冰霜随后沿甲缝绽放焚开`**，彻底杜绝光团代替接触。
- **惯性与毁伤分层：** ① 碎石先径向飞出，尘浪晚半拍落后于裂纹；② 范围大招走**由远及近/由内向外递进毁伤**——`外围气流略早于主体抵达 → 玻璃幕墙先被掀飞 → 外墙撕裂 → 支撑受损倾倒 → 主体碾过接触面瞬间粉化；远景先崩，前景此时仍保持完整，绝不远近楼群同时炸开`；③ 粒子重力分层——重型断甲石块翻滚下坠，细密粉尘水珠随涡流悬飞。

## 四、手势结印、法力释放与 3A CG 电影级材质词典

彻底摒弃“炫酷光效、漫天粒子、能量爆炸”等廉价页游废词，采用电影视效工业物理语言：
- **手势结印三拍刚性力学（禁“剑指/乱比划” `错33`）：** 写实手指接触与发力（如 `拇指扣压中指蓄势弹响` / `左指竖扣右掌相合→十指交错锁印→双掌翻腕外推`），指尖或掌心能量核显式锁死**持续附着供能、不随洪流脱手飞走**，双手皮肤保持通透次表面散射 `SSS` 原色绝不发光。
- **3A 电影 CG 物理材质与相变替代词表：**
  - **金属/甲胄质感：** `各向异性金属拉丝高光（Anisotropic Specular）`、刃面磨损划痕、湿润水膜镜面反射；
  - **肌肤/织物：** 次表面散射 `SSS` 通透肌肤、浸水变沉甩动的粗麻/纱袂折影、浅色布料锁本色仅衣缘带环境冷暖反光（`错39`）；
  - **三层物理分层特效（禁写 50%/30% 百分比 `错56`）：** **① 实体/深色核心层**（古铁剑身、深紫粘稠水体核、黑洞风眼）＋ **② 介质相变中层**（高压分叉电弧、热浪折射畸变 `Heat Haze`、超临界高温汽化真空蒸汽隧道、焦散光斑 `Caustics`）＋ **③ 物理碎屑外层**（剥落冰壳、燃焦纸屑、飞溅金箔、受重力分离的水珠与灰烬）；
  - **阶段色系隔离：** 常规战与终结大招按时间段切换高对比冷暖色系（如冷青紫电 → 炽红金），绝不同镜混色互污。

## 五、手术刀式防穿模单句库（直接嵌入分镜，替代冗长负面清单）

比底部 500 字负面词精准十倍——按需直接嵌进对应分镜句尾：
1. **防立足面崩穿：** `主角脚下小块立足面保持完整，不随四周裂纹一起塌陷。`
2. **防脚底喷火/悬空发光（治 `错53`）：** `起跳与落地脚下没有任何喷射、发光涟漪或能量承托物。`
3. **防归鞘二次挥刀（治 `错56`）：** `主角原地按鞘不动、绝不追加挥刀，所有空间斩线皆为上一刀留下的延迟余劲。`
4. **防未接触提前假爆：** `接触前不提前成坑、不提前爆炸，受击者具真实阻力与格挡挣扎。`
5. **防截停滑步穿模：** `双手扣死杆尾后双脚不后滑，地面混凝土从鞋底向外压陷开裂。`
6. **防晚撤离或白屏吞动作：** `起跳有明确腿部蹬地发力，不等冲击打中后才撤离；不以持续白屏遮掉起跳、腾空与落地。`
7. **防指尖供能核脱锚：** `能量核心始终固定于指尖/掌心持续供能，不随洪流射走，也不因释放消失。`
8. **防远近建筑同时假炸：** `破坏严格由远及近逐栋推进，远景粉化时前景结构仍保持完整，绝不同时炸开。`
9. **防本体尺度漂移：** `施术者本体身高比例全程恒定，巨型法相/龙首仅为独立能量结构且不生多余躯干。`
10. **防同镜机位乱切：** `同一镜内飞行兵器沿原方向轨迹连续推进，不来回切镜打断速度感。`
11. **防一镜到底视角反车晕眩：** `镜头不反转运动方向，顺着主体外侧曲面划出连续弧线。`
12. **防强风暴/重粒子糊掉主体轮廓：** `巨兽/主体从局部到整体逐步实体化，风暴与粒子内始终清晰可见它的轮廓。`

## 六、一镜到底「物理动量载体」运镜与逐步实体化法（A10 国际 VFX 标杆提炼）

> 面向召唤、变身、机甲组装、大招凝聚与高难度 **10–15 秒连续一镜到底 CG 镜头**，用极高纯度的导演自然语言稳住空间与质感，不靠碎片微秒切分：

1. **单一物理动量载体牵引全镜（零空摇）：**
   - 开头用一句话定死全镜物理引擎：`一镜到底，镜头持续加速，全部镜头运动顺着同一股向前奔涌的〔魔力流/飞刃/气浪〕，镜头围绕实体物体开展运镜`。
   - 机位变形全程挂在载体前沿上：俯冲贴手掌 → 急转大角度荷兰倾斜贴地推进 → 顺肩头划上扬弧线并**顺滑滚回水平机位** → 跟随发光前沿抬升 → **显式写死 `镜头不反转运动方向`** 顺巨物外侧曲面绕行俯冲 → 落回主角身前缓缓减速收束。
2. **「由局部到整体」解剖级逐步实体化（治塑料凭空跳出）：**
   - 召唤巨兽、聚形法相或机甲合体时，严禁笼统写“光雾散开出现一头巨兽”，强制按**从尾到头 / 从骨架到外壳**逐段生长：`能量光带凝实为尾部 → 拱起躯干 → 肢体与巨翼舒展绽开 → 脉冲顺脖颈涌动绽放头颅 → 粒子聚合出粗糙表皮、犄角、半通透发光膜与裂隙`；紧跟一句 **`风暴内始终清晰可见它的轮廓`**，保住主体剪影不被粒子吞糊。
3. **大画幅占屏红线 ＋ 极简自然时间铆钉：**
   - 全局写死 `画面内主角、能量洪流或巨物需占据较大画幅`（防拉远缩成小人 `错30`）；
   - 一镜到底不切十几个碎片秒数，只在**高潮成型点**与**收束落幅点**钉两颗自然时间锚（如 `9 秒时刻，完整巨兽矗立身后上空` ＋ `最后一秒镜头缓缓减速，巨物填满画面上半区、主角神情稳固占据前景`）。
4. **反作用力锚定 ＋ 风场/运镜/衣物三矢量同向：**
   - 向上爆发漩涡里写清 **`头发与破旧衣物向上飞扬，双脚牢牢扎根地面`**（根治人物失重漂浮）；
   - 巨物振翅或重击冲击波，明确写死 **`冲击力裹挟孢子/碎屑与雾气，顺着镜头俯冲方向向下席卷，主角装束被气流向后猛烈甩动`**，让镜头动线、空气流向与布料动力学三矢量严丝合缝。
5. **因果递进单轨声景弧：**
   - 音效写成随重量攀升的一条连续曲线（`接触瞬间抬升共鸣嗡鸣 → 开裂撕扯涌动 → 躯体成型愈发低沉厚重 → 衣物/微粒/振翅大地感重击 → 最终低沉咆哮释放张力`），末尾直落 `无清晰人类对白。不要字幕，不要背景音乐`。
