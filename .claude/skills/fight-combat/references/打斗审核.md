# 打斗审核｜十道闸门与高发翻车卡（fight-combat 参考，交付前读）

> 来源：用户 178 号 skill 第 03 篇（36 张卡），合并同类后保留 22 张。这些是**设计阶段的预防卡**，不是本库实测的错题；本库实测出的错仍记在 `工位/_共用/错误库.md`。
> 结论只有三种：**阻断**（不改不能交）、**要改**、**通过**。文本过了只写"文本通过，待生成验证"；看过成片逐项验收，才能说成片通过。

## 一、十道闸门（按顺序过）
1. **任务：** 时长、画幅、制式、用户锁定的事和可以由导演定的事分清了吗？模型能力不清楚时没有虚构吗？
2. **资产：** 每个参战者有相对体量、主手、武器、能力归属吗？
3. **能力与逻辑：** 每种能力有合同（谁的、怎么触发、打谁、路径、结束、代价）吗？
4. **攻击闭环：** 每次攻击有对象、有接触或明确落空、有对方的应对、有新态吗？
5. **空间与尺度：** 站位卡齐吗？世界方向没有无因翻转吗？尺度有参照物吗？
6. **摄影机：** 只选了一种流派吗？没有抢跑、穿墙、用抖动遮动作吗？关键接触有镜头完整负责吗？
7. **时长与负载：** 事件装得下吗？同时在动的东西是不是太多？
8. **视听可读：** 脸、手、武器、目标看得见吗？特效没吞人吗？声音跟着事件吗？
9. **连续性与接口：** 状态账本逐镜继承了吗？每段开头重写入态、结尾停在未完成相位了吗？
10. **强度保真：** 用户要的速度、力量、规模、数量、爽点，逐项还在吗？

## 二、高发翻车卡
每张：现象 → 为什么 → 怎么改。

**资产与身份**
- **F01 视觉预设压过动作：** 大段质感词，动作只有一句。→ 先写动作因果，质感放全局段。
- **F02 只有称呼没有资产：** "剑修""Boss"。→ 补体量、主手、武器、能力归属。
- **F03 体量关系缺失：** 两人谁高谁壮不知道，巨物没有参照。→ 写相对体量和日常参照物。
- **F04 武器漂移：** 换手、变长、多出一把。→ 锁"哪只手、多长、收在哪"，换手必须写原因。
- **F05 人、法相、召唤物分不清：** → 写层级：谁是本体，谁受谁指挥，谁能被打。

**动作与因果**
- **F06 距离和武器不匹配：** 贴身还在用枪尖。→ 按工作距离换握或拉距。
- **F07 对空气出招：** 攻击没有对象。→ 每次攻击写目标部位。
- **F08 回合制站桩：** 一方打完另一方才动。→ 对手在对方攻击进行中就应对。
- **F09 只剩爆炸没有接触：** → 补接触部位和压缩一拍。
- **F10 对手成沙袋：** → 每次主要攻击后给对手一个有效动作。
- **F11 能力只有名字：** → 写能力合同。
- **F12 瞬移写成快跑，或无因换位：** → 按位移五种分清。
- **F13 受力方向断裂：** 往左打人往右飞。→ 对齐击打方向、受力方向、后续轨迹。
- **F14 修辞被逐字做成实体：** "开天门"生成一扇门。→ 过体验门，翻成结果尺度。
- **F15 无触发的二次命中：** 同一击打中两次。→ 一次攻击一次结算，再打要有新的发力。

**摄影机与剪辑**
- **F16 摄影机抢跑或穿过没破的结构：** → 摄影机走已有通道或已形成的破口。
- **F17 运镜吃掉接触：** → 接触那一拍让摄影机稳住或让位。
- **F18 假长镜靠烟尘黑场偷接：** → 两端状态对得上才算接缝，否则硬切。
- **F19 景别一直不变：** 尺度或接触丢失。→ 相邻两镜至少换三项镜头指纹（见 `cam-shot/references/空间与调度.md`）。

**破坏、特效与强度**
- **F20 指定数量被写成"很多"：** → 逐个可数，当独立验收项。
- **F21 破坏没有材料顺序：** → 按破坏七机制写先后。
- **F22 用"保守可生成"解决所有风险：** 删瞬移、删破坏、把战斗改成慢走。→ 先完成强方案，再给拆段、锁站位、换机位的制作路径和具体风险。

## 三、风险怎么处理（不降级）
| 遇到 | 做法 |
|---|---|
| 时长不够 | 删重复信息、重排读取顺序、拆段并做接口 |
| 摄影机和人抢路 | 改机位、侧跟、让位、用真实通道或老实切镜 |
| 破坏几何太复杂 | 接触、内部贯穿、外部结果分开生成 |
| 特效吞人 | 改体积、亮度、遮挡和读取窗口，不削弱招式 |
| 高燃和可读冲突 | 用相对速度、短读取窗和多一镜覆盖解决，不把战斗降成慢走 |
| 模型能力未知 | 标出事实缺口和备选制作路径，不虚构成功率 |
