## 一、小规模多人战斗调度（1v2 / 1v3 / 2v2 / 3v3）

> 多人战最易翻车的三件事：**背景对手举刀站等像回合制**、**超过 3 人挤焦平面触发脸崩与分身（`错55`）**、**切镜乱跳轴分不清谁打谁**。严格按以下六条执行：

### 1. 主角唯一视觉锚点与同镜人数上限
- **同场人数上限：** 单场流畅可控 **2–4 人**（1v2 / 1v3 / 2v2 / 3v3 分组交替）；
- **同镜交手上限：** 单镜实际发生肢体/兵器交互 **≤3 人**；
- **焦平面上限（防脸崩分身）：**
  - 中景/全景：**焦平面清晰主体 ≤2 人**，第 3 人仅作前景高速掠过遮挡或后景焦外逼近剪影；
  - 近景/特写：**严禁 ≥3 人同框**，特写只给当前直接交锋的 1–2 人。
- **开局入场：** 第一帧以「主角＋至少一名对手」同框中近景立住锚点（人物占画面足够比例），其余对手以运动姿态从画框边缘压入或后景包抄，绝不摆一排静态全家福。

### 2. 双层轴线管理（主轴 ＋ 从轴）
- **主轴：** 主角与当前主对手之间的攻防连线，镜头站主轴同侧（30–60° 斜角）保持左右稳定；
- **从轴：** 其余对手从侧翼/后方绕位、压进或被击退的次级动线；
- **合法切换主轴的 3 种时机（无触发严禁硬跳轴）：**
  1. **原主对手被击退/倒地/出画**，主角视线与重心自然转向新威胁；
  2. **主角主动转身/旋身换位**，镜头顺转身轨迹跟移建立新主轴（写清转身动作）；
  3. **新威胁强势切入画内打断**，原主对手退为背景失衡态。

### 3. 三拍轮转制反“站等”红线（核心防假打）
- **铁律：** 任何未轮到与主角直接交手的对手，**绝不能原地举械摆架势旁观超过 1 秒**！每一镜里，非当前主交手对手必须明确处于以下 **三态之一**：
  - **压上态：** 侧翼冲刺切入、举械下压或绕后封路；
  - **被击退态：** 刚吃招滑退、踉跄扶墙、被掀翻在地爬起；
  - **绕位态：** 贴墙/绕柱变换攻击角度，准备下一拍夹击。
- **1v3 破围核心解法（绝不原地被围着挨个单挑）：**
  - 主角始终移动走**破围点**（往包围圈最薄弱一侧切出，把三名对手拉成一字纵深，迫使后排被前排挡住）；
  - **借敌互挡与地形隔离：** 擒拿/摔投/借力把对手 A 甩向压上的对手 B 撞成一团，或借门框/窄巷/断柱把 1v3 切成连续三个 1v1。

### 4. 多人战节拍弧与防分身差异锚点
- **标准多人节拍弧：** `接敌破势 → 遭侧翼合围施压 → 找破围点借敌互撞破局 → 加速逐个击破（间隔骤缩）→ 收势喘息/警戒震慑`。
- **防分身差异化锚点（同场 3–4 人必配）：** 每名参战者至少在 **2 项**上明显区分——**体型高矮壮瘦 / 发型或头饰 / 主色衣物轮廓 / 兵器形制与主手**，并在锁定段一次锚定，下文只用自然代称或外貌特征指代。

## 二、防守三态溃败链 ＋ 闪避大幅化法则

> 根治 AI 动作戏两大假打惯性：① 对手被重击震开架防后，下一帧莫名原地满血摆回标准格挡；② “微微侧身一让”像走过场毫无危机感。

### 1. 防守三态不可逆溃败链
强攻压制下，守方防线必须逐级恶化，**严禁在 1 秒内瞬时满血复原完整架势**：

| 状态 | 持续窗口 | 身体与手部表现 | 允许衔接 |
|---|---|---|---|
| **① 完整态** | ≤1.5–2 秒 | 双臂立架稳固、下盘扎稳、视线锁死来路，能正面硬接或偏转 1–2 击 | 硬接滑退、化劲反打、或被重劲压入崩防线 |
| **② 崩防线** | 瞬时节点 | 双臂被硬生生震开/挑偏，中门大开，胸腹与咽喉暴露，重心明显后仰或侧倾 | **禁止直接切回完整态！** 必须掉进过渡态或直接吃重击 |
| **③ 过渡态（零碎保命）** | 0.5–1 秒 | 失去架势后只能靠本能狼狈求生：**极低下潜削发、铁板桥后仰 ≥45°、单臂仓促拍偏、连续碎步踉跄后撤、借撞墙/滚翻卸力** | 要么被攻方抓住空档补重击，要么靠大幅度位移脱出距离才能重新立架 |

- **不同来袭匹配不同防守姿势（禁千篇一律“双手交叉硬挡”）：** 直线重拳/直刺→拍偏/侧闪切内线；横扫弧踢/横斩→极低下潜或提膝贴臂卸力；上段劈砸→斜架滑刃泄力＋撤步；贴身箍颈/抓拿→沉肘护肋＋顶膝破控或滚身脱锁。

### 2. 闪避大幅化法则：闪避即位移，位移即蓄力
- 禁用敷衍的“微微一闪/轻巧侧身”，把每一次成功闪避写成**肉眼可见的大幅度空间换位与重心蓄势**：
  - **极低下潜：** 俯身贴近地面，拳风/刃锋擦过头顶削断几缕碎发，下蹲同时腿部已蓄满蹬地反冲劲；
  - **铁板桥后仰：** 上身向后折弯 ≥45°，衣襟发丝垂掠地面，双脚死死抓地借腰腹弹回反踢；
  - **贴地滑步 / 滚翻换位：** 顺势矮身滑入对手身侧死角，起身瞬间拳肘已贴到对方肋下；
  - **侧翻 / 跃障换位：** 借柱子、矮墙或对手膝肩蹬踏换到侧后方，落点直接接反击。

## 三、近景「序列化机枪对招」＋ 机位空间铁律

### 1. 近景机枪节奏 vs 全景炮弹节奏
- **全景/中全景（炮弹节奏）：** 突出大位移、腾空/摔投、武器大弧线与环境破坏，每一击独立拉开看清轨迹与落点；
- **近景/中近景（机枪节奏）：** 突出贴身压迫与高频攻防密度（如 **3 轻 1 重 / 左右交替加速 / 封-破-杀**）。
- **核心禁令：** 严禁用“每秒打 5 拳 / 两人极速对打 / 眼花缭乱互攻”这类空洞频率词！强制写成**可见的「序列化招式链」**——逐击写清：`攻方具体部位＋招式 → 守方逐击不同的防御/失衡反应 → 双方步法持续推进或后退`（如：`抢步切偏门，左拍手压开对方前臂，右日字冲拳连贯抢攻中线，对手连退两步单臂仓促架开两击，第三击被沉肩顶肘震开中门、重心后仰撞向石柱`）。
- **节奏动态呼吸：** 严禁全片一个速度平推，同节奏连续不超 5 秒，用「高频连打 → 破防重击 → 错步换位喘息（运动中完成，绝不静止呆立）→ 再次加速」形成波浪起伏。

### 2. 中全景禁 90° 侧拍铁律 ＋ 景别-幅度绝对匹配
- **90° 侧拍铁律（根治横版街机感）：**
  - **中景 / 全景（看到完整身形）：严禁 90° 纯侧面平拍**（人物和兵器像横版格斗贴纸，失去纵深与厚度），一律改 **30–60° 斜角**拍出前后纵深层次；
  - **近景 / 特写：** 允许 90° 侧拍或微偏角度，专门放大双拳/双刃近身对撞的压迫感。
- **景别与动作幅度绝对匹配：**
  - 小幅高密拳肘/腕指拆招/刀剑短距交锋 → **近景/中近景**放大细节与压迫；
  - 大弧横斩/腾空跃击/过肩摔投/远距击飞 → **中全景/全景**交待完整弧线、空间位移与地形结果。

### 3. 机位-动作语义绑定速查
| 动作类型 | 推荐机位与跟随 | 为什么有效 |
|---|---|---|
| 贴地低扫 / 滑铲 / 地趟腿 | 超低机位贴地平视或 45–60° 斜俯跟拍 | 贴地切出下盘破坏线与地面碎屑弧线 |
| 蓄力跃起 / 凌空下劈 | 低仰角跟起跳 → 高点斜侧随下坠急跟 | 避免正俯拍吞高度，保留天地参照 |
| 贴身近战缠斗 / 擒拿锁技 | 过肩中近景（OTS）随转身小幅绕移 | 代入贴肉压迫感，看清抓腕锁肘发力 |
| 重击轰飞 / 砸穿掩体 | 同框广角中全景随受力方向急跟（`错30`） | 攻方、受击者、破碎结构同框保力量感 |
| 高速破围 / 穿巷追击 | 低位惯性追尾（过门框/拐角带轻微压迫晃动） | 用环境掠过速度证明位移爆发力 |

### 4. 受击部位差异化物理反应（禁千篇一律“惨叫后退”）
- **面部/下颌：** 头颈瞬间向受力方向甩偏，唾沫/汗水沿离心弧线飞散，眼神失焦半拍；
- **胸口/心窝：** 胸腔向内骤然压缩一顿，双脚离地向后仰飞或犁地急滑，双臂失控外甩；
- **腹部/肋部：** 身体瞬间向前对折弓成虾形，膝盖发软、呼吸呛窒，双手本能捂腹失掉上盘防护；
- **下盘（膝弯/胫骨/脚踝）：** 支撑腿瞬间折弯打软，单膝重重砸地或整个人原地失去支点凌空翻倒；
- **肩臂/手腕：** 整条手臂沿击打方向猛然弹开，持械手虎口震麻脱力、兵器脱手或被带偏中线。

## 四、写实打斗平台合规去血腥物理转译词典（现代/犯罪/武侠线按需选用）

> 在写实真人或严审平台环境下，直接写残酷暴力词易触发风控拦截；用以下物理转译词可**保留全部肉疼打击感与重量，同时安全过审**：

| 高危直白词（易拦截） | 物理合规转译写法（保留肉疼与冲击感） |
|---|---|
| 打断骨头 / 骨折断臂 | 接触瞬间肌肉剧烈凹陷波纹，伴随沉闷骨骼受力脆响，受击肢体失力反折下垂 |
| 满脸鲜血 / 鲜血狂喷 | 眉骨裂开一道深色细痕，嘴角渗出暗红血丝，汗水与灰尘糊满脸颊 |
| 刺穿喉咙 / 一刀抹脖 | 锋利刃尖/指尖死死抵住对方咽喉皮肤寸许，对方喉结僵硬滚动、动作骤停 |
| 劈开脑袋 / 削断手脚 | 刃锋擦着颧骨掠过削断额前碎发，衣袖被凌空撕裂露出皮肉浅痕、护甲崩碎飞溅 |
| 砸成肉泥 / 踩爆头颅 | 重击将对方整个人压进碎裂地砖/水泥墙面，尘浪炸起、地面放射开裂，对手彻底失去意识瘫软 |
| 捅进心脏 / 血肉横飞 | 兵刃实打实贯入护甲/衣襟深处，火星与破布碎屑向后爆散，受击者双瞳骤缩、重心瞬间抽空跪倒 |
