# 受力、破坏与特效（fight-combat 参考，按需读）


## 一、受力六拍（展开）
| 拍 | 写什么 | 常见漏法 |
|---|---|---|
| 进入 | 攻击进入有效距离，对方来得及或来不及反应 | 隔着一米就"命中" |
| 接触 | 哪里碰哪里（拳峰对左肋、刃口对护臂） | 只写"击中" |
| 压缩 | 极短的阻力：肌肉、护甲、兵器在接触点形变或一顿 | 直接跳到飞出去 |
| 受力 | 身体、武器、衣料、地面沿力的方向反馈 | 受力方向和击打方向对不上 |
| 传播 | 力传到环境：脚下开裂、身后墙凹陷、气浪推开尘土 | 只剩一团爆炸 |
| 新态 | 谁重新站稳、谁失控、空间变了什么 | 回到原样重来 |

真人制式强调重心、疼痛、呼吸和代价；CG 制式可以放大传播范围，但不删压缩、受力和新态。

**力量链（发力一侧）：** 预备 → 脚下支点 → 腿髋 → 躯干 → 肩臂或武器 → 瞬时加速 → 接触 → 反作用力回到身体 → 回收或追击。大力量靠链条完整，不靠"沉重""猛烈"这些词。

## 二、速度剖面：五种，至少落实一种
| 剖面 | 可见证据 |
|---|---|
| 瞬时爆发 | 脚下塌陷或尘环、极短的尾迹、几乎同时到达 |
| 渐进加速 | 背景流速、姿态前倾、距离持续缩短 |
| 高速巡航 | 相对速度稳定，背景成流线，衣发持续后掠 |
| 脉冲步进 | 多次短爆发，每次之间有一个可见的方向选择 |
| 极限制动 | 反向的力、脚下犁沟、衣摆和尘雾越过身体 |

超人类级别另加：前臂外侧的环状气浪、拳锋前缘的短促热光、被整片抽走的尘土。【已核：钢铁之躯】

## 三、破坏七机制
按 `力量源 → 对象 → 机制 → 变化顺序 → 留下的新空间` 写。

| 机制 | 顺序 |
|---|---|
| 钝力压溃 | 接触区凹陷 → 裂纹放射 → 体块剥落 → 整体位移 |
| 锐器切断 | 刃线掠过 → 切面出现 → 延迟一拍分离 → 失撑坍塌 |
| 穿透 | 局部破口 → 内部路径 → 出口体块飞出 → 留下通道 |
| 支撑失效 | 柱、梁、连接处断 → 结构按重力和连接关系依次坍塌 |
| 冲击波 | 接触点亮起 → 一圈向外推开 → 掀翻、剥离、玻璃逐层爆裂 |
| 热熔与冰裂 | 相变 → 材料发红软化或发白脆化 → 滴落或崩裂 → 热烟或冷雾 |
| 空间分离 | 按该能力自己的规则改变连续性，不伪装成普通爆炸 |

- **材料各坏各的：** 柏油砸出坑并放射开裂；钢板绕着受力体弯折；玻璃整片碎落；木头沿纹理劈裂；石材崩成块；混凝土露出钢筋。【已核】
- **连续穿层：** 先定入射方向和层数；身体依次穿过新破口，摄影机不领先钻进完整楼板；用楼板截面、灯带、柱列来计数；每层不停下来摆表情。
- **山崩地裂：** 选连接处、层理或悬伸部位；切断后岩体因失撑滑落，**先大体块移动，粉尘晚一拍从断面喷出**。地裂要有起点、方向、深度和分开的体块。只有满屏尘雾不算。
- **巨物：** 先定相对比例和接触部位，用日常物件给尺度（膝盖高过站牌、手掌盖住一辆车）。巨物战仍要有有效目标和破防点，不自动变成躲避消耗战。
- **破坏留在场景里：** 已破的墙、已塌的楼板、没散的烟，后面每一镜都继承，并改变下一步的走位。

## 四、特效九步（任何能力都过一遍）
`谁触发 → 怎么成形 → 怎么运动 → 表面什么材质 → 有什么粒子 → 打到目标怎样 → 环境怎么跟着变 → 镜头怎么配合 → 怎么消散`
- 特效先有战斗功能，再谈好看。每个特效要有来源，不写无来源的爆炸、雷电、裂缝。
- 环境底光保住脸、手、武器和目标；能量光只随事件脉冲亮起。特效不吞人。
- 不用静态纹理平移和满屏粒子冒充主体结构。

## 五、十系元素材质表（只是材质词，不是招式）
按"形体｜表面与粒子｜运动｜消散"选词，写进自己的句子里。

| 系 | 形体 | 表面与粒子 | 运动 | 消散 |
|---|---|---|---|---|
| 水 | 弧刃、水带、水柱、水壁 | 独立涡流、细泡、高亮刃缘、水丝拖尾 | 地表波纹先行、缠绕、弯曲的位移轨迹 | 爆散成水花和雾，落地成滩 |
| 火 | 火刃、火环、拳上的火核 | 流体火纹、火星拖尾、余烬 | 短促多段爆燃、火尾分叉、折返的火轨 | 黑烟上卷、余烬飘落、地面焦痕 |
| 风 | 薄透的风刃、风涡、气柱 | 分层尾流、被卷起的尘与叶 | 气核先压缩再定向炸开、向心收束 | 尘土落回、衣发归位 |
| 雷 | 分叉电弧、电链、球形电网 | 瞬亮的白芯、蓝紫边缘、余电在金属上爬行 | 折线闪动、多点同时命中、短促贯穿 | 一缕带焦味的薄烟、金属上的残电 |
| 冰 | 冰棱、冰面、冰甲 | 半透明带气泡、霜花、白色冷雾 | 沿表面蔓延、从接触点向外结晶 | 崩成碎晶、化成冷雾和水迹 |
| 土 | 岩刺、石壁、沉陷的地面 | 粗粝断面、碎石、扬尘 | 地下推进有前兆、整块隆起或下陷 | 体块停住、粉尘缓慢沉降 |
| 木 | 藤条、巨根、木笼 | 木纹硬化、尖刺、叶片与花粉粒子 | 完整的生长过程：发芽 → 伸长 → 硬化 | 枯萎、断裂、叶片散落 |
| 金 | 金属刃片、锁链、甲片 | 冷亮的镜面高光、火花、金属碎屑 | 直线疾射、拼合与拆解、磁吸式聚拢 | 落地有声、嵌入环境 |
| 光 | 光束、光刃、光翼 | 高亮核心、柔和外晕、微小光尘 | 直线、瞬达、照亮周围表面 | 由内向外褪暗，留下短暂的视觉残像 |
| 暗 | 影刃、雾团、从影子里伸出的肢体 | 边缘吞光、无高光、墨状絮丝 | 贴地蔓延、从阴影处涌出、吸附 | 缩回影子、絮丝断开变淡 |

- 一人一系为主，颜色和发出部位全段不换。
- 两系相遇写**相互作用**：水遇火成蒸汽遮挡视线；冰遇雷沿冰面传导；风助火势改变火的方向。
- 中式仙侠别滑成西式魔法界面：不出现悬浮的符号界面、能量条、几何魔法阵，除非设定里明确有。

## 六、声音因果
按 `发力 → 破风 → 接触 → 传播 → 结构后果 → 距离回声 → 余响` 排，声音跟着事件走，不提前、不模板化。用户没要就不加背景音乐。执行层规定不用拟声词，写"金属相撞的短促脆响"这类描述。
