# 高能写法｜实拍与 CG（fight-combat 参考，按需读）

> **定位：** 打斗、客户商单、院线级 CG 动作片的**直抄自然语言库**（涵盖：镜头景别＋运镜轨迹＋身体发力＋特效材质＋环境物理破坏）。
> **铁律：** 作品名、导演名只作本表检索坐标，**绝不写进最终提示词**；把句式里的 `〔〕` 换成本场角色与场景即可直接喂给 Seedance 2.5；不带拟声词和比喻。
> 证据等级：【已核】＝制作方/视效团队访谈与专业摄影解析；【公认】＝成片逐镜拉片特征。

## 一、超音速肉搏与材质破坏（坐标：DC《超人：钢铁之躯》）

| 编号 | 镜头与动作机制 | 解决什么问题 |
|---|---|---|
| SH-01【已核】 | **追不上的目击者（慢半拍手持）**：人比镜头快，人物先冲出，摄影机晚半拍才猛摇过去找人 | 消除摆拍感，卖出超音速体量 |
| SH-02【已核】 | **停半秒再急推（Snap Zoom）**：远景先停顿确认高空/街角的小点，再一把猛推到上半身 | 远距离瞬间贴脸的临场冲击 |
| SH-03【已核】 | **前臂音爆环与热光**：重拳出击瞬间，前臂外侧炸开一圈白雾音爆环，拳锋前缘泛短促热光 | 不用"极快/大力"空词，让力量可见 |
| SH-04【已核】 | **起点真、落点真、中间一瞬**：看清蹬地塌陷与撞击落点，中间只留一道拉长残影与掀起的尘线 | 防止模型把高速冲刺生成成慢跑 |
| SH-05【已核】 | **按材料各坏各的**：柏油路下陷放射裂、钢板绕后背弯折成弧、玻璃整片碎落、混凝土露钢筋 | 告别通用假爆炸，拉满物理真实感 |
| SH-06【已核】 | **冲击波逐层点火**：半空相撞先亮起压缩白核 → 气浪环外推 → 两侧高楼幕墙按距离先后爆裂 | 大场面破坏的层次感与时间差 |
| SH-07【已核】 | **披风/衣摆反向动力学**：急停或悬停时，披风与尘雾越过身体继续前冲半拍再回落 | 强化急停的巨大动量 |

## 三、宽景一镜打完与近身枪斗（坐标：好莱坞《疾速追杀》系列）

| 编号 | 镜头与动作机制 | 解决什么问题 |
|---|---|---|
| JW-01【已核】 | **宽景一镜打完**：全景/中全景框住全身，出手、格挡、摔投、补枪同镜完成，不靠碎切假装激烈 | 动作链条清晰可读，极具真实武术功底 |
| JW-02【已核】 | **稳定器跟、让、微调**：摄影机像双人舞搭档，人进镜头退，人转镜头横移，平滑不抢戏 | 画面稳重高级，不晕眩 |
| JW-03【已核】 | **正上方垂直俯拍清房（上帝视角）**：镜头垂直向下平移，墙体分割房间，一眼看清多人包抄与逐个反杀 | 复杂室内的空间调度与战术爽感 |
| JW-04【已核】 | **CQC 压腕控枪＋贴身补枪**：先一手锁死对方持枪手腕改向，贴肋连开两枪，再借尸体当掩体转火 | 近距离枪战的职业冷酷感 |
| JW-05【已核】 | **一镜一事，绝不重复同一种死法**：第一人被绊摔补枪，第二人被夺刀反刺，第三人被推撞玻璃柜 | 防止连续打斗审美疲劳 |
| JW-06【已核】 | **冷暖实体灯分层＋刀枪独立高光**：深黑底色配青绿/橙红霓虹灯管切出人物轮廓，刀刃枪身永远有一条冷高光 | 暗光夜战里人、枪、刀绝不糊成一团 |
| JW-07【公认】 | **真实体力代价与换弹节奏**：打空弹匣有明确滑套锁定、单手换弹或直接拔备用短刀，摔倒后起身有沉重感 | 赋予角色真实的肉身血汗味 |

- **【JW-01/04 宽景压腕控枪＋过肩摔＋连射】**
  `中全景，稳定器平稳侧跟，两人全身完整在画内，不切镜。〔甲〕一步切入右侧敌人的内线，左手一把扣住敌人持枪的右腕向上推偏，枪口朝天花板走火打落一簇吊灯玻璃；〔甲〕右手手枪紧贴敌人左肋连开两枪，随即左脚插进敌人双腿后方，用肩膀顶住其胸口将其重重过肩摔在积水的地板上，枪口顺势下压朝地补上一枪；动作未停，〔甲〕借蹲姿顺势旋身，枪口已指向从左侧走廊冲出的第二名敌人。`
- **【JW-03 垂直俯拍跨房间战术清场】**
  `正上方垂直俯拍，摄影机在天花板高度匀速向前平移，室内隔断墙将画面分割为左右两个房间与一条走廊。〔甲〕从左下角房门突入，两枪击倒迎面的守卫，翻滚越过木桌躲开右侧射来的弹雨，木桌表面木屑成串炸起；〔甲〕贴着隔断墙滑到门边，在右侧敌人跨过门槛的瞬间夺过对方长枪，用枪托砸倒对方并顺势向走廊深处点射，三人的移动路线与火力线在俯视画面里一清二楚。`
- **【JW-06/07 夜雨霓虹暗光＋换弹拔刀】**
  `中近景，稳定器缓慢后退跟拍。环境为深黑的雨夜巷道，背景一块橙红色霓虹灯牌与前景冷青色车灯将人物轮廓从暗处锐利切出，枪身与刀刃上始终有一条清晰的冷白高光。〔甲〕连开三枪后手枪滑套向后锁死（空仓挂机），对面敌人趁机持刀扑到一臂之内；〔甲〕来不及换弹，左手直接松开手枪任其垂在战术绳上，右手反手从胸前拔出短刀，迎着来刀侧面一记短促格挡擦出火星，顺势贴身刺入对方肩窝，将对方顶在潮湿的砖墙上。`
