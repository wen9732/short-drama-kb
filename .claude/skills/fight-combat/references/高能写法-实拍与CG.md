# 高能写法｜实拍与 CG（fight-combat 参考，按需读）

> 每条 = **出处事实 → 机制 → 可直接改写的句式**。作品名、导演名只在"出处"里，**不进提示词**；句式里的〔〕换成本场事实；句式不带拟声词和比喻。
> 证据等级：【已核】＝联网读到制作方或专业媒体原文；【公认】＝影评与观众普遍认可，没找到制作方原文；【推断】＝按成片特征归纳，待实测。【2026-11-11 联网】

## 一、超人类对打（出处：DC《钢铁之躯》）

| 编号 | 出处事实 | 机制 |
|---|---|---|
| SH-01【已核】 | 导演要求摄影机像纪录片摄制组一样跟拍，不让镜头运动带着动画走；小镇对打由真人掌机 | **摄影机是追不上的目击者**：人比摄影机快，镜头晚半拍才找到人 |
| SH-02【已核】 | 急推变焦：先短暂停住，再猛地推近，常用来跨越很远的距离；源自太空题材剧集的"新闻镜头"拍法 | **停一下再急推**：远处一个小点，镜头停住确认，再一把推到跟前 |
| SH-03【已核】 | 高速出拳时前臂周围有一圈音爆状的痕迹，拳锋前缘发热发亮，让动作显得比实际更快 | **速度要有可见的物理痕迹**，不靠"极快"两个字 |
| SH-04【已核】 | 只拍动作的起点和终点，中间由数字替身接管，切换只用一两帧；整段看起来是一个不断的镜头 | **起点真、终点真、中间一瞬**：起势和落点看得清，位移过程极短 |
| SH-05【已核】 | 破坏按材质分别模拟：柏油路面砸出坑并向外开裂、钢制金库门绕着身体弯折、金属框玻璃门碎裂 | **每种材料用自己的方式坏** |
| SH-06【已核】 | 两人在城市上空相撞产生冲击波，把高楼撕开；破坏先定关键形状和时序，再按顺序"点火" | **破坏有先后顺序**：接触点 → 冲击波扩散 → 结构依次失效 |
| SH-07【已核】 | 披风约七成镜头是数字的，主要目的是做出标志性剪影 | **剪影优先**：高速中靠轮廓认人 |

**句式**
- SH-01/02：`手持摄影，机位在〔街道一侧〕。〔A〕从画面深处高速掠来，镜头慢半拍才摇过去找到他，停住半秒，随即急推到他的上半身，画面带轻微晃动。`
- SH-03：`〔A〕出拳的一瞬，前臂外侧炸开一圈白色的环状气浪，拳锋前缘泛出短促的橙色热光，身后的尘土沿出拳方向被整片抽走。`
- SH-04：`〔A〕蹬地，脚下的〔水泥地〕先向下塌出一个浅坑；下一瞬他已经撞在〔B〕身上，两人之间的那段距离只留下一道被拉长的残影和一线被掀起的尘土。`
- SH-05：`〔B〕被砸进〔柏油路面〕，路面以落点为中心下陷成坑，裂缝向四周放射；他身后的〔金属卷帘门〕向内凹成他后背的形状，门框上的玻璃整片碎落。`
- SH-06：`两人在〔楼宇之间的半空〕相撞，接触点先亮起一团压缩的白光，随后一圈冲击波向外推开，〔近处大楼〕的玻璃幕墙从撞击高度开始，一层接一层向上向下爆裂。`

## 二、近身枪斗与格斗（出处：好莱坞《疾速追杀》系列）

| 编号 | 出处事实 | 机制 |
|---|---|---|
| JW-01【已核】 | 打斗尽量用宽景，"能多宽就多宽"；特写只做插入；刻意不用手持 | **宽景里把一招打完**：出手、格挡、接触、结果同镜成立 |
| JW-02【已核】 | 镜头一直在动，但动得慢而流畅，跟着编排走；A 机轨道、B 机稳定器，很少超过两台 | **摄影机活着但不抢戏**：跟、让、微调构图 |
| JW-03【已核】 | 俯拍长镜头：公寓一整段由索道摄影机从正上方一镜拍完，只插少量地面镜头 | **上帝视角读走位**：多个敌人、多个房间的路线一眼看清 |
| JW-04【已核】 | 剪辑师的标准：每个镜头都是一个能一句话讲清的小事件（"他跑、停、环顾"，约两秒）；快切只会让人迷失 | **一镜一事**：能用一句话说清才算合格 |
| JW-05【已核】 | 把打斗当对白来剪：谁对谁做了什么必须和对话一样清楚；相似的节拍不重复，多余的撞击直接删 | **不重复同一种打法**：每个交换都要换点东西 |
| JW-06【已核】 | 画面里放可见的实体灯，颜色与主光相对（青绿主光配橙红实体灯）把前后景分开；偏爱单一光源和深黑；用蒸汽不用烟雾 | **对比色分层**：人永远从背景里分得出来 |
| JW-07【已核】 | 用颜色和反差让刀、枪在快动作里读得清 | **武器要有自己的高光** |

**句式**
- JW-01/02：`全景，稳定器平稳跟随，两人全身始终在画内。〔A〕左手压下对方持枪的手腕，右手贴着对方肋下近距离连开两枪，随即借对方倒下的身体转向〔下一个从右侧门口进来的人〕；镜头只随他的转身小幅横移，不切。`
- JW-03：`正上方垂直俯拍，摄影机沿〔走廊〕匀速前移，墙体把画面分成几个房间。〔A〕从〔左下房间〕穿门进入〔中间房间〕，〔两名敌人〕分别从上方和右方的门逼近，三个人的路线在俯视里同时看得见。`
- JW-06/07：`环境是深黑的，主光为青绿色的单一侧光；背景里有几支橙红色的灯管把人物轮廓从暗处切出来。枪身和刀刃上各有一条清晰的冷色高光。地面有低矮的蒸汽，不遮挡人物腰部以上。`

## 三、黑衣装备战与巨物（出处：日漫《杀戮都市》及其 CG 电影）

| 编号 | 出处事实 | 机制 |
|---|---|---|
| GZ-01【已核】 | 动捕在标好区域的空场里一口气演完；导演事先模拟人物间距和走位，再定机位 | **先定距离和走位，再定镜头** |
| GZ-02【已核】 | 霓虹灯当调度工具：决战前用一块绿色霓虹的亮起，把观众视线引到某个人身上 | **用环境光指挥观众看哪里** |
| GZ-03【已核】 | 导演给特效下具体指令：风向、楼房按什么顺序起火、雾和蒸汽和烟分几层 | **特效有风向和点火顺序** |
| GZ-04【已核】 | 敌人的眼部光束按一个从 0 到 1 的蓄能量表计时，红光跟同一节拍 | **大招有可见的蓄能表**：观众能数着等它来 |
| GZ-05【已核】 | 偏爱红与黑的克制配色，不用花哨的彩色灯光 | **两色世界** |
| GZ-06【公认】 | 武器扣下扳机后有延迟才生效；黑色紧身战斗服受压时表面鼓起 | **延迟结算**：开火和结果之间留一拍悬念 |
| GZ-07【公认】 | 普通人体量对抗数层楼高的怪物，夜晚真实街区 | **用日常街景给怪物定尺度** |

**句式**
- GZ-02：`夜晚街道以红黑两色为主。〔楼顶的一块绿色霓虹招牌〕突然亮起，绿光落在画面右侧〔A〕的肩上和枪身上，其余人物留在暗处。`
- GZ-04：`〔怪物〕额头的红光从一个小点开始，逐级变亮、变大，共〔四级〕；每亮一级，周围的空气就向它收缩一次，地上的碎屑向它滑动。第四级亮满的一瞬，光束射出。`
- GZ-06：`〔A〕扣下扳机，枪口只闪了一下蓝光，没有任何东西飞出；〔怪物〕继续向前迈了两步——第三步落地时，它的右肩从内部向外炸开。`
- GZ-07：`〔怪物〕的膝盖高过路边的〔公交站牌〕，手掌按下去盖住〔一整辆出租车〕的车顶；〔A〕站在斑马线上，高度只到它的脚踝。`

## 四、超能力少女的碾压战（出处：韩国《魔女》系列）

| 编号 | 出处事实 | 机制 |
|---|---|---|
| WT-01【已核】 | 全片大部分时间压着能力不放，到后段才爆发；入侵者在她能力觉醒后几秒内全灭 | **长压短爆**：前面越平常，爆发越狠 |
| WT-02【已核】 | 反转之后，她开始杀人时带着明显的愉悦，令人不安 | **强者的脸是松的**：笑、歪头、慢条斯理 |
| WT-03【已核】 | 终局打法：一拳打穿墙、互相把人扔出去、跃到天花板高度、沿墙面移动、让枪悬浮起来对准敌人 | **超能力落在日常空间里**：走廊、墙、天花板都是受力面 |
| WT-04【已核】 | 续作被评为"构图干净精确、强调每一击的重量"；快的人在画面里是一道模糊；把人扔穿树、墙、车 | **稳镜头拍快人**：镜头不晃，人变成残影 |
| WT-05【已核】 | 大量数字特效，但配合实拍的血包和假体，不是绿幕感 | **超能力有肉身后果** |
| WT-06【公认】 | 对手同样有能力，且在屠杀后鼓掌大笑 | **同类相遇先看态度，再动手** |

**句式**
- WT-01/02：`〔少女〕一直低着头。第一个人伸手抓她肩膀的一瞬，她抬起脸，嘴角是放松的、带一点笑；画面里她的位置只剩一道模糊的影子，三个持枪的人几乎同时向后飞出，撞在〔走廊两侧的墙〕上。`
- WT-03：`她侧身一脚把〔B〕踹进墙里，石膏板和砖一起向内塌出一个人形的洞；她没有回头，抬手，地上那把手枪自己浮起来，枪口转向走廊尽头的最后一个人。`
- WT-04：`固定机位，中全景，镜头完全不动。〔少女〕从画面左侧到右侧只用了不到半秒，中间是一道水平的残影；她停下时，身后的〔B〕才开始倒下。`
- WT-05：`〔B〕的后背撞碎车窗，玻璃碴嵌进他的外套，他滑坐到地上，咳出一口血，手还在够掉在一旁的枪。`

## 五、两种摄影机流派，一场戏只选一种

| | 追不上的目击者 | 冷静的旁观者 |
|---|---|---|
| 出处 | 《钢铁之躯》 | 《疾速追杀》《魔女》续作 |
| 做法 | 手持、慢半拍、急推变焦 | 宽景、稳定器或固定、慢而流畅 |
| 适合 | 飞行、超音速、城市级破坏 | 近身格斗、枪斗、需要看清招式 |
| 风险 | 晃动吃掉接触 | 速度感不够，要靠残影和环境补 |

两种混在同一段里，模型会两头都做不好。【推断，需实测】
