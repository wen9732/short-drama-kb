# 裂变法｜拿到一个案例，怎么举一反三（fight-combat 参考，按需读）

> 目的：案例只取机制。裂变就是**保住机制、换掉皮**，一条案例长出多条不撞车的新设计。【用户】2026-11-12
> 裂变出来的东西是**候选设计**，没生成过的一律标"未实测"，不当规则用。

## 一、三步
1. **剥皮取骨：** 把案例写成一句不含任何专名的机制句："〔谁〕用〔什么手段〕把〔对手〕从〔状态一〕逼到〔状态二〕，〔环境〕承担了〔什么结果〕"。写不出这句，说明还没看懂案例。
2. **换轴：** 从下面九根轴里**换两到三根**，其余不动。只换一根太像原作，换五根以上机制就丢了。
3. **回验：** 新设计过主文件的五道门和四问；再跑 `python3 tools/check_copy.py`，人名、设定、成段句子一个不带。

## 二、九根裂变轴
| 轴 | 可选项 |
|---|---|
| 体量差 | 同体量、大欺小、小打大、一对多、人对巨物 |
| 手段 | 徒手、短兵、长兵、重兵器、枪械、元素能力、念力、法宝、召唤物 |
| 空间 | 窄廊、楼梯井、开阔地、多层楼内、屋顶、水面、车内与车顶、高空、林地 |
| 高度层 | 同层、上下层、垂直坠落、由地升空、由空落地 |
| 战局链 | 压迫、反转、争线、追击、重击破局 |
| 摄影机流派 | 追不上的目击者、冷静的旁观者；另可选俯视读走位、贴身同行 |
| 制式 | 真人写实、写实 CG、三维国漫、二维动画 |
| 强弱与态度 | 碾压且轻松、势均力敌、以弱胜强、惨胜带伤、假装弱后翻牌 |
| 结局接口 | 击倒、逼退、对手逃脱、同归受伤、被第三方打断、新威胁入场 |

## 三、已做好的裂变表（案例 → 骨 → 三个变体）
变体只写到设计级别，用的时候按主文件第八节编译。全部未实测。

**A03 第2条｜楼内高速缠斗，重劈贯穿楼层**
骨：两个高速个体在柱列密集的多层建筑里互相追砍，每次交手打掉一处承重，最后一记下劈把对手连续砸穿数层。
- 变体一（换手段、制式）：真人写实，两名持短棍的人在停车楼里对打，每次落空都砸瘪一处车顶或立柱护角，最后一脚把对手从车道护栏踹到下一层。
- 变体二（换空间、高度层）：仙侠，两名修士在悬崖栈道上御剑缠斗，每次相撞震断一段栈木，最后一剑把对手连同栈道一起压下三层崖台。
- 变体三（换体量、强弱）：人对巨物，少女在厂房钢梁之间绕着三层楼高的怪物跑，引它自己撞断立柱，屋顶塌下来替她完成重击。

**A03 第3条｜下坠劈弹幕，抛刀脚踢刀柄贯胸内爆**
骨：追击方沿破口下坠途中连续拨开对手远程弹幕，落地借掩体绕位后把主武器抛空借脚蹬音爆投射贯胸，打断对手蓄能触发胸口内爆再贴身重踢轰出建筑。
- 变体一（换手段、制式）：真人特工动作，竖井绳降躲开下方手枪点射，落地绕水泥柱把战术匕首抛起反脚踢柄钉穿对手扳机手，顺势踹穿玻璃幕墙。
- 变体二（换空间、手段）：仙侠斗法，破云下坠劈散漫天火符，落地将重剑抛空一掌拍剑格轰成音爆飞剑钉入对方阵眼法器，引爆其灵力反噬。

**A03 第4条｜追逃与白发觉醒，队友远程狙击侧写**
骨：目标逃离，主角用极小肢体动作触发形态升级、反向滑动变焦蹬塌建筑追上斜向贯楼，另切远处队友瞄准镜无法锁定与地面队友极限闪避落石的第三方尺度侧写。
- 变体一：都市夜路，摩托追车；后座的人中途站起换成双手持枪；远处天桥上的同伴瞄准镜被高速漂移甩脱锁不住，被迫改打前方路灯逼车转向。
- 变体二：水面，踏水追击逃船；主角中途脚下的水结成冰面加速；岸上同伴放出藤蔓横拦河道。
- 变体三：反转强弱——被追的人是假装逃，把追击者引进同伴布好的阵里，追击链变成反转链。

**A03 第5条｜绝境心脏脉冲进化与垂直穿楼升空**
骨：重伤强敌砸飞地面援兵后疯狂捶地，镜头锁死胸口心跳脉冲与光学色散完成骨骼体型重组进化，随即垂直向上连续撞穿多层建筑冲上高空宣战。
- 变体一（换制式、体量）：硬科幻机甲，残破核心在驾驶舱内高频脉冲过载，外装甲逐块弹射重组为重装形态，点火垂直撞穿地下机库三层钢板升空。
- 变体二（换空间、手段）：古风志怪，坠入枯井的妖狐双掌拍裂井壁，体内妖丹脉动令骨刺破背生长，垂直撞碎塔心七层木楼冲上雨夜塔顶。

**A03 第6条｜城市级四步轰炸后的一击延迟斩首与死亡 POV**
骨：对手四步放大放出覆盖全场的大招，主角不躲，入纯黑静默空间深呼吸蓄势后一瞬突进至对手身后收刀；狂风骤停、延迟显痕头身分离，最后切对手坠落头颅第一视角双眨眼黑屏。
- 变体一：蓄能表做成可数的——对手身上四盏灯逐级亮起，主角在第三级时出发，第四级亮满前到达。
- 变体二：缩到近身尺度，拳台上对手抡出一记要打满全弧的重摆拳，主角贴着弧线内侧进去一记短上勾，对手晚半拍才察觉护齿飞出。
- 变体三：换结局接口——斩到一半被第三方的一发远程打断，双方同时回头，新威胁入场。

**A06｜单人清场：先枪后剑，压轴巨物现身**
骨：一个人边跑边用远程清小怪，距离被压没之后换近战武器，清完时更大的东西才出现。
- 变体一：真人写实，走廊里先手枪后匕首，换武器的原因是打空弹匣，最后电梯门打开，里面站满了人。
- 变体二：仙侠，先飞剑远控后拔出背上重剑贴身，清完后山体本身睁开一只眼。
- 变体三：换摄影机流派——全程正上方俯视，一镜读完她的路线和每个敌人倒下的位置。

**A02｜逃跑中变身**
骨：被追的人在不停步的情况下完成形态变化，变化完成的瞬间攻守易位。
- 变体一：变化改成装备展开，外骨骼在奔跑中一节节扣合，扣完最后一节时转身。
- 变体二：变化的是环境而不是人——他跑进自己的领域，地面颜色从脚下向外翻过去。
- 变体三：假变身，追兵以为他要变，全体急停戒备，他借这一秒拐进巷子。

**A07｜长枪物理力学链与掷枪瞬移截停反震（未实测裂变）**
骨：主战者以长兵连环破阵后凌空掷出兵器贯穿敌群，随即瞬移至远端路径侧方徒手扣死全速杆尾，凭惯性分层（饰带焰尾前甩越身、双脚压裂地面不后滑）把截停动能炸成环形气浪清场，再借蓄势终招引爆后主动跃离爆区。
- 变体一（换手段、空间、制式）：仙侠竹林古栈道，剑修掷出巨阙重剑洞穿数具傀儡后闪身落于栈道尽头，单手反扣重剑剑柄硬生生刹停，脚下青石压陷龟裂、剑穗与寒雾越过剑锋前卷回拢，反冲气浪震断整排竹林。
- 变体二（换体量、手段）：科幻废土机甲格斗，高机动轻甲把高频长矛掷穿数台哨兵无人机，火箭助推超前侧滑扣死矛尾，金属摩擦火星向前爆射、双足在钢桥压出深凹，借反震甩矛砸毁后方重炮台。
- 变体三（换强弱、结局接口）：以弱胜强反转链——被围猎的刺客故意掷出重枪诱使强敌侧身闪避，自己瞬移截停后并不回攻，而是借鞋底压裂地面的反冲波震塌上方悬岩封死追兵退路脱身。

**A08｜疾跑拔刀跨屏延迟斩＋立体交叉剑雨拆解巨物（未实测裂变）**
骨：高速移动中不停顿拔刀一闪掠过，不追加挥刀而由上一刀残留的多道跨屏延迟斩线同步爆解；随后面对十层楼高巨物，跃过其头顶在背面俯拍中铺开层层远程兵雨，切低位以高空俯冲×贴地扫腿立体交叉逐层拆解下盘与护甲，最后落地归鞘合锁同刹那引爆暴露核心。
- 变体一（换空间、手段）：月夜古林寒潭（已实用于 A05 进阶版），剑仙八道附魔奔雷飞剑贴弹道伴飞轰塌千年古树，缠雷主剑迎面贯穿水墙切出真空蒸汽隧道并留下跨屏延迟雷线，踩立断根零震动归鞘合锁同刻跨纵深移焦引爆残敌骨面。
- 变体二（换手段、制式）：现代异能都市高架，短刃刺客贴车顶疾跑拔刀斜掠装甲车队，停步后三道跨屏透明气斩线逐一显形切开车身；面对重型步行机甲，凌空铺开电磁飞镖雨贴地切断液压膝关节再引爆胸口电池仓。

**A09｜雨中螺旋觉醒变甲＋指尖持续供能由远及近粉化风暴（未实测裂变）**
骨：由背面脚部螺旋升绕切长焦微距完成发色蜕变与环爆清雨，踏步每落脚迸出分叉能量经天降雷柱无缝成甲；随后指尖核心疯狂压缩且持续附着供能不脱手，打响指持续轰出螺旋能量风暴，沿街区纵深由远及近（外围气流先掀玻璃→结构倾倒→接触面粉化，绝不远近同爆）犁出毁灭通道。
- 变体一（换元素、空间）：极夜雪山古寺，女术士踏雪每步开出冰莲裂缝、漫天寒霜自肩背聚拢无缝凝结玄冰战铠，掌心稳锁一枚深蓝冰核不脱手，翻掌推出贴山谷推进的极寒冰风暴，由远处山门逐座将古殿冻脆粉化推进至近景。
- 变体二（换制式、体量）：硬科幻轨道电梯，纳米液态金属自受损战靴沿小腿螺旋爬升覆满全身变甲，掌心反应炉锁定持续输出等离子螺旋束，沿百米长廊由远端舱门逐节熔毁推进至前景防爆门。

## 四、从高能写法卡里直接裂变
机制卡（SH、JW、JJ、NR、GZ、XX、WT 编号）本身就是骨。常用的组合：
- **稳镜头拍快人（WT-04）× 资源战（XX-01）：** 固定机位里，一名修士不动，三件法宝在画面里交错成残影，对手一个个倒下。
- **蓄能表（GZ-04）× 一镜一事（JW-04）：** 每个镜头只做一件事，但背景里那盏灯每镜亮一级，观众数着等。
- **贴近起幅拉开（JJ-02）× 材料各坏各的（SH-05）：** 从拳面贴近起幅，后拉的过程中依次经过三种材料各自的破坏结果。
- **快的人绕慢的人（NR-06）× 强者的脸是松的（WT-02）：** 绕的人在笑，被绕的人越转越慌。

## 五、裂变的纪律
- 不搬原作的人名、台词、怪物、法宝、专有设定和成段句子。
- 裂变体进案例库前必须注明"裂变自哪条、换了哪几根轴、未实测"。
- 用户实测通过的裂变体，才去掉"未实测"；同一机制两次通过，才提出升为规则。
