# 裂变法｜拿到一个案例，怎么举一反三（fight-combat 参考，按需读）

> 目的：案例只取机制。裂变就是**保住机制、换掉皮**，一条案例长出多条不撞车的新设计。【用户】2026-11-12
> 裂变出来的东西是**候选设计**，没生成过的一律标"未实测"，不当规则用。

## 一、三步
1. **剥皮取骨：** 把案例写成一句不含任何专名的机制句："〔谁〕用〔什么手段〕把〔对手〕从〔状态一〕逼到〔状态二〕，〔环境〕承担了〔什么结果〕"。写不出这句，说明还没看懂案例。
2. **换轴：** 从下面九根轴里**换两到三根**，其余不动。只换一根太像原作，换五根以上机制就丢了。
3. **回验：** 新设计过主文件的五道门和四问；再跑 `python3 tools/check_copy.py`，人名、设定、成段句子一个不带。

## 二、九根裂变轴
| 轴 | 可选项 |
|---|---|
| 体量差 | 同体量、大欺小、小打大、一对多、人对巨物 |
| 手段 | 徒手、短兵、长兵、重兵器、枪械、元素能力、念力、法宝、召唤物 |
| 空间 | 窄廊、楼梯井、开阔地、多层楼内、屋顶、水面、车内与车顶、高空、林地 |
| 高度层 | 同层、上下层、垂直坠落、由地升空、由空落地 |
| 战局链 | 压迫、反转、争线、追击、重击破局 |
| 摄影机流派 | 追不上的目击者、冷静的旁观者；另可选俯视读走位、贴身同行 |
| 制式 | 真人写实、写实 CG、三维国漫、二维动画 |
| 强弱与态度 | 碾压且轻松、势均力敌、以弱胜强、惨胜带伤、假装弱后翻牌 |
| 结局接口 | 击倒、逼退、对手逃脱、同归受伤、被第三方打断、新威胁入场 |

## 三、已做好的裂变表（案例 → 骨 → 三个变体）
变体只写到设计级别，用的时候按主文件第八节编译。全部未实测。

**A03｜楼内高速缠斗，重劈贯穿楼层**
骨：两个高速个体在柱列密集的多层建筑里互相追砍，每次交手打掉一处承重，最后一记下劈把对手连续砸穿数层。
- 变体一（换手段、制式）：真人写实，两名持短棍的人在停车楼里对打，每次落空都砸瘪一处车顶或立柱护角，最后一脚把对手从车道护栏踹到下一层。
- 变体二（换空间、高度层）：仙侠，两名修士在悬崖栈道上御剑缠斗，每次相撞震断一段栈木，最后一剑把对手连同栈道一起压下三层崖台。
- 变体三（换体量、强弱）：人对巨物，少女在厂房钢梁之间绕着三层楼高的怪物跑，引它自己撞断立柱，屋顶塌下来替她完成重击。

**A04｜追逃与升级，队友远程支援**
骨：目标逃离，主角在追击途中升级形态，另有一人从远处用一击封住目标去路。
- 变体一：都市夜路，摩托追车；后座的人中途站起换成双手持枪；远处天桥上的同伴一枪打爆前方路灯逼车转向。
- 变体二：水面，踏水追击逃船；主角中途脚下的水结成冰面加速；岸上同伴放出藤蔓横拦河道。
- 变体三：反转强弱——被追的人是假装逃，把追击者引进同伴布好的阵里，追击链变成反转链。

**A05｜城市级轰炸后的一击斩首**
骨：对手蓄能放出覆盖全场的大招，主角不躲，用蓄能的时间读它的节拍，在大招的空档里一次突进了结。
- 变体一：蓄能表做成可数的——对手身上四盏灯逐级亮起，主角在第三级时出发，第四级亮满前到达。
- 变体二：缩到近身尺度，拳台上对手抡出一记要打满全弧的重摆拳，主角贴着弧线内侧进去一记短上勾。
- 变体三：换结局接口——斩到一半被第三方的一发远程打断，双方同时回头，新威胁入场。

**A06｜单人清场：先枪后剑，压轴巨物现身**
骨：一个人边跑边用远程清小怪，距离被压没之后换近战武器，清完时更大的东西才出现。
- 变体一：真人写实，走廊里先手枪后匕首，换武器的原因是打空弹匣，最后电梯门打开，里面站满了人。
- 变体二：仙侠，先飞剑远控后拔出背上重剑贴身，清完后山体本身睁开一只眼。
- 变体三：换摄影机流派——全程正上方俯视，一镜读完她的路线和每个敌人倒下的位置。

**A02｜逃跑中变身**
骨：被追的人在不停步的情况下完成形态变化，变化完成的瞬间攻守易位。
- 变体一：变化改成装备展开，外骨骼在奔跑中一节节扣合，扣完最后一节时转身。
- 变体二：变化的是环境而不是人——他跑进自己的领域，地面颜色从脚下向外翻过去。
- 变体三：假变身，追兵以为他要变，全体急停戒备，他借这一秒拐进巷子。

## 四、从高能写法卡里直接裂变
机制卡（SH、JW、JJ、NR、GZ、XX、WT 编号）本身就是骨。常用的组合：
- **稳镜头拍快人（WT-04）× 资源战（XX-01）：** 固定机位里，一名修士不动，三件法宝在画面里交错成残影，对手一个个倒下。
- **蓄能表（GZ-04）× 一镜一事（JW-04）：** 每个镜头只做一件事，但背景里那盏灯每镜亮一级，观众数着等。
- **贴近起幅拉开（JJ-02）× 材料各坏各的（SH-05）：** 从拳面贴近起幅，后拉的过程中依次经过三种材料各自的破坏结果。
- **快的人绕慢的人（NR-06）× 强者的脸是松的（WT-02）：** 绕的人在笑，被绕的人越转越慌。

## 五、裂变的纪律
- 不搬原作的人名、台词、怪物、法宝、专有设定和成段句子。
- 裂变体进案例库前必须注明"裂变自哪条、换了哪几根轴、未实测"。
- 用户实测通过的裂变体，才去掉"未实测"；同一机制两次通过，才提出升为规则。
