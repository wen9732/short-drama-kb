# 动作层·高能打斗（v1）

## 边界
- **负责：** 打斗的战局设计、站位与距离、动作路径、接触与受力、能力规则、破坏与特效的因果、打斗段的"下一镜拍什么"、强度保真。
- **不负责：** 景别焦段机位怎么选、构图句式（→ `cam-shot`，其中 `references/空间与调度.md` 是打斗的必读搭档）；两镜之间的接缝句式（→ `cam-transitions`）；演员的情绪表演（→ `perf-`）；画面质感与色调包（→ `genre-`）；平台格式、台词符号、时间戳（→ `exec-seedance25`）。
- **互斥：** 其他 `fight-` 主库（目前只有这一个）。
- **常搭配：** `exec-seedance25`（必带）＋ `cam-shot`（空间与调度、摄影机状态与连贯）＋ `cam-transitions`（切点速查）。

## 一句话原则
先定观众要感到什么，再把人物、能力、空间、攻防排成**可推演的因果链**，最后才写提示词。用户指定的速度、力量、规模和爽点不降级；风险靠重排、拆段、锁站位解决，不靠删破坏、减数量、把高燃改成保守展示。【用户·178 号 skill】

## 一、动笔前先过五道门
1. **体验门：** 这一段观众要感到什么（碾压、险胜、追不上、被困、反杀）？"拳够重""一剑开天"这类话是**修辞**，先翻成可见的结果尺度，不逐字生成成一扇门、一把巨剑。
2. **资产门：** 每个参战者写清：相对体量（谁高谁壮）、主手、武器在哪只手和它的长度、能力从身体哪里发出是什么颜色、打法差异。长相服装以参考图为准，不另写。"剑修""Boss"这种称呼不算资产。
3. **空间门：** 按 `cam-shot/references/空间与调度.md` 写站位卡：锚点、双方起点、初始距离档、互动轴、高度层、禁区、计划终点。**先写世界位置，再写画面左右。**
4. **能力门：** 每种能力一句合同：谁的、怎么触发、打向谁、走什么路径、怎么结束、有什么代价。一人一套，全段不换。
5. **负载门：** 同时在动的主体、近身接触、武器换手、破坏、特效、摄影机路线，叠得太多就拆段。先删重复蓄力和无功能亮相，核心事件不缩水。

## 二、一招怎么写：六拍
每次关键交互都走完这六拍，缺哪拍补哪拍：
**进入**（攻击进入有效距离）→ **接触**（实体真正碰到：哪里碰哪里）→ **压缩**（极短的阻力或形变）→ **受力**（身体、武器、衣料、地面沿力的方向反馈）→ **传播**（力传到环境）→ **新态**（谁占了什么位置、谁失衡、空间变了什么）。
- 命中写清：接触部位、力的方向、对方怎么动、攻击者怎么收。只写"击中""爆炸"不算。
- 对手是活的：每次主要攻击都引出格挡、偏转、闪避、硬吃、反击或换位之一。一边倒也要有有效阻力，不写站桩靶。
- 实体动作完成接触，光和气浪是结果，不替代接触。

## 三、连招按"攻击权"排，不按招数排
五种链，按战局选，一段里以一种为主：
- **压迫链：** 抢入攻击线 → 两三次同体系威胁 → 对手被迫移动 → 封退路 → 重击 → 受力。
- **反转链：** 露出空当 → 对方主动进入 → 闪或截 → 借对方余势改角度 → 反击 → 攻击权易手。
- **争线链（兵器）：** 首次相接 → 沿兵器滑移偏转 → 脚步换位 → 一方脱离重攻 → 新距离。
- **追击链：** 目标脱离 → 沿同一主轴压近 → 障碍逼出路线变化 → 再入有效距离 → 接触或逼停。
- **重击破局链：** 立支点 → 大路径出手 → 对方闪或硬扛 → 环境承担结果 → 攻击者回收慢 → 出现反击窗口。
每条链只锁 2–5 个决定战局的节点，中间的招让模型在同一体系里自然连。动作密时，先减摄影机变化，不把人砍成站桩。体系与招式写法见 `references/动作语言.md`。

## 四、下一镜拍什么：四问（打斗连贯性的核心）
每切一次镜、每起一段，都问：
1. **上一镜留下什么没做完？** 动作相位、受力方向、新出现的威胁——下一镜从它开始。
2. **观众的眼睛停在哪？** 下一镜的关键事件从那个位置附近进画；高速段不让观众重新找人。
3. **这一镜换了什么？** 距离档、高度层、攻击权、武器状态至少换一项；什么都没换的镜头合并或删掉。
4. **强度掉了没有？** 不重新起跑、不重新对峙、不收招定格；结果镜里就带出下一个威胁。
- 状态账本逐镜继承：位置、朝向、高度、速度趋势、主手与武器、伤损、已破的结构、没散的烟火。
- 强度靠**反差**维持，不靠一直快：稳与乱、满与空、远程与贴身、宽景与贴身交替。

## 五、跨段怎么接（每段自成一体）
- 段首把**入态当事实重写**：谁在哪、朝哪、多快、带着什么伤、哪里已经破了。不写"接上一段"。
- 段尾停在**没做完的动作相位**上（剑已出鞘未落、人已离地未落、拳已到未收），不收招、不摆定格。
- 两段怎么对上，只写在给用户看的设计表里。
- 分清四种东西：真长镜（一镜内连续）、多镜剪辑、一次生成、跨段接续。人物多、走位复杂、跨空间、摄影机又在大动时，拆成多段，在动作匹配、整幅遮挡、甩镜、暗区处交接；烟尘、爆闪不是万能胶，两端状态对不上就老实硬切。

## 六、速度、位移与破坏
- **速度必须落到一种可见证据：** 尘土与碎屑被带走、带方向的残影、气浪环、背景流线、慢半拍才追上的摄影机。只写"极快"不算。
- **起点和落点看得清，中间可以只有一瞬。** 高速制动要有余势：衣摆发丝继续前甩、尘雾越过身体。
- **位移五种别混：** 连续高速跑、借力轻功、自由飞行、爆发换位、真瞬移。残影只证明原位置，不变成第二个人。
- **破坏按材料、按顺序坏，并留在场景里：** 力量源 → 对象 → 怎么坏（压溃、切断、穿透、失撑、冲击波、热熔冰裂）→ 先后顺序 → 留下的新空间。用户指定的数量逐个可数。
- 细则、元素材质表、特效九步见 `references/受力破坏与特效.md`。

## 七、摄影机在打斗里的本分
- 摄影机只改变"怎么看"，不偷改站位；不提前钻进还没破的墙；不靠持续抖动遮动作。
- **三向量一起查：** 人往哪动、力往哪打、镜头往哪走。三者都复杂时先让摄影机简单。
- **一场只选一种流派：** "追不上的目击者"（手持、慢半拍、急推）或"冷静的旁观者"（宽景、稳、慢而流畅）。混用两头都做不好。【推断，待实测】
- 关键接触至少有一镜完整负责：看得见施力的一端、目标、接触位置和第一下反应。

## 八、编译进提示词（格式以 `exec-seedance25` 为准）
- 用第一种写法（七段式带时间戳）。打斗段在【人物与场景锁定】里加**站位卡**和**能力合同**，在【镜头与表演原则】里写明选哪种摄影机流派。
- 正面写清"是什么"，负面只留高概率误读和已经翻过车的项，不堆禁词。
- 专业招式名每个节拍最多留一两个，并立刻补上可见的身体路径；删掉名字后单看路径仍能懂谁打谁。英文术语不进提示词。
- 不写招式的"技能名"当标题，不写导演名、作品名。不用拟声词和比喻。
- 写完按 `references/打斗审核.md` 过一遍；文本过了只能说"文本通过，待生成验证"。

## 写法示例
- **空话：** "两人高速激战，拳脚对轰，特效拉满，极具冲击力。"
- **改写：** "3-6秒：中全景，稳定器侧跟。甲从柱子左侧两步切入乙的内线，左手压下乙的右腕，右拳自下而上打在乙左肋；乙上身向右折，后脚滑退半步撞上身后的铁栏，栏杆向外弯出一道弧。乙借栏杆反弹，右肘横扫回来——画面停在肘尖离甲的下颌一拳远的位置。"

## 自检
- [ ] 每个参战者有体量、主手、武器、能力归属，没有只靠称呼？
- [ ] 站位卡齐了，世界位置和画面左右没混？
- [ ] 每次主要攻击都有对象、接触点、受力方向和对方的应对？
- [ ] 四问逐镜过了，没有重新起跑、重新对峙、收招定格？
- [ ] 速度有可见证据，破坏有材料和顺序，数量可数？
- [ ] 每段开头重写入态、结尾停在未完成相位，没有指向别段的话？
- [ ] 用户指定的强度、规模、数量一项没少？
- [ ] 有没有越界写了构图句式、接缝句式、表演情绪？→ 移走
