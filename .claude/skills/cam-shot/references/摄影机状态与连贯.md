# 摄影机状态与连贯｜摄影机怎么"在场"、切过去看哪里、强度怎么不掉（cam-shot 参考，按需读）

> 来源：【用户】动作库 19A《导演级运镜机制完整知识库 v2.0》。前景门框、前景关系、过肩、背转正弧线、环绕、俯拍、焦点交接七张卡已在 `叙事运镜机制.md`，这里只收**那份没有的**。
> 导演和片名只是研究坐标，写在"出处"里，不进提示词。两镜的接缝句式归 `cam-transitions`。

## 一、先定摄影机怎么"在场"：七种状态

每个关键镜头先选状态，再选推拉摇移。一段里状态可以变，但**变化要有触发**。

| 状态 | 是什么 | 适合 | 句式 |
|---|---|---|---|
| 观察者 | 固定或近固定，靠走位、表演、遮挡、声音推动 | 谈判、审讯、微表情、等待 | `固定机位，镜头不动。` |
| 同行者 | 人先动，镜头晚一点跟上，不贴死 | 步行、调查、关系戏 | `他迈步之后镜头才开始跟，始终落后半步。` |
| 锁步 | 镜头和人同速同停，人在画面里大小位置不变，环境流过去 | 职业感、冷静、精密行动 | `镜头与他同速侧移，他在画面里的大小和位置不变，背景的〔门框〕匀速掠过。` |
| 追逐者 | 追、超前、短暂跟丢再找回 | 追逐、突发危险 | `镜头追着他，转角处短暂跟丢，半秒后重新把他框进画面中心。`**跟丢必须写找回。** |
| 身体化 | 像在场的人，会被冲击打乱 | 爆炸、撞击、近身混战 | 见第二节稳定弧线。**不从头抖到尾。** |
| 独立见证 | 人走了镜头不追，留下看后果 | 犯罪现场、灾难、悬疑落幅 | `他冲出画面，镜头没有跟，停在〔翻倒的车和散落的鞋〕上。` |
| 虚拟摄影机 | 现实做不到、但空间逻辑读得懂的路径 | 动画、超能力、仙侠、概念片 | 仍然要有起点、速度、惯性、停点；不无故穿墙、瞬间换高度。**高风险，待实测。** |

- 人物越掌控，镜头越稳、越同步；人物失控时镜头才松开。**"稳 → 松"的变化本身就是心理表达。**【出处：《杀手》式锁步】
- 人物内心越忙，镜头越克制：关键微表情用固定、近固定或极慢的推。

## 二、稳定弧线：高强度段落的呼吸

不只写"稳定"或"手持"，写变化：

**稳 → 响应 → 被打乱 → 重新捕捉 → 新的稳**

句式：`镜头平稳侧跟。〔爆炸〕在画面右后方炸开的一瞬，画面向左猛地一偏、短暂失焦；半秒后重新对上他的脸，稳在一个比刚才更近的位置。`

- 被打乱只在**冲击发生的那一下**；关键的脸、命中、反应必须恢复清晰。
- 上一镜乱，下一镜可以完全不动，用反差给重量。

## 三、切过去看哪里：注意力路径

高速段每次切镜前问四句：
1. 切之前观众的眼睛在画面哪里？
2. 切之后关键事件出现在哪里？
3. 观众要不要重新扫一遍画面才找得到？
4. 如果要找，是故意让人不安，还是白白损耗？

**原则：高速动作少让眼睛跑；慢戏可以用负空间让观众自己找。**

句式：`上一镜结束时〔刀尖〕停在画面中心偏右；这一镜〔被劈开的柱子〕就从画面中心偏右裂开。`
（跨段时不写"上一镜"，只写本段第一镜的关键事件在画面哪里。）

## 四、宽景把一招打完

攻击路径、格挡、接触、摔投、位移、结果尽量在同一镜里成立；镜头只跟和小幅调整构图。武术和兵器戏首选，配短距离横移。【出处：《疾速追杀》式宽景】

## 五、其余机制卡

| 机制 | 结构 | 什么时候用 |
|---|---|---|
| 荷兰角 | 由平到斜，在一个明确触发后进入 | 世界关系已经失衡、认知偏差、威胁；不是"紧张按钮"，不常驻 |
| 快摇 | 快速摇到新目标，**结束时必须重新框住主体** | 注意力突然跳转、目标切换 |
| 继承视线 | 甲先发现目标 → 乙晚半拍看向同处 → 乙先出画 → 甲出画 → 镜头不追人，沿甲的视线继续移 → 停在那件东西上 | 悬疑、犯罪、结尾伏笔 |
| 走位驱动画框 | 镜头少动，人物进出、前后穿插、坐下起身来改构图 | 群像、餐桌、办公室、会议。**对模型友好**：人和镜头不同时高负载 |
| 冲击扰动 | 只在撞击那一下给镜头一个短促位移 | 重击、爆炸、车祸 |
| 贴身参与 | 镜头和车、飞行器、人物共享加速度；近距离广角，背景真实流动，身体受力可见 | 驾驶舱、车内、飞行 |
| 高速里保住环境 | 快不等于背景全糊；路、地形、建筑要让人知道在哪、往哪、离危险多远 | 追车、飞行、高速追击 |
| 焦段家族 | 一段戏定一套：空间家族（广、纵深）、亲密家族（中长、贴人）、压缩家族（长焦、层叠）、贴身变形家族（极近广角） | 段落级的统一。不写"悲伤等于某个毫米数" |
| 客观与主观两套拍法 | 客观：有重量、允许小瑕疵；主观：更戏剧、构图和焦点更精确。切换由心理或世界规则触发 | 幻觉、领域展开、心理世界 |
| 有动机的失焦 | 高压事件触发短暂失焦，随后找回 | 极端压力瞬间。关键信息必须恢复清晰 |

## 六、八个组合配方

| 任务 | 配方 |
|---|---|
| 对峙升级 | 肩背占得多的过肩 → 前景关系 → 小幅关系环绕 → 停在反应上 |
| 反转揭脸 | 背影稳住 → 触发 → 背转正弧线 → 隐藏的道具或表情出现 → 正面停住 |
| 困局收紧 | 中景交代空间 → 困局环绕，每个新角度少一个出口 → 半径略收 → 停在封死的背景前 |
| 线索发现 | 人清楚 → 视线或声音触发 → 镜头不动 → 焦点从人交给线索 → 线索读清 → 回到反应 |
| 全知进入临场 | 顶拍地图 → 冲突触发 → 镜头下降 → 高位斜俯 → 人物身边跟随 |
| 悬疑落幅 | 主角发现 → 配角晚半拍 → 受控环绕 → 两人先后出画 → 继承视线 → 空镜 |
| **高速动作可读** | 交代地理 → 宽景对打 → 关键接触稳住看 → 按注意力落点切 → 结果与反应 |
| **压力弧线** | 稳 → 声音或冲击 → 被打乱 → 短暂失焦 → 重新捕捉 → 新的稳 |

## 七、表演和镜头的错时

- 重要反应默认顺序：**外部触发 → 眼神先变 → 头跟上 → 身体和手跟上 → 镜头最后响应。**
- 主角先发现；配角通过主角的状态晚半拍才明白。不要两人同步转头、同步眨眼、同步停步。

## 八、四种"连续"别混着说

- **真长镜**：一个镜头里摄影机真实连续运动。
- **多镜剪辑**：多个机位，有切点。
- **一次生成**：平台一次出的那一段。
- **跨段接续**：分开生成，靠动作匹配、整幅遮挡、快摇模糊、暗区、门框或车身接上。

人物多、走位复杂、跨空间、镜头又在大动——四样叠在一起时，不逼模型一次做完，拆成多段，在上面那些位置交接。接续时**人物和信息的连续**排第一，"看起来没切"排最后。

## 九、不要写的和要改成的

- 不写：`高级电影感`、某导演名加"式环绕"、`上帝视角很有临场感`、把快摇、荷兰角、大环绕、大推拉堆在一句里。
- 改成：**起幅在哪 → 什么触发 → 镜头沿什么路径走 → 主体和前景各干什么 → 揭示了什么 → 观看权交给谁 → 停在哪。**
- 机位高度、焦段、弧度、半径、距离只在**会改变画面**时才写；写焦段时同时写景别、距离和透视结果。
