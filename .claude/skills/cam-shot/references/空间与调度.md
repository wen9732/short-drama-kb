# 空间与调度｜站位、距离、锚点、构图、透视（cam-shot 参考，按需读）

> 解决一件事：**模型把人放错地方。** 先把世界里的位置写死，再写画面里怎么看。
> 打斗、追逐、多人戏必读；两个人坐着说话的戏只用第一、二、四节。

## 一、站位卡（每段都写，写在【人物与场景锁定】里）

**先写世界位置，再写画面左右。** "画左、画右"只是这一镜看见的样子，换个机位就变；世界位置不变。

| 项 | 写什么 | 句式 |
|---|---|---|
| 锚点 | 场景里 2–4 个不会动的东西：门、柱、柜台、车、楼梯、平台边缘 | `场景里有三处固定物：〔北墙的铁门〕、〔中间一排四根水泥柱〕、〔南侧倒下的栏杆〕。` |
| 起点 | 每个人相对锚点在哪、多高、朝哪 | `〔甲〕站在〔第二根柱子〕的西侧一步，面朝东；〔乙〕背靠〔铁门〕，面朝西。` |
| 距离档 | 贴身／一臂／两三步／十步以上，武器够不够得着 | `两人相隔约〔三步〕，〔乙〕的长棍伸直刚好够到〔甲〕的胸口。` |
| 互动轴 | 两人之间那条连线的走向 | `两人的连线是东西向，与柱列平行。` |
| 主运动轴 | 追、退、换位主要往哪走 | `这一段的移动沿柱列自西向东推进。` |
| 高度层 | 地面／台阶／高台／半空／上下层 | `〔甲〕在地面，〔乙〕站在高出半人的平台上。` |
| 禁区 | 不能穿、不能站、站了就错的地方 | `中间的圆台上没有人；两人都不越过南侧栏杆。` |
| 计划终点 | 这一段结束时谁在哪 | `结束时〔乙〕被逼到〔铁门〕前，后背离门一拳；〔甲〕在他正面两步。` |

- **参考图里带着、这一场不该有的东西，写明"画面里没有"。**
- **每一镜（哪怕是中近景）都顺手带一件看得见的环境物：** 实测表明，中近景如果只写人物不提环境物，模型极易把背景直接丢成纯黑或纯色夜空。每镜顺手写一句“身侧的水泥柱”“脚边的断栏杆”“背后的红灯”，把人钉在现场。
- 人物坐着办事的戏，起点写到"坐在哪件家具的哪一侧、面朝哪、左右手边各是什么"。
- 一段里人物换了位置，写"从哪走到哪、走了几步、经过什么"，不让他凭空出现在新位置。
- **环境飞物写清来路与方向：** 气浪掀飞汽车或碎石砸人时，顺着力的方向写清“谁挥臂震飞前方的车 → 车从画面哪一侧迎面撞向哪一侧的人”，防止飞物从受击者背后反向飞来。

## 二、距离怎么写（人和人、人和镜头）

**人与人：四档，用身体当尺子，不写米数**（模型对米数不敏感，对身体尺度敏感）。

| 档 | 尺子 | 能干什么 |
|---|---|---|
| 贴身 | 胸口相抵、前额相距一拳 | 肘、膝、擒抱、短刀 |
| 一臂 | 伸直手臂能碰到 | 拳、掌、短兵器 |
| 两三步 | 要迈步才够得着 | 腿、长兵器、突进的起点 |
| 十步以上 | 要跑或要飞 | 枪、弓、法术、对峙 |

- **近战不等于贴脸。** 徒手要留躯干转动的余地；长兵器贴身后不能再抡全长，得换握、用柄或拉开。【用户·v2】
- 距离变了要写**为什么变**：他退了两步、她被打退、他一步切进来。

**人与镜头：焦段和距离一起写，光写毫米数没用。**

| 想要 | 写法 |
|---|---|
| 空间夸张、冲击 | `广角贴近拍，镜头离他不到一臂，近处的〔拳头〕占去画面三分之一，身体在后方缩小。` |
| 关系可读、重击与破坏 | `广角中全景，镜头在两人侧面五六步外，出招者、受击者与被打穿的〔楼板／石柱〕同时在画内看清。`（实测证明：拍大招切楼、多层砸穿时切远景会让人物变成几个像素的小点、彻底丢失力量感；用同框中全景跟拍才是力量感最强的景别） |
| 压缩、窥视 | `长焦从远处拍，前后景被压在一起，背景的〔人群〕贴在他肩后。` |

## 三、构图：画面里谁在哪、占多大

每个重要镜头写清四件事：**主体占画面多大、在画面哪个位置、前中后景各是什么、空出来的地方给谁。**

| 手法 | 什么时候用 | 句式 |
|---|---|---|
| 中心锚定 | 快切的打斗、高速段。关键信息放在画面中心，切过去不用找【已核：导演在现场要求"把十字准星对准她的鼻子、对准那把枪"】 | `〔甲〕的上半身始终在画面正中，背景在两侧流动。` |
| 偏置加负空间 | 威胁在画外、等待、对峙。空的那一侧就是危险来的方向【已核：偏置可以暗示注意对象在空的那一侧之外】 | `〔乙〕压在画面右侧三分之一，左边三分之二是空的走廊，尽头的门开着。` |
| 中心得势 → 短边失势 | 主动权易手。把"谁占上风"直接写进构图【用户·V2.5】 | `开始时〔甲〕在画面正中；被逼退后他被挤到画面最右缘，身后只剩一条窄边。` |
| 三层纵深 | 任何要立体感的镜头。前景给尺度，中景是主体，后景交代在哪【已核：宽景里放前景物件给空间感】 | `前景是虚化的〔翻倒的椅腿〕，中景〔甲〕半蹲，后景是〔碎了一半的落地窗〕。` |
| 框中框 | 锁定目标、偷看、被困 | `镜头从〔两根柱子之间的窄缝〕看过去，〔乙〕被夹在缝里，只露出上半身。` |
| 斜线 | 兵器、冲刺、失衡。主武器是画面里唯一的一条攻击线【用户·V2.5】 | `〔刀〕从画面左下斜贯到右上，刀尖指向〔乙〕的咽喉；画面里没有第二条同样醒目的线。` |
| 引导线 | 把视线送到人身上 | `地上的〔水渍和裂缝〕都朝〔甲〕脚下汇过去。` |
| 压顶／留头 | 压迫或孤立。头顶留得少更紧，留得多更小【已核】 | `镜头贴着天花板往下看，〔乙〕被压在画面最下方三分之一。` |
| 高低位 | 强弱。高处的人占上风 | `〔甲〕站在台阶上，〔乙〕在下，镜头在〔乙〕肩后仰看。` |

- **宽画幅的空要用掉**：居中就让两侧有东西，偏置就让空侧有意义，或在后景放一件有戏的东西。【已核】
- **偏置是重音，居中是底**：高速段以居中为底，偶尔偏一次才有力量；港片、日式动作会让注意力在画面里跳，但每一跳都是算好的。【已核】
- 雷区：画面边缘切在关节上；背景物体从头顶长出来；前景肢体超过一个；三个镜头人都在正中。

## 四、角度与透视

| 角度 | 效果 | 句式与风险 |
|---|---|---|
| 平视 | 中性、共情 | 默认 |
| 低机位仰拍 | 力量、尺度 | `机位低于腰线，仰拍。` 保留一个比例参照物；超广角下肢体容易重复 |
| 高机位俯拍 | 弱小、被看 | `高位斜俯。` 追捕和多人走位用斜俯，既看得见路线也看得见身体 |
| 垂直顶拍 | 地图、阵型、命运 | `正上方垂直俯拍。` 只在要读路线和包围时用 |
| 贴地墙角 | 突入、搜查、追逐 | `机位在墙角贴地，人物斜穿画面。` 风险：脚部重复 |
| 物下仰看 | 揭示、压迫 | `机位在〔桌下／车底〕，人物从上方进入画面。` |
| 武器近镜 | 威胁 | `〔枪口〕在最前景，只允许这一件武器贴近镜头，目标在它后面保持可读。` |
| 荷兰角 | 世界已经失衡 | 由平到斜要有触发事件；不整段常驻 |
| 垂直跟落 | 坠落、跳下、砸穿多层 | `广角中全景在楼外随两人同步急坠，打穿的楼板与下方的地面在画面里越来越近。` 镜头不穿过身体；空中下劈写“高点收腹拧腰、双手举剑过顶劈落”，不写“头下脚上”（会被字面画成僵硬倒挂木偶） |
| 垂直立面奔跑 | 摩天楼外墙、悬崖峭壁狂奔 | `机位在侧面偏斜仰角，画面下方保留水平地面或垂直悬挂的灯牌作参照，拍他踩着垂直玻璃幕墙向上狂奔，上方的目标始终在画面上缘。` 不用正俯或越肩俯拍（缺少天地参照会被模型画成 40 度缓坡） |
| 由遮挡升起 | 英雄亮相、空间打开 | `镜头从低处上升，先被〔护栏〕挡住，随后他从遮挡后面露出来。` |
| 反向让位 | 双方逼近 | `他向前冲，镜头短暂后撤并略向侧移。` 不同时再加环绕 |
| 乱后骤停 | 重量 | `上一镜高速晃动；这一镜完全固定。` |

**大透视三种写法**
- **近大远小**：`广角，〔拳头／剑尖／脚底〕直对镜头，在前景迅速放大；身体因强透视在后方缩小。` 一次只让一个肢体或一件武器冲向镜头。
- **纵深冲刺**：`镜头贴地沿他的冲刺方向推进，两侧的〔柱子〕向后飞退，尽头的目标在画面中心越来越大。`
- **尺度对比**：`〔怪物〕的膝盖高过〔路牌〕；人只到它的脚踝。` 巨物必须挨着一件日常物。

## 五、相邻镜头别长一个样：六项里至少换三项

每一镜有六个特征：**景别、机位高度、机位方位、焦段透视、运镜、构图手法。** 相邻两镜至少换三项。【用户·V2.5】

连续三镜里不出现：同一个景别；连续两次环绕；连续两次肢体或武器冲镜头；连续两次同方向推进；三镜人都在正中；三镜同一个焦段区间。

**强镜头用过要冷却两三镜再用**：低位英雄环绕、急推变焦、滑动变焦、极端荷兰角、武器擦镜、极端前景手掌、镜头翻转、超长焦压缩。

## 六、兵器进画面

- **刀剑**：斜线优先；主剑是唯一攻击线，副剑准备下一动、不抢中心；刃不穿过脸和胸，不和另一把融在一起。
- **枪矛长柄**：强调够得着的范围；尖端的路径和身体分开层次；贴身后收杆、换握或拉开。
- **重兵器**：多拍支点、起势、惯性和落点，少拍挥出去之后的漂亮姿势；拍身体怎么扛住重量。
- **枪械**：枪口方向、视线、掩体三者一致；镜头不横穿枪口线；先给反应和空间关系，再给枪火。
