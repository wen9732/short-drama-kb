## 一、《情绪音效与声音桥设计库》➔ Doubao-Seed-Audio 1.0 声学转译矩阵

> 原则：在 Seedance 2.5 视频提示词里写 `BRAAM / Reverse Riser / Muffled` 是为了直出声场；转进 **Doubao-Seed-Audio 1.0** 时，**禁止直接留裸英文缩写**，必须全部展开为具体乐器、频段质感与拟声汉字比喻。

| 已训练音效库概念 | 戏剧与声学机制 | Doubao-Seed-Audio 1.0 原生中文写法模板 |
|---|---|---|
| **`BRAAM`** | 巨型低频铜管暴鸣＋长余震，重大危机或终局落地 | `先是铜管组重低音与合成器高频渐强铺压，随即砸下一声沉闷宏大、类似深沉钟鸣“咚”的低频氛围重击特效音并带有长时间余震` |
| **`Sub Impact` / `Sub Drop`** | <40Hz 极低频深潜钝击，心沉谷底、实体碰撞 | `紧接着是一声沉闷厚重的低频重击撞地声（或沉重物体坠落砸响），同时背景旋律骤然沉底压低` |
| **`Dull Drum Hit` / `Drum Hit`** | 干净闷鼓卡点，压迫催促、打脸与古装紧迫节点 | `伴随着一声重击鼓点的特效音` / `先是一声空旷的鼓槌敲击声音效` / `音乐加入中国大鼓并伴有定音鼓重敲卡点` |
| **`Reverse Riser` / `String Riser`** | 爆点前 2–5 秒攀升蓄力，拖拽悬念 | `随后弦乐组以震音持续向上攀升渐强，同时配合合成器高频效音逐渐拉紧氛围` |
| **`Suckback` → 静默留白** | 爆点前半拍把空气抽空，制造极致反差 | `蓄力达到顶峰时音乐与所有环境杂音突然骤停抽空，留出一瞬窒息的空旷静默，紧接着……` |
| **`Low Drone`** | 连续不祥的低频压迫嗡鸣底噪 | `伴随着一阵长时间的低频氛围嗡嗡音效铺垫在暗处，整体氛围沉闷诡异` |
| **`Windy Swish` / `Whoosh` / `Sword Whoosh`** | 高速掠过、法术、冷兵器或转场呼啸 | `一声尖锐的风声呼啸而过的特效音` / `一声类似“呼”的风声转场特效音` / `连续两声类似于“咻”的法术闪过特效音` / `金属质感类似刀光“唰”的特效音` |
| **`Muffled` + `Ear Ringing`** | 遭受重创或震惊后的主观闷塞失聪与微弱耳鸣 | `重击过后周边人声与环境杂响瞬间变得遥远闷塞仿佛隔墙传来，隐约浮留一缕极细微尖细的持续电流般嗡鸣，伴随人物压低且混乱的喘息声` |
| **`Audio Ducking`** | 核心台词开口前背景主动退让，防止盖掉对白 | `人物开口瞬间，周围配乐与风雨杂音自然减弱退后，只清晰突出说话人低沉颤抖的呼吸与声线` |
| **`Room Tone` + 材质三合一 `Foley`** | 写实物理空间与细腻物件材质碰撞 | `环境中伴随着持续的轻微鸟叫声` / `一声轻微的布鞋在木台阶上走路的脚步声` / `一声展开纸张的声音，接着是一阵在皮包中翻找物品的轻响` / `两声高跟鞋走路脚步声` |
| **`UI Pop / System / Sci-Fi`** | 科幻扫描、虚拟界面、数据加载、播报截断 | `一阵类似机器运转的声音，然后是一声表示数据加载的电子提示音，接着是一声清脆的电子提示音，再是一声点击屏幕的电子提示音，最后是一声表示扫描完成的电子提示音` |
| **`J-cut / L-cut` 跨段声桥** | 跨生成段或场景切换的听觉黏合 | **J-cut（声先画后）：** 前段结尾人物未开口但先铺入 `随后隐约响起一阵由远及近的汽车行驶声与轻微刹车声`；**L-cut（余音延展）：** 对白或动作结束后写 `音乐停止。伴随着持续的微风与轻微鸟叫声延续到结束` |

## 三、实战示范（Prompt-to-Audio 转换 ＋ 三套多题材标准模板）

### 示范 A｜核心能力：把 Seedance 2.5 视频提示词转化为 Doubao-Seed-Audio 1.0 音频设计
> **原输入（Seedance 2.5 视频分镜摘录，含视觉与英文词）：**
> `15秒｜16:9 anamorphic｜Sony VENICE 2 + 1/8 Black Pro-Mist。深夜暴雨帐篷酒摊，40mm贴桌跟拍。分镜一（0-5s）：男子1（@图1）轻转酒杯；女子2（@图2）掀帘进门坐下，男子停手，铺入 Low Drone，酒瓶 foreground wipe 切过。分镜二（5-10s）：50mm 揭露桌下拨枪，雨声盖住枪套暗扣 Foley，Audio Ducking 后男子1压低说：{喝了再动手。} 随后 rack focus 回脸，Suckback 半拍硬切。分镜三（10-15s）：75-85mm 特写，背景暖斑虚化，周边杂雨声瞬间 muffled，女子2压哑气声说：{你早就知道了……为什么不躲。} 【保护项】不要背景音乐，不要字幕。`

**洗净与声音设计拆解：**
1. **彻底删光视觉词：** 删除 `16:9 anamorphic / Sony VENICE 2 / 1/8 Black Pro-Mist / 40mm / @图1 / rack focus / foreground wipe / 暖斑虚化 / 保护项不要背景音乐`。
2. **补齐人物音色档案：** 原文只写了“男子1/女子2”，为确保声优配对准确，按悬疑对峙补充年龄与嗓音特征。
3. **翻译 SFX 与补全主观心理配乐弧线：**
   - `Low Drone` → 转化为先隐忍铺底的低沉合成器 pad 与隐约低频嗡鸣，在女子掀帘停手时悄悄渗入；
   - `Audio Ducking` + `Foley` → 掀塑料帘抖落水珠声＋极轻皮扣弹开脆响，说话前雨声与低频铺底自动退让变轻；
   - `Suckback → Muffled` → 转为台词前突然抽空雨声的短暂静默＋女声开口前所有杂音骤然变得遥远闷塞仿佛隔水传来，配一记沉微心脏搏动般的低频钝击。

**转换结果（可直接粘贴至 Doubao-Seed-Audio 1.0 使用）：**
```text
男子 1 是 35 岁左右的青年男性，嗓音低沉，偏冷峻克制，带有轻微颗粒感
女子 2 是 28 岁左右的青年女性，嗓音清冷微哑，克制隐忍


整个声场设在暴雨敲打塑料篷布的密集环境里，开头先是持续闷实的塑料棚雨打声与屋外深街积水流动的微响。男子 1 面前响起一声玻璃酒杯底在塑料桌面轻旋滑动的细微摩擦声。随即一声透明厚塑料门帘被急切掀开、雨珠扑簌抖落的哗啦水声，紧接着两声急促踩在湿地面上的脚步声靠近，一把塑料折椅发出轻微挪动受力响后归于安静。此时一段极轻、低沉压迫的合成器 pad 伴随长时间低频氛围嗡嗡音效悄然铺底，弦乐低音部克制地缓慢拉紧。密集的暴雨敲篷声中隐约夹杂着一声极其细微干脆的皮质枪套暗扣弹开轻响。随着瓷杯底与塑料桌面平滑推摩发出一声细轻滑动响，所有大雨杂音与低频铺底自然压低退让，男子 1 用平常得像闲聊、却微微下沉的平稳语调说道：“喝了再动手。” 话音刚落，四周原本密集敲打的雨声与低频嗡鸣突然骤停抽空半拍，瞬间被一声低沉厚重的闷响拖入隔绝感极强的闷塞声场，所有环境雨声变得遥远沉闷仿佛隔着厚水墙传来，唯留一缕极细微的尖锐嗡鸣与她极轻的吸气吞咽声。女子 2 压紧声带，用压哑却死撑平直的气声缓缓问道：“你早就知道了……为什么不躲。” 结尾雨声在低暗合成器余韵中缓慢回涌并停留两秒渐弱。
```
