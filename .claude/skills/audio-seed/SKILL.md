# 声音层·Doubao-Seed-Audio 1.0 音效与配乐设计

来源标注：【官方示例】用户提供的 Doubao-Seed-Audio 1.0 五套完整工程样板；【官方】Seed-Audio 1.0（100ms 时序协同与单次约 2 分钟统一音频建模）；【衔接库】`.claude/skills/cam-transitions/references/情绪音效与声音桥设计库.md`。

## 边界
- **负责：**
  1. **提示词转音效（Prompt-to-Audio）：** 将 `Seedance 2.5` 视频分镜提示词、剧本正文或创意脚本，剥除全部画面/机位/`@图N` 后重铸为 `Doubao-Seed-Audio 1.0` 可直出的完整声音工程提示词；
  2. **独立配乐与音效设计：** 角色音色档案定制、器乐配乐编制与动态开关、时序音效拟音链、空间混响与通信信道失真设计。
- **不负责：** 视频构图、焦段、机位、运镜、`@图片N` 绑定、时间戳 `分镜一/二/三`（→ `exec-seedance25` / `cam-shot`）；静态生图提示词（→ `art-image`）；剧本剧情改写与台词增删（→ `script-shanyin`）。
- **互斥与绝对隔离铁律：**
  - **严禁把视频提示词句式带进音频稿：** 输出文本内禁止出现 `不要背景音乐`、`{}` 花括号、`分镜一（0-4秒）`、`@图1`、`rack focus / anamorphic` 等视觉与视频语法；也禁止写成 `[音效：xxx]` 中括号舞台提示。
  - **严禁运行视频验错脚本：** 本库产物**不要**用 `tools/check_errors.py` 检查（视频库禁止“像……一样”“咚”字双引号及配乐，而这恰是 `Doubao-Seed-Audio 1.0` 的原生核心语法）。
- **必读联动（单向借用声学戏剧脑）：** 必须同时读取 `.claude/skills/cam-transitions/references/情绪音效与声音桥设计库.md`，复用其中的 **“先静后炸”三不无脑加铁律、Material＋Action＋Space 材质拟音公式、`Audio Ducking` 语音让位、`Muffled / Ear Ringing` 主观心理逻辑与 `J-cut / L-cut` 声桥构想**，再用本库转译为 `Doubao-Seed-Audio 1.0` 原生中文声学写法。

## 一句话原则
**像声音导演写一条“连续听觉长镜”，不用代码标签，不夹半句视觉画面。** 上段先定死谁的声音什么质感，下段用“配乐编制＋时序音效＋带信道与喘息的 `“台词”`”流式串联，平时极克制留白，关键处配乐与重击才一锤定音。【官方示例】

## 一、Doubao-Seed-Audio 1.0 硬格式结构（两段式）

### 1. 上段：人物音色档案表（有开口就必列，每角色占一行，段尾空两行）
固定句式：`<角色名> 是<年龄段＋性别>[，方言/语种]，嗓音<物理发声质感词>，<气质/戏剧风格词>`
- **常用音色维度库：**
  - **年龄与语种/方言：** 青年男性 / 中年男性 / 中老年男性 / 老年男性 / 青年女性 / 中青年女性 / 55 岁左右的中年女性 / 大妈 / 35 岁左右的青年男性；`台湾口音`、`TVB 普通话`、`英语`。
  - **声带质感：** `嗓音低沉`、`浑厚`、`嗓音偏尖细`、`轻微鼻音`、`气泡音`、`沙哑`、`略带沙哑`、`声音温和`、`嗓音柔和`、`播音腔`、`有机械感`、`磁性`、`音调稍低`。
  - **气质与演法：** `沉稳`、`威严`、`庄重`、`张扬`、`知性`、`苍老`、`成熟`、`谦逊`、`严肃`、`凶狠冷酷`、`探案类电视剧风格`。
  - **旁白与功能音：** `旁白`、`播报员`、`广播员` 也必须按完全相同句式在顶部定义。【官方示例】

### 2. 下段：纯自然中文连续声景正文（无时间戳、无中括号、全中文双引号 `“……”`）
把配乐、环境、音效、声道处理与对白按时间顺位编织进连续段落：
- **时序连接词库（支持 100ms 精度顺位进场）：** `开头由……` → `先是……` → `紧接着……` → `然后……` → `随后……` → `再出现……` → `最后……`；夹入对白流时用 `对话中夹杂着……`、`对话后先是……`、`句首伴随着……`、`句中夹杂着……`、`句尾伴随着……`、`其中夹杂着……`。【官方】【官方示例】
- **配乐（BGM）三要素写法（严禁只写“悬疑背景音乐”）：**
  1. **铺底与主奏分工：** `音乐以<铺底，如合成器 pad / 低沉合成器 pad>铺底，同时有/以<主奏乐器，如马林巴 / 竖琴 / 铜管组 / 弦乐组 / 中国大鼓>为主奏，加入<合奏声部>，整体情绪<紧张悬疑 / 诡异黑暗 / 沉闷激烈>`。
  2. **段落演进与突停：** 随剧情转折显式写 **`此时音乐转变，……主奏，……作为 pad 使用`**、**`……与定音鼓渐强`**、**`伴随着一阵警报声，音乐停止`**、**`音乐停止。伴随着环境音起，……到结束`**。【官方示例】
- **音效与拟音（SFX & Foley）四要素写法：**
  - 格式：**量词**（`一声` / `两声` / `连续两声` / `一阵` / `一阵持续的` / `一阵轻微的`）＋ **质感与空间**（`沉闷的` / `尖锐的` / `清脆的` / `空旷的` / `重力度`）＋ **具体发声体或拟声参照**（生活物写“材质＋动作＋地点”，特效/转场音用 **`类似于“咚”/“咻”/“唰”/“呼”的……特效音`**）。
  - 继承 `情绪音效与声音桥设计库.md` **留白铁律**：对白推进与平淡日常只用轻弱环境音（`鸟叫声`、`微风`、`布鞋踩木台阶`、`展开纸张`）垫底，绝不每句话都硬塞鼓点与爆炸；单段生成建议控制在约 2 分钟以内。【衔接库】【官方】
- **台词、副语言与声学媒介写法：**
  - 台词一律使用中文双引号 **`“……”`**。
  - **空间与通信处理写在台词前：** `声音有混响感` / `声音整体带有明显回响` / `通过电话回应，声音经过处理，显得有些遥远和失真` / `接着声音像从电视机传来，带有轻微回响` / `接着声音像从对讲机传来` / `带有回响效果`。
  - **情绪变档与截断控制：** 说话中可分段插叙音量与语速变化（`接着音量提高，一字一句地说道：“……”`、`语调放低，缓和地喘气：“……”`）；悬念断口显式写 **`句首有截断感`** 或 **`话语在结尾处被截断`**；非台词人声写清发声状态（`发出一声沉重的叹息`、`先吸一口气`、`发出痛苦吞咽声音`、`错落有力的呼喊`）。【官方示例】

## 二、视频提示词 / 剧本 ➔ 音效设计（Prompt-to-Audio 五步协议）

当用户丢来一段 `Seedance 2.5` 分镜提示词、视频脚本或“帮我把这个提示词转成音效配乐设计”时，按下列五步洗净重铸：
1. **剥离视觉层：** 一刀清掉 `@图片N`、摄影机与镜头型号、滤镜、`24fps`、构图走位、`分镜一（0-4秒）`、`【全局影像与风格】` 与 `【保护项】不要背景音乐`。
2. **锁定音色与信道：** 抽出所有说话人、人群噪点与画外发声设备（电话/广播/对讲机/电视），逐个补全上部《人物音色档案表》（原视频提示词漏写的嗓音特质按性格补全）。
3. **转译音轨与动作声源：** 把视频里的“推门、拨枪、撞击、拉焦变闷、切镜遮挡”以及英文词 `BRAAM / Reverse Riser / Suckback / Low Drone / Windy Swish / Muffled / Audio Ducking / J-L cut`，全部按 `references/音效武器库映射与配乐编排库.md` 翻译成 `Doubao-Seed-Audio 1.0` 的纯中文时序拟音＋声桥句子；同时补全**原视频因禁音乐而留白的配乐弧线**（进→转→渐强→停，若原片是极简纯写实无音乐戏则显式标注全片无音乐仅用环境底噪与 Foley）。
4. **控制密度（反喧宾夺主）：** 对白核心句前主动作底噪让位（压低环境与配乐让出人声），只在情绪拐点/冲突撞击处落重音与打击乐渐强。
5. **合规自检再交付：** 用下面的清单逐条过完再输出。
