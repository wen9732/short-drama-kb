## 二、图像资产（`art-image`）→ 视频母图前置桥接铁律

在进入视频提示词前，核对角色与场景母图是否满足以下 **3 项动画工业前置标准**（详见 `art-image/references/生图提示词手册.md` 四之（四））：
1. **角色设定卡（「1+3+cm身高标尺」全头尾入画版）**：左侧 `1/3` 为性格微表情特写胸像，右侧 `2/3` 为同一角色的**全身正、侧、背三视图**；**双耳尖至脚底、尾巴末端（或昆虫触角顶端）必须 100% 完整入画且四周留白**，最右侧附带**垂直厘米身高标尺（如 `158cm / 178cm`）**。
2. **多物种同地平线群像比例卡**：同剧跨体型物种（如水獭、羊驼、灰熊、小鹿、蜜獾、小熊猫，或灰兔与小鹿）必须在同一张白底横版图的同一水平地面并排站立，锁死绝对体量差；视频内文同步写死**量化身高差锚点**（如 `夏夏站立时头顶约到班尼下巴位置，严禁摄影机自动缩放角色对齐人脸`）。
3. **九宫格表情矩阵 → 视频动态转化**：静态 `3×3` 表情图仅作特征锚点；视频严禁做“静态表情硬切”，必须转化为 **「五阶段时间轴＋八通道器官联动」**（见 `references/拟人动物与非人IP视频表情动作系统.md`）。

## 三、去真人化清洗（十洗八留）与导演提示词五大提纯铁律

### 1. 去真人化「十洗八留」
- **十洗（除光谱 A 写实电影风保留胶片光学外，非真人动画一律洗除）：** ① 真人解剖皮肤词（毛孔/黑头/胡茬/法令纹/油汗）；② 现代真人妆造服装词（除非特定拟人设定）；③ 真人演员微表情词（苹果肌/咬肌/青筋暴起→改写为耳位/吻部/眼睑/胡须/触角/尾巴通道）；④ 物理摄影机穿帮词；⑤ 竖屏狗血豪门套路；⑥ **一刀切锁死“皮克斯/迪士尼”标签**；⑦ **把“给人类看的编导说理评语”写进提示词**（如“表情不是表情包”）；⑧ **混入 `<camera-motion>` 等 XML 代码标签或同镜多重冲突运镜**；⑨ **`@` 素材名双名粘连与配音张冠李戴**；⑩ **跨画风废词包串戏**（如误粘“中国高中校园/球场观众声/真人毛孔”）。
- **八留：** ① 动画十二法则（预备动作/挤压拉伸/跟随重叠/弧线运动）；② Patrick Lin 虚拟摄影三维布局与焦段心理学；③ 拟人动物/非人 IP 专属器官通道；④ 跨媒介图层遮挡与动态画风突变；⑤ 动画级无缝空间转场；⑥ 材质与流体物理交互（SSS/风场/水花/卡通火焰）；⑦ 台词发音四态隔离（开口同步/倾听微反应/半途抬掌打断/内心 OS 闭嘴）；⑧ 单母场景绝对空间坐标与反打背景互斥锁。

### 2. 导演提示词六大提纯铁律（以案例为训练原型，严禁连原稿缺点与冗余符号照抄）
1. **净版排版与符号铁律（最高优先级）**：
   - **顶部单次 `@`、下文零 `@`**：`@` 仅在开头角色/素材绑定段出现 **1 次**（若无需挂图则全篇零 `@`），**下方分镜正文中一律直写干净角色名（如 `暖暖妈`、`小豆包`），严禁在正文中频繁重复加 `@`**！
   - **去 `-` 横杠、去 `一、二、` 公文编号**：提示词正文中**严禁使用 Markdown 列表横杠 `- `，严禁使用 `一、二、三、四、五、` 等公文序号**，直接用干净的 `【板块名】` 与自然段落书写。
   - **干净整数秒时间码 `（0-5秒）`**：分镜时间统一写成 **`镜头1（0-3秒）：`、`镜头2（3-6秒）：`** 这种干净的整数秒括号格式，**严禁写 `00:15.5—00:18.0` 这类带双零冒号、长破折号或 `.5` 小数点的冗余时间码**！
2. **单条单母场景铁律**：15–30s 单条优先锁死 **1 个唯一母场景**；跨空间必须拆分为 **5 秒独立开门/升空转场节点**（如 `门框周边墙面先局部失焦渐变为室内材质`）。
3. **单点一次写死、全篇零复读（防 Token 稀释）**：空间轴线、身高差、反打背景互斥只在顶部写 **1 次**；删净与分镜重复的长篇剧情概述及 6–8 倍车轱辘补丁话，单条控制在 **1,500–2,500 字高密度指令**。
4. **跨节点换方案彻底清场**：当动作方案调整（如“砸电脑”改“拍合同”、“河马在场”改“厕所戏河马不在场”），必须把风场/光影/限制段里的旧方案残留词连根拔除，严禁自相矛盾。
5. **秒数三方绝对对齐与台词优先锁**：`分镜累加秒数 ＝ 内文总时长 ＝ 面板设定秒数`；显式声明 **`台词完整性优先于动作和运镜，严禁加速赶词或吞字`**，并为最长台词镜单独锁死秒数。
6. **复杂动作阶段强隔离与工程妥协**：长镜头内多动作必须写明先后完全停稳边界（如 `必先站稳停步→原地数手指→重走后再遇 NPC 挥手`）；跨幕躺地且后续需承重（坐身上/当桌面签字）的角色，统一锁死 **`全程胸腹贴地、脸朝下俯卧、圆滚滚背部朝上`**。
