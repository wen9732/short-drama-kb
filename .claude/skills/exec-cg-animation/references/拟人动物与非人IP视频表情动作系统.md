# 拟人动物与非人 IP 视频表情动作系统（八通道 × 物种滤镜 × 五阶段时间轴）

> **核心目标：** 彻底消灭拟人动物与非人 IP 视频的**“戴头套木偶感、站桩念词 AI 死板感、表情包式无由抽搐”**。基于《拟人动物视频表情系统 v1.0》与《路西的世界》《班尼打工日记》《唐阿虎求职记》实测数据提纯。

---

## 一、总控公式与三大底层铁律

$$\text{鲜活无 AI 感角色表演} = \text{角色底盘} + \text{触发刺激事件（声音/关键词先行）} + \text{情绪主导与八通道协同} + \text{五阶段动态时间轴} + \text{按美学光谱分级的可控夸张点睛}$$

1. **情绪不是静态脸谱，而是“从 A 状态被刺激推向 B 状态”的变化过程**：单写“伤心/愤怒/惊讶”必出木偶脸；必须写清 **`初始微状态 → 听见/看见什么具体刺激 → 哪个动物器官先动 → 面部与躯干如何跟进 → 尾段如何回落（Settle）`**。
2. **听觉/视线器官永远领先台词 0.2 秒（Organ-Lead Principle）**：拟人动物对环境的反应必须**耳尖、触角或瞳孔视线先动 0.2 秒**，随后头部、吻部与肩背重心才跟进，绝不能等台词念完才动耳朵。
3. **按美学光谱分级控制夸张度（严禁跨光谱乱套）**：
   - **【光谱 A 写实拟人电影风（如《班尼》）】**：走**死鱼眼冷幽默反差（Deadpan Contrast）**与写实克制微表情（半垂眼睑、单耳微挑、鼻腔轻呼气、胸口以下小幅摊手、手持蒲扇变速节拍），**严禁套用眼珠暴突或身体压扁**；
   - **【光谱 B/C 2D 软体生物与毛毡定格（如《路西》）】**：走**跨维度几何软体形变**（2D 菌伞开合、眼珠上翻引导视线、细长多足微颤）或 **`12fps` 手工定格不对称大小眼错位律动**；
   - **【光谱 D 迪士尼式 3D 卡通喜剧（如《唐阿虎》）】**：全面放开**卡通挤压拉伸（Squash & Stretch）**——允许`眼珠暴突、下巴脱臼式张嘴、胸腹脸踹成扁平再像弹簧反弹、身体如橡胶皮球弹滚、人肉板凳如压扁气球向两侧扩散与“嘭”地果冻回弹`。

## 二、拟人动物与非人 IP 八大控制通道（8 Control Channels）

每写一个核心反应镜，至少从以下 8 个通道中组合 **3–4 个可见物理动作**（彻底替代“眼神复杂、心情沉重”等抽象废话）：

| 通道编号与名称 | 解剖部位与精细控制词库 | 反死板与物种边界注意（参照 `REG-009~011`） |
|---|---|---|
| **通道 1｜眉区与额部毛流（Brow & Forehead Fur）** | 内眉上挑（委屈/求饶）、双眉死死下压（凶狠警告，如胖虎瞪胖狼）、单眉高挑（狐狸调侃/怀疑）、眉心拧成川字结（河马烦躁爆发前兆）、额头毛流随抬眉舒展 | **无眉物种禁令：** 鸟类、爬行类、无眉蘑菇怪或昆虫严禁强行画人类粗黑眉毛，改用**上眼睑边缘角度、额部羽毛/鳞片/触角根部起伏**替代 |
| **通道 2｜眼睑开合与眨眼节拍（Eyelids & Blink Rhythm）** | 半垂死鱼眼（班尼招牌疲惫打工人态）、眼睑骤然撑开露出完整眼白（震惊/听见“百来万”瞬间清醒）、下眼睑微抬眯成弯缝（胖虎谄媚赔笑/狐狸算计）、单眼快眨接双击眨眼（Double Blink 消化信息）、左眼慢闭右眼快眨两下（毛毡精灵不对称童趣） | 严禁全程不眨眼瞪视；在思考转折处加入 `快眨两次眼` 或 `眼皮狂跳（河马爆发前）` 是破除 AI 死板感的最强细节 |
| **通道 3｜瞳孔与视线落点（Pupil & Gaze Target）** | 视线死锁对方双眼/手部单据、眼珠先向声源斜瞥再转头（Eye-Lead）、瞳孔骤缩（恐惧/狠瞪警告）、瞳孔放大映出火光/报纸文字/圣洁轮廓光、视线心虚游移不敢对视、2D 生物眼珠直直向上翻引导镜头升空 | **铁律：** 每次开口或听话必须绑定**明确视线落点**（如 `边走边侧脸看着身旁的夏夏说`），严禁对着空无一人的前方空气说话 |
| **通道 4｜口鼻吻部与胡须（Muzzle, Nose & Whiskers）** | 鼻尖高频轻抽（嗅探/哭泣前兆）、鼻孔猛然扩张喷出两股白气（河马破门暴怒）、长吻部整体张合带动上唇胡须外展或下垂、嘴角单侧微勾（狐狸坏笑）、脸颊与肚皮同步鼓起蓄气（胖虎咆哮前）、捂胸咳出一小口卡通番茄汁（鬣狗卖惨） | **兽吻解剖铁律：** 犬科/狐狸/狼/虎必须让**整个口鼻吻部（Muzzle）**参与张合与牵拉，严禁在长兽吻前端贴一张僵硬的真人小嘴 |
| **通道 5｜耳位角度与耳尖动态（Ears & Ear Tips）** | 双耳瞬间绷直竖起（警觉/听见金钱关键词）、双耳向后紧紧贴平压低（胖狼挨瞪秒怂/心虚/恐惧）、单耳朝画外声源偏转（听觉先行）、长兔耳随叹气无力垂落贴住肩头（班尼疲惫）、耳尖高频轻抖（憋笑/羞怯） | 耳朵是拟人哺乳动物的“第二双眼睛”，但**严禁无因果胡乱摇耳**，必须绑定具体声音或情绪转折 |
| **通道 6｜尾巴 / 昆虫触角 / 菌伞等物种专属通道（Tail / Antennae / Cap）** | **哺乳类尾：** 尾巴夹紧贴腿（恐惧）、尾尖轻拍地面（不耐烦）、尾巴高频摇晃（胖虎抱大腿谄媚）、大尾自然垂摆；<br>**昆虫触角（如西装蟑螂老板）：** 头顶两根细长触角随踱步产生自然惯性摆动，**强调语气或指人训话时触角微微向上扬起**，被打断时触角向后微缩；<br>**2D 菌类/软体生物：** 顶部荷叶边菌伞轻轻开合呼吸，伞缘发光孢子随情绪微闪 | **无尾物种禁令：** 熊、蛙、短尾兔（仅小圆尾团）或穿封闭西装裤不露尾的角色，**严禁生成长尾巴摇摆**，改用肩背重心或耳朵/触角通道 |
| **通道 7｜头颈倾角与缓冲（Head, Neck & Cushion）** | 歪头 15 度慢半拍思考（胖狼憨笨态）、脑袋猛地往回一缩（挨瞪秒怂）、下巴微收眼神上挑、转头时的轻微过冲与回弹缓冲（Overshoot & Settle）、脸朝下趴地时仅把脑袋轻轻偏一点小幅闷声说话 | 转头切忌匀速机械旋转；加入 `先转眼珠 → 头部快速跟进并轻微过冲 → 回落停稳` 立刻拥有动画生命力 |
| **通道 8｜肩背重心、手部节拍与全身弹性（COG, Hands & Squash-Stretch）** | 叹气时双肩下榻胸腔内收、惊喜时重心前倾、胸口以下小幅克制摊手（班尼）、抬起单掌干脆打断对方说话（坤老板）、一手摇蒲扇随情绪变速直至停在胸口（班尼妈）、跪地双手高举/合十哀求（卖惨手势白名单）、全身受击扁平挤压与果冻回弹（光谱 D 专属） | 手部严禁无意义乱挥；在长独白中给手部绑定一个**物理节拍器道具**（如蒲扇、维修单折痕、手指点算五根手指） |

## 四、五阶段动态表情时间轴（5-Stage Dynamic Rhythm）与 10 大变脸公式

### 1. 单镜头内部五阶段时间轴（彻底根治“表情先于事件发生 `REG-001`”）
任何带情绪转折的镜头（哪怕只有 3–4 秒），内部必须按以下 5 个相位顺次展开：
1. **`0%–15%` 基础状态（Base State）**：角色处于上一镜延续的生理常态（如班尼半垂眼皮走动、胖狼脸朝下趴地呆看、母亲低头看维修单）。
2. **`15%–30%` 刺激进入与器官先行（Stimulus & Organ-Lead）**：**画外音、关键词、对方动作或突发声响先进入** → 角色的**耳尖、触角或眼珠视线提前 `0.2 秒` 转向刺激源**，手部原有动作（如摇蒲扇、敲键盘）瞬间停顿！
3. **`30%–55%` 情绪起势（Emotion Rise）**：眉区、眼睑、口鼻吻部与肩背重心同步启动（如双眉拧紧、吸气胸口鼓起、手指收紧捏弯纸张边缘）。
4. **`55%–80%` 峰值与可控夸张（Peak & Controlled Exaggeration）**：按所属美学光谱释放高点——
   - **光谱 A（写实电影风）**：`双耳瞬间绷直 Hold 0.3 秒 + 瞳孔瞬间锁死对方五官 + 短促吸气` 或 `主观镜头瞬间为对方加上温柔圣洁轮廓光`；
   - **光谱 C（定格风）**：`左眼慢闭、右眼急速眨两下，双臂卡重拍定格高举`；
   - **光谱 D（3D 卡通风）**：`Double Take（双击回看：先扫过→顿0.2秒→猛地甩头回看眼珠暴突）`、`Overshoot（身体后仰过冲再回弹）` 或 `咆哮掀起环形空气压缩波`。
5. **`80%–100%` 回落与余韵（Settle & Hold）**：绝不在最高点僵硬切断！加入 `一次慢眨眼、鼻腔长呼一口气、肩膀微塌回落` 或 **`完整保留 1–2 秒现场安静呼吸微动`**（如河马吼完“别嚎！拿证据！”后的 2 秒静止呼吸反应）。

### 2. 高频拟人情绪“从 A 到 B”变脸公式速查（10 大实战微公式）
1. **【精明算计 → 秒切职业假笑（狐狸/职场人）】**：`听到利益关键词耳尖先动 → 眼底闪过一丝精光（0.3s） → 0.5秒内眼尾弯起、嘴角上扬切回体面热情的职业微笑，双手礼貌前引`。
2. **【真诚同情 → 挨狠瞪 → 秒怂缩头改口（《唐阿虎》第三幕同镜快摇）】**：`俯卧侧脸呆呆点头小声说“好惨啊” → 感受到旁侧凶狠目光（胖虎双眉死压、瞳孔骤缩） → 呆眨一下眼、双耳瞬间向后贴平压低、眼珠快转急忙改口“但是我们饿得更久噻！” → 脑袋猛地往回一缩露憨厚傻笑`。
3. **【疲惫敷衍 → 听见巨款瞬间清醒（《班尼》手术室唤醒）】**：`半闭眼视线虚焦漂浮、耳音发闷 → 听见“百来万”三字瞬间：眼睑猛然撑开、焦点死锁对方五官、双耳“唰”地绷直立起、右手猛地抓紧身下床单`。
4. **【暴怒踹人 → 遭抱腿讨好 → 无奈心软（《唐阿虎》河马）】**：`鼻孔喷白气叉腰怒视 → 低头看见抱紧自己大腿满脸堆笑高频摇尾的胖虎 → 紧锁的眉头慢慢舒展、眼神柔和下来、嘴角浮现一丝无奈心软，转身一屁股坐到胖狼背上`。
5. **【温柔甜美 → 平静吐出恐怖黑话（《班尼》夏夏反差公式）】**：`修长脖颈微倾、大杏眼弯成温柔月牙、声音轻柔甜美地挽住对方手臂 → 表情毫无凶相变化，用最平静的温柔语调说出“麻辣兔头，在四川老火了”`。
6. **【愤怒质问 → 半途抬掌干脆打断（《班尼》坤老板）】**：`对方刚说到“我扫你码——”半途 → 角色不听完直接抬起单只手掌向前做出干脆的制止手势，同时开口无缝打断：“扫什么码？客人差评写着……”`。
7. **【盲目狂喜 → 旁人憨憨补刀 → 石化崩溃（《唐阿虎》第四幕砸电脑）】**：`刚砸碎电脑胸口剧烈起伏、骄傲摊手炫耀自己更惨 → 听见地上同伴慢吞吞补刀“你至少先把简历备份了嘛” → 挥舞在半空的手臂瞬间僵死、眼珠缓缓下移看向满地碎片、嘴巴慢慢张大转为绝望哭喊`。

## 五、台词发音与旁白 OS 四态物理隔离锁（专治乱动嘴与口型错位）

在每一个含人声的镜头里，必须从以下 4 种发音状态中**明确标注 1 种**：
1. **【状态 A：现场开口对白（Lip-Sync Dialogue）】**：写明 `现场实际开口说出，吻部/嘴唇正常完成同步口型，说话时视线死锁{目标角色}`。
2. **【状态 B：倾听反应（Listening State）】**：写明 `本镜不说话，嘴唇保持自然闭合或微张呼吸，仅靠耳尖微动、眨眼与眼神变化做出倾听反应`（严禁倾听者跟着说话者一起动嘴）。
3. **【状态 C：内心独白 / 旁白（Inner Monologue / Voiceover OS）】**：**最高频防翻车点！** 必须显式写明：**`“{台词}”属于内心独白（OS），角色在画面中嘴唇完全闭合不动，严禁做说话口型，完全依靠眼神游移、端水走路或微表情传达内心戏`**（见 `N02 片段八` 班尼端冰水内心独白）。
4. **【状态 D：打破第四面墙面向观众 / 画外系统音（Fourth-Wall / Off-Screen SFX）】**：
   - 打破第四面墙（`N02 片段七`）：`班尼从看向夏夏的姿态侧过头，正面直视镜头（面向观众）说出：“{台词}”，这句话是对观众说的，不是对夏夏说的`；
   - 画外系统音/画外喊声（如“支付宝到账三万元”或画外“动手”）：`该声音在现场实际响起，角色听见后立刻做出耳朵竖起/瞳孔放大反应，但画面内无人对此做口型`。
