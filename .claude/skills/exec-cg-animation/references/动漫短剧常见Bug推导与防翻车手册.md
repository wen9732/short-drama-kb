# 3D/2D 动漫短剧与拟人 IP｜常见 Bug 推导、高动态卡通物理 VFX 与防翻车手册

> **核心原则：** 案例原稿是**训练数据的原型**，用于推断底层机制、让我们的导演提示词更加完美，**绝不能把原稿测试过程中的失败节点、跨节点残留矛盾或冗长车轱辘话一并抄进来**。本手册汇总了从《动物城 3DCG 错误汇总》、《动物城》测试稿、`N02 班尼打工日记` 30 节点迭代及 `N03 唐阿虎求职记` 17 节点迭代中推导出的 **6 大类 35 项常见 Bug 根治方案** 与 **7 大高动态卡通物理 VFX 写法**。

---

## 一、6 大类 35 项常见 Bug 病根推导与标准化根治总表

### （一）提示词语法、标签污染与注意力稀释类 Bug（`Bug-01`～`Bug-05`）

| 编号 | 翻车现象与病根推导 | 标准化根治写法（写提示词直接照此执行） |
|---|---|---|
| **Bug-01** | **混入 `<camera-motion>` 等残余代码标签或劈裂焦段词**：测试稿出现 `5<camera-motion>crane_up</camera-motion>0mm`（把 `50mm` 劈裂）且同镜混写 `crane_up` 与 `Push In`，导致镜头抽搐 | **纯自然中文＋精选英文工业词直写运镜**，彻底删净 `<camera-motion>` 等尖括号标签；**每个镜头只保留一条主要运动路径**（如 `50mm近景，沿视线方向缓慢前推`），严禁同镜既升摇臂又前推又横移。 |
| **Bug-02** | **`@` 素材名双名粘连、正文频繁重复 `@` 与配音张冠李戴**：写成 `@动物群像动物群像参考`，或在下方分镜正文里每提一次角色就加一次 `@暖暖妈 / @小豆包`（甚至带入 `-`、`一、`、`00:15.5—00:18.0` 等冗余编号符号），干扰模型自然语义读取 | **顶部单次绑定、正文零 `@` 净版铁律**：<br>① `@` 仅在顶部【角色】区绑定 **1 次**，**下方分镜正文一律直写干净的角色名（如 `暖暖妈`、`小豆包`），严禁在正文里重复加 `@`**；<br>② **全篇去掉列表横杠 `- ` 与 `一、二、三、` 公文序号**；<br>③ **时间码统一用干净的整数秒括号 `（0-3秒）`、`（15-18秒）`**，严禁写 `00:15.5—00:18.0` 这种双零冒号小数点格式！ |
| **Bug-03** | **把“给人类看的编导说理/教学评语”写进提示词**：写 `“表情不是表情包，必须由剧情触发”`、`“前景中景背景都在发生事情但为主戏服务”`、`“这个镜头重点是先用手讲故事”`——模型看不懂议论文只会发呆 | **100% 翻译为可见物理动作与器官位移**！删掉所有“这个镜头的重点是/旨在表现/不是表情包”等评语，直接写：`右手手指一点点收紧，将维修单纸张右缘捏出弯曲折痕`。 |
| **Bug-04** | **跨画风废词包串戏污染**：拟人动物戏误粘 `“人物皮肤保留毛孔和指纹……真实中国高中校园……球场观众声……Ghibli and Makoto Shinkai style”`，导致毛发变塑料肉皮、服装串戏 | **严按【光谱 A～E】纯净定调**：拟人动物戏彻底删净 `皮肤毛孔/指纹/真人人类/球场观众声` 及跨画风英文词串，并在首句锁死 `画面内禁止出现真实人类`。 |
| **Bug-05** | **7000 字“补丁叠补丁”车轱辘话引发后半段失忆（Token Dilution）**：翻车后不删旧文直接叠 `【重点修正版】【重点加强】`，同一句站位重复 6–8 遍，或先写 2000 字剧情再写 3000 字分镜复述 | **单点一次写死、全篇零复读**：空间坐标、身高差、反打背景互斥只在顶部写 **1 次**；删掉与分镜完全重复的长篇剧情概述，单条控制在 **1,500–2,500 字高密度有效指令**。 |

### （二）空间坐标、机位轴线与跨场景跳变类 Bug（`Bug-06`～`Bug-12`）

| 编号 | 翻车现象与病根推导 | 标准化根治写法（写提示词直接照此执行） |
|---|---|---|
| **Bug-06** | **15 秒单条强行跨“室外广场 → 室内门店”两张不同环境母图**：单次生成同时激活两套建筑空间，导致门内外空间黏连坍塌、主戏时间被吃光 | **【单条单母场景铁律】** 15–30s 单条优先锁死 **1 个唯一母场景**；必须跨空间时，用 `N02 片段四` 的**“5 秒独立开门转场节点（门框周边墙面先局部失焦渐变为室内材质）”**单独生成！ |
| **Bug-07** | **把“画面左侧/右侧”当成物理固定位置（`AC-04`）**：切反打镜头后画面左右翻转，AI 在店里重造第二个大门或让家具乱飞 | 开篇先锁死一条**绝对物理基准轴**（如 `以从店深处服务柜台面向门口为准：左侧为靠窗卡座区，右侧为储物架` 或 `陆地沙滩侧 → 班尼 → 夏夏 → 海面侧`）。 |
| **Bug-08** | **把“从柜台方向拍”写成“摄影机在柜台内侧”（`AC-05`）**：AI 直接把外面的顾客角色也关进封闭柜台内部出不来 | 明确写清观看区域与被摄物的物理分隔：**`镜头位于店深处服务柜台前方的通道内侧，朝门口方向平拍`**。 |
| **Bug-09** | **使用 `C1 / C2 / C3 / D` 等抽象机位代号（`AC-P04`）**：AI 不懂字母代号代表什么方位，随机乱切导致越轴 | 禁用字母机位代号；每镜直接用自然语言写清**“相对于角色与母场景的方位＋朝向”**（如 `位于两人斜前方偏左，从海面侧朝陆地方向斜拍班尼`）。 |
| **Bug-10** | **双人海边散步单人反打时“两人背后都是同一片海”穿帮** | **单人反打背景互斥死锁（`N02 片段六`）**：`拍靠海的夏夏时（从陆地朝海拍），背景必须是虚化海面与夕阳浪线；拍靠陆地的班尼时（从海面朝陆地斜拍），背景必须是虚化沙滩、椰树与岸上植物，严禁班尼单人镜背后出现大片海面`。 |
| **Bug-11** | **多镜对话中 AI 为“自动优化构图”擅自移动坐着的主角（`#24/#25`）** | 写死**【母场景唯一锚点与“机位动 ≠ 人物动”法则（`N02 片段十四`）】**：`母场景参考图是唯一真实固定空间；班尼从第一帧起全程固定坐在右侧绿色卡座木桌外侧座椅，所有镜头只是摄影机在同一房间内改变角度，严禁换桌、换边或翻转餐厅方向`。 |
| **Bug-12** | **海滩散步写了一句“海边步道”，脚下长出水泥路和铁栏杆** | 正反双锁（`N02 片段五`）：**`两人始终走在真实的浅色沙滩湿沙边缘，靠近浪线但不踩进海里；画面中严禁出现任何步道、人行道、石板路、柏油路、木栈道、台阶或栏杆`**。 |

### （三）角色比例、持续姿态、次要角色蒸发与位移跳步类 Bug（`Bug-13`～`Bug-18`）

| 编号 | 翻车现象与病根推导 | 标准化根治写法（写提示词直接照此执行） |
|---|---|---|
| **Bug-13** | **一高一矮搭档切镜后变成一样高**：摄影机为了把两张脸框在同一水平线自动缩放角色 | 写死**量化身高差锚点（`N02 片段六/十四`）**：`夏夏/叽米站立时头顶始终约到班尼下巴位置；摄影机必须适应真实身高差，严禁为对齐两张脸自动缩放角色比例；矮个子看高个子时视线自然略微上抬`。 |
| **Bug-14** | **角色躺地装死选“四脚朝天仰卧”，导致后续坐身上/摊合同签字穿模** | **跨幕持续躺姿工程妥协（`N03 片段二～八`）**：若躺地角色后续需承受跨坐或当桌面签字，统一锁死为 **`全程胸腹贴地、脸朝下俯卧、圆滚滚背部朝上，绝不翻身仰卧`**，仅露半边侧脸靠眼珠转动和耳朵后压演戏！ |
| **Bug-15** | **角色跪在躺地同伴旁激动哭喊，被 AI 演成“殴打躺地同伴”** | **手势白名单＋禁击打黑名单（`N03 片段二`）**：`胖虎跪在胖狼右侧保持半个身位距离，绝对不能拍打胖狼；卖惨时手的动作只能是【朝天举手 / 抱头 / 朝门口伸手 / 双手合十哀求 / 擦泪】，严禁做成砸地、拍地、拍胖狼、捶胖狼`。 |
| **Bug-16** | **主角走动后，同场的次要角色凭空蒸发（`AC-01`）** | **次要角色在场空间锚定**：多角色同场时，不作为主体的角色必须保留一句画内/画外锚点（如 `熊仍站在原门口过道侧后方虚焦背景中目送`）。 |
| **Bug-17** | **跨空间瞬移与缺失“牵手→松手→离画”中间态（`AC-03`）** | **写清连续物理位移链**：`母亲左手牵着孩子右手 → 转头看单据分神，左手手指自然松开 → 孩子抽回手迈步朝右侧跑出画面右缘 → 母亲低头看见空手一惊、转头朝画外呼喊`。 |
| **Bug-18** | **长镜头里把“看钟数手指”和“跟 NPC 挥手打招呼”揉成四不像** | **长镜头阶段强隔离（`N02 片段十三`）**：`班尼看到墙钟后必须双脚完全站稳停住 → 原地低头抬手数手指 → 放下手重新迈步 → 走出几步后才遇到叽米挥手打招呼；【强制隔离：看钟与数手指期间严禁叽米提前挥手】`。 |

### （四）拟人动物微表情、视线落点与“去 AI 死板感”类 Bug（`Bug-19`～`Bug-24`）

| 编号 | 翻车现象与病根推导 | 标准化根治写法（写提示词直接照此执行） |
|---|---|---|
| **Bug-19** | **表情先于刺激事件发生，或全程像戴头套木偶站桩念词（`#7` / `REG-001`）** | **五阶段动态＋器官先行铁律**：`① 基础状态 → ② 刺激进入（声音/关键词先入，耳朵与视线提前 0.2s 转向声源） → ③ 眉眼吻部起势 → ④ 峰值可控夸张 → ⑤ 眨眼呼气回落 Settle`。 |
| **Bug-20** | **眼神空洞无灵魂、或转头对着没人的空气说话（`AC-02`）** | **说话时机＋视线落点双绑定**：每句台词必须写明`边走边侧脸看着身旁的 X 说` 或 `停下脚步抬头直视右前方柜台后的 X 说`。 |
| **Bug-21** | **装饰性动物小动作泛滥抢戏（胡乱摇尾压耳、片尾硬加尾巴扫倒立牌 `错25/26`）** | **器官动作因果制**：所有耳/尾/触角动作必须由具体刺激触发并服务角色性格（如蟑螂老板强调语气指人时`头顶两根细长触角微微上扬`）。 |
| **Bug-22** | **违背物种解剖结构：给无眉物种画粗眉、给无尾物种写长尾摇摆（`REG-009~011`）** | **严守物种解剖边界**：犬科/狐狸/狼让整个**长口鼻吻部**参与张合；无眉物种靠**上眼睑与额部毛流/羽冠**演戏；熊/河马/蛙/短尾兔改用**肩背重心沉降、鼻孔喷气或长耳摆动**替代长尾。 |
| **Bug-23** | **单人长台词独角戏坐着不动像新闻播音员** | **手持道具情绪节拍器法（`N02 片段十五` 蒲扇法则）**：一手拿手机贴耳、一手拿蒲扇全程不换手，把扇风速度绑在情绪上（`慢扇 → 快扇 → 核心质问句蒲扇彻底停在胸口不动 → 气笑后恢复慢扇`）。 |
| **Bug-24** | **反应镜头写“失望表情停留好几秒”导致画面像卡死（`AC-08`）** | 改写为**微小的决策动作链**或直接切 **`85mm 手部捏紧纸张边缘轻微弯曲` 的 Insert 特写**。 |

### （五）道具连续性、文字/屏幕防乱码、手部防穿帮与跨媒介合成类 Bug（`Bug-25`～`Bug-29`）

| 编号 | 翻车现象与病根推导 | 标准化根治写法（写提示词直接照此执行） |
|---|---|---|
| **Bug-25** | **白底角色三视图/设定板直接穿帮出现在视频镜头里（`AC-09`）** | 在【参考素材职责】写死：**`角色设定图只锁定几何头身比、毛发材质与服装配色；座位/比例参考图只锁定初始左右关系与距离；严禁把任何参考图直接生成为白底设定板或三视图拼图`**。 |
| **Bug-26** | **纸张文件、报纸、合同与电脑屏幕出现外星乱码伪汉字** | **分级留白零乱码法（`N03 片段五/七`）**：① 特写合同/报纸`只保留一行超大清晰黑体中文「劳动合同」（或四行大字标题），其余区域全部留白，禁出任何小字表格`；② 电脑拒绝信屏幕`只显示整齐排列的邮件卡片图标与醒目巨大的红色叉号，禁出小字与英文，停留不超 2 秒`；③ 普通手持表格`只保留白色表格纸视觉印象，不生成可辨识文字`。 |
| **Bug-27** | **递接手机或展示手机屏幕时手部多指畸变、UI 穿帮（`#12`）** | **手机防穿帮三解法（`N02 片段三/六/七`）**：① 不看屏幕时只拍`手机背面`，屏幕朝向角色本人；② 边走边给旁人看屏幕时，`不要把手机递给对方接走！持机者自己拿着手机向对方倾斜置于两人之间，对方只伸一根手指轻滑两下`；③ 拍账户余额飙升时，锁死`固定方框、等宽字体、完整金额从 12,342元 整体连续递增至 999,999元 停 0.4 秒，禁单字符滚筒乱跳`。 |
| **Bug-28** | **同场出现两台同类道具（如两台笔记本电脑）被模型混成同一台** | **双同质道具物理隔离锁（`N03 片段五`）**：`鬣狗的电脑在行李车上，屏幕完好，全程由鬣狗双手持有绝不掉落或裂纹；胖虎的电脑从胖狼旁边的旧背包拉出，深灰色厚重磨损，胖虎只摔自己的电脑；两台电脑严禁互换、复制或融合`。 |
| **Bug-29** | **3D 环境中嵌入 2D 手绘角色时，带入 2D 背景色块或半透明淡出消失** | **跨媒介共生四铁律（`N01 片段一/五`）**：`① 只提取2D角色本体，严禁带入参考图2D背景；② 前景3D叶片必须对后方2D生物产生真实物理遮挡与接触阴影；③ 渐进生成按“彩色斑块蠕动→分化局部伞盖短腿→完整2D软体生物”三阶演进；④ 离场只能随镜头推进滑出画框或被前景3D叶片遮挡，严禁半透明淡出`。 |

### （六）时长密度、台词同步、旁白 OS 闭嘴与局部返工类 Bug（`Bug-30`～`Bug-35`）

| 编号 | 翻车现象与病根推导 | 标准化根治写法（写提示词直接照此执行） |
|---|---|---|
| **Bug-30** | **单段塞入过多分镜与台词导致连珠炮赶词、吞字、口型错乱（`#7/#8/#27`）** | **锁死单段切镜与语速分配（`N02 片段六`）**：① 15s 段最多 **3–4 镜**，25–30s 段最多 **6–8 镜**（高密度喜剧蒙太奇除外）；② 显式写明 **`台词完整性优先于动作和运镜，若动作来不及优先缩短动作，严禁加速赶词或吞字`**；③ 为最长台词镜单独锁死秒数（如 `镜号02 锁死 5.3 秒`），普通句间只留 `0.2s` 自然气口。 |

## 三、【光谱 C 专属】手作毛毡/定格动画四大高阶物理与防翻车铁律（源自 `N04《囡囡的毛绒梦境》`）

> 写手作毛毡、黏土、纸艺、木偶定格动画时必守以下四条（填补原定格动画只写“12fps”导致镜头卡顿或声画割裂的盲区）：

1. **双帧率反差铁律（12fps 离散主体 × 24fps 丝滑机位）：**
   - 明确写死 **`画面内一切可动物体（角色肢体表情、绒毛摆动、载具颠簸、飘浮绒絮、甚至扫过的光斑）共用约 12fps 阶梯跳帧，每动作末端带 1 帧顿挫，无流畅补间、无运动模糊（速度靠帧间位置跳跃表现）；但推拉摇移环绕等机位运动全程丝滑连贯无跳帧`**，并加防误判声明 `角色顿挫不等于镜头顿挫`。
2. **全材质同构声学法则（非写实材质世界严禁现实机械声）：**
   - 当载具、轨道、家具全为毛毡/棉花/黏土/木头材质时，**严禁模型套用现实世界的金属撞击、链条咔哒、电机啸叫、轮胎打滑与金属混响**；一律按世界观材质重写拟音（如毛毡过山车/碰碰车全写为 `厚毛绒相互挤压的短促吸音噗叽闷响、棉花填充物压紧回弹的咕叽声、毛毡碾过轨道接缝的软塌塌咚·咚，无尖锐高频与金属余韵`）。
3. **非对称特征全角度死锁 ＋ 材质形变边界（不炸毛、不炸棉絮）：**
   - 角色若带不对称五官（如一大一小、一高一低错位哑光毛毡眼），必须声明 **`正面、侧面、俯视、倒悬剪影等任何角度都严禁被 AI 自动修成对称等高或发光亮眼`**；
   - 软弹触碰写 **`被摸头时整团酥软塌陷下沉再像充气一样回弹，绒毛始终平顺贴服不炸成刺球`**；载具碰撞写 **`接触点毛绒只向内压扁凹陷再整体回弹，绝不向四周炸出满天棉絮碎毛`**。
4. **跨物种同握道具左右分界防穿插锁：**
   - 当人类角色与非人/毛绒角色同时握同一根栏杆或把手（如过山车第一人称主观特写），必须写明物理分区：**`把手分左右两段各自被握紧——左半段并排排布甲的双手，右半段并排排布乙的双爪，中间留出一小截无人抓握的空隙作分界，人手与兽爪绝不交错穿插`**。
