## 三、Seedance 2.5 最新通用写法与五大实测防坑（v3.25 核心升级）

### 3.1 图片线 vs 视频线：双轨物理隔离
- **图片线（`art-image`）：** 写全五官、服饰织物、色板、颗粒；按模型处理否定词（`Nano Banana 2 / GPT-4o` 严禁写 `不要 X`，全改为正向描述；`GPT-Image-2` 句尾用 `Avoid:`）；严禁出现运镜和时间线词。
- **视频线（`exec-seedance25`）：** 主体外观交给 `@图片N`（或 `@人物图`）锁定，**仅在锁定段写一次并注明“只锁外貌/服饰/质感，不采用原图背景与静姿”**，严禁堆砌长段五官穿搭；严禁把带标注文字图或撞后静止结果图直接挂成过程参考。

### 3.2 四选一弹性常规工作流（不锁死单模，纯中文 `分镜一/二/三` 执行体）
1. **全局影调先定调：** 先核查 `情境化全局影调与器材美学库.md` 定下 A–H 方案，写全【全局影像与风格】四必填：① 色彩基调与高光滚落；② 实景光源方向与空气介质；③ 焦段景深分工；④ 肤质/织物/漆木玻璃物理肌理。
2. **按戏选对路线（详见 `通用写法工作流与示范.md` 与 `常规标杆补充示范集.md`）：**
   - **路线 A（常规叙事七段式）：** 有对白与微表情因果，10–15s 整数秒切片，用中文 **`分镜一（0-4秒）｜...`** 编排，台词用 `{台词内容}` 且先写说话前状态再写声音变化（禁套“用中文，……，说：”模板）。
   - **路线 B（一镜丝滑调度流）：** 借前景大物遮挡滑出、推物拉焦或光色连贯蜕变吃掉硬切（参 `补充示范 1` 片场黑框转场、`补充示范 2` 酒摊拨枪、`补充示范 4` 茶馆推茶遮挡）。
   - **路线 C（物理碰撞破坏流）：** 先交代斜坡/湿滑/盲区与车速动因，按 **挤压内凹 → 碎件飞溅 → 缝隙积灰滞后扬起沉降 → 回弹新态** 五层落地（参 `补充示范 3` 湿坡盲区碰撞物理链）。
   - **路线 D（无对白质感 TVC）：** 切 `分镜式写法.md`（去时间戳，按微距质感逐级递进）。
   - **真人情绪与首尾帧参考：** `补充示范 5` 演示首尾帧防重映与落拍钩子，`补充示范 6`（借鉴 `K05 玄关递伞` 机制）示范全片 15s 不破防克制情绪调度。
3. **段外【跨组衔接台账】：** 每组 `10–15s` 独立自足，不跨段写“同上一段/下面将发生”；段间怎么接、声音桥与视线出口统一写在段外【跨组衔接台账】。

### 3.3 实测防废片红线 & 五大反面警醒（交付前逐条核查）
- **五大反面警醒：**
  1. 左右矢量拧死打结（左来避让→右打把→车必须斜向右前偏滑，不可反拧左撞）；
  2. 速度与盲区动因不足（平路慢速硬撞像自杀，必须提前交代斜坡/湿滑/墙角盲区）；
  3. 前景遮挡方向搞反（放左侧前景而视野向右横移，物体只能左滑出画，不可能从右抹入）；
  4. 首尾帧重复 `@图N` 与缺下镜入口（重复点名易致双人同框；末镜须留动作/物件/声响悬念）；
  5. 台词空降画外前情（无画面铺垫却冒出脱离本段语境的“怎么不跑啊”等幻觉台词）。
- **硬禁词红线：** 分镜与保护项均**严禁出现 `摄影师/摄像师/摄影机/相机/三脚架/稳定器/无人机`**（统一改写为观察高度/肩扛纪实视感/平稳跟随/航拍视角）；`200mm+` 长焦强制背景虚化；每镜至少 3 秒、人物戏优先中近景与过肩，不拍面部毛孔特写。

## 五、交付自检与仓库维护脚本（全工具实操命令）

- **交付剧本/分镜前必跑验错自审：**
  ```bash
  python tools/check_errors.py 草稿.md --script 剧本.md --review
  ```
  检查 34 条实测高频错项（台词漏改加、乱序、`<>` 人名、机械模板、空反应镜、保护项、打斗废片词等）；v3.25 已原生支持英文 `SHOT NN` 与中文 `分镜一/二/三（A-B秒）` / `分镜一｜A-B秒` 格式识别，回复末附一行 `自审：查了什么，改了什么`。
- **借鉴过案例库后查重：** `python tools/check_copy.py 草稿.md`（查连续 ≥25 字雷同）。
- **入库/升版本后全库体检＋自动同步导出：**
  ```bash
  python tools/check_kb.py
  python tools/export_agent.py --all
  ```
  `check_kb.py` 校验七张工位卡字数预算、规则单源、案例零 `META` 与双端索引一致性、`check_errors.py` 自检；`export_agent.py --all` 同步重生成 `系统提示词/导出/` 下 5 份工位导出提示词及 `给其他AI的接入说明.md`。
