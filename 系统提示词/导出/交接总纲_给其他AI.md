## 三、Seedance 2.5 最新通用写法、五维光学底座、情绪音效与六大实测防坑（v3.27 核心升级）

### 3.1 图片线 vs 视频线：双轨物理隔离
- **图片线（`art-image`）：** 写全五官、服饰织物、色板、颗粒；按模型处理否定词（`Nano Banana 2 / GPT-4o` 严禁写 `不要 X`，全改为正向描述；`GPT-Image-2` 句尾用 `Avoid:`）；严禁出现运镜和时间线词。
- **视频线（`exec-seedance25`）：** 主体外观交给 `@图片N`（或 `@人物图`）锁定，**仅在锁定段逐行单绑一次并注明“只锁外貌/服饰/质感，不采用原图背景与静姿”**（严禁多人合并一行写 `@图片1、@图片2`），严禁堆砌长段五官穿搭；严禁把带标注文字图或撞后静止结果图直接挂成过程参考。

### 3.2 四选一弹性常规工作流（因戏五维光学底座 ＋ 中英工业词混写 ＋ 直出音效声桥）
1. **全局影调按戏定调（严禁千片一律套同款器材）：** 先查 `情境化全局影调与器材美学库.md` **A–H 预设**，用“影像观感参照……（禁写使用某摄影机拍摄）”写全五维底座——① **机身＋胶片/印片**（情感用 `Alexa 35/Mini LF`、冷峻悬疑用 `Sony VENICE 2 + 500T`、碰撞颗粒用 `RED V-RAPTOR + 250D`、风沙末日用 `skip-bleach`）；② **镜头玻璃＋滤镜＋`24fps/180°快门`**（温润用 `Cooke S4/i + 1/8 Black Pro-Mist`，碰撞碎片或都市疏离去柔光用 `Zeiss Supreme Prime`，怀旧用 `Panavision K35 + Glimmerglass`，粗粝变形拉丝用 `Atlas Orion / Panavision C-Series`）；③ **主辅光比与拒绝平面美颜打光**（留阴影肌理、克制反射不过曝、微弱眼神光）；④ **按景别分级焦段**（`35–40mm` 关系 / `50mm` 过肩 / `75–85mm` 情绪近景）；⑤ **全材质物理肌理**。
2. **中英影视工业混写边界（v3.26 解除纯中文死锁）：** 叙事因果、物理走位与 `{}` 台词用自然中文；高纯度英文光学/胶片/运镜/音效词（`anamorphic / Kodak Vision3 500T / Kodachrome / skip-bleach / rack focus / whip pan / Dutch angle / parallel tracking / foreground wipe / handheld breathing micro-shake / BRAAM / Riser / Low Drone / Muffled`）**允许且推荐单写点睛**，但**严禁同一概念中英双语复读**，且英文运镜/音效词后**必须附中文物理起止与触发节点**；严禁 `8K / masterpiece / CG / render` 等静态修图废词。
3. **按戏选对路线与情绪音效搭配（详查 `情绪音效与声音桥设计库.md`）：**
   - **路线 A（常规叙事七段式）：** `分镜一（0-4秒）｜...` 整数秒切片，台词 `{}` 前写状态后写声音变化。
   - **路线 B（一镜丝滑调度流）：** 用 `foreground wipe`、`rack focus`、`whip pan`、`parallel tracking` 吃掉硬切，配合 `Windy Swish / Muffled`。
   - **路线 C（物理碰撞破坏流）：** 坡速/盲区前提 → 挤压内凹 → 碎件飞溅 → 尘灰滞后扬起沉降 → 回弹新态，配 `Reverse Riser / Suckback → Sub Impact / BRAAM → Ear Ringing`。
   - **路线 D（无对白质感 TVC）：** 切 `分镜式写法.md`；真人情绪与首尾帧对照 `补充示范 5/6`。
   - **防无脑加音效三铁律：** ① 日常写实稳态只留 `Room Tone + Foley`，禁砸鼓点；② 每 10–15s 段最多 1 次主爆点（`BRAAM / Sub Impact / Drum Hit`）；③ 保护项保留 `不要背景音乐`（仅禁旋律歌曲配乐），写实正剧与母婴 TVC 禁用 `UI Pop / Coin / Glitch`。
4. **段外【跨组衔接台账】＋声桥：** 每组 `10–15s` 独立自足，不跨段写“同上一段”；用 **`J-cut（下场声提前1秒渗入）` / `L-cut（本段余音拖进下段前2秒）` / `Tick Tock` 节律锚**成对焊死跨段出口与入口。

### 3.3 实测防废片红线 & 六大反面警醒（交付前逐条核查）
- **六大反面警醒：**
  1. 左右矢量拧死打结（左来避让→右打把→车必须斜向右前偏滑，不可反拧左撞）；
  2. 速度与盲区动因不足（平路慢速硬撞像自杀，必须提前交代斜坡/湿滑/墙角盲区）；
  3. 前景遮挡方向搞反（放左侧前景而视野向右横移，物体只能左滑出画，不可能从右抹入）；
  4. 首尾帧重复 `@图N` 与缺下镜入口（重复点名易致双人同框；末镜须留动作/物件/声响悬念）；
  5. 台词空降画外前情（无画面铺垫却冒出脱离本段语境的“怎么不跑啊”等幻觉台词）；
  6. 被动句“幽灵门窗”、无源声响与手部道具瞬移（门窗帘开合必须写清谁用哪只手拉开/反手带门关严；声音须先交代场内发声物；手中道具若中途放桌没写拾回，结尾绝不凭空重回手里）。
- **硬禁词红线：** 非片场花絮戏，分镜与保护项均**严禁出现 `摄影师/摄像师/摄影机/相机/三脚架/稳定器/无人机/camera/operator`**（统一改写为 `handheld breathing micro-shake / tracking / 观察高度`）；保护项禁点名不想要的物体（如不写“不出现安全气囊/参考图入片”，改成正向约束“中控台完好、手机屏幕背向视角”）。

## 五、交付自检与仓库维护脚本（全工具实操命令）

- **交付剧本/分镜前必跑验错自审：**
  ```bash
  python tools/check_errors.py 草稿.md --script 剧本.md --review
  ```
  检查 34 条实测高频错项（台词漏改加、乱序、`<>` 人名、机械模板、空反应镜、保护项、打斗废片词等）；v3.25 已原生支持英文 `SHOT NN` 与中文 `分镜一/二/三（A-B秒）` / `分镜一｜A-B秒` 格式识别，回复末附一行 `自审：查了什么，改了什么`。
- **借鉴过案例库后查重：** `python tools/check_copy.py 草稿.md`（查连续 ≥25 字雷同）。
- **入库/升版本后全库体检＋自动同步导出：**
  ```bash
  python tools/check_kb.py
  python tools/export_agent.py --all
  ```
  `check_kb.py` 校验七张工位卡字数预算、规则单源、案例零 `META` 与双端索引一致性、`check_errors.py` 自检；`export_agent.py --all` 同步重生成 `系统提示词/导出/` 下 5 份工位导出提示词及 `给其他AI的接入说明.md`。
