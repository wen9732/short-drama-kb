# 导出的独立系统提示词

这里的文件由 `python3 tools/export_agent.py --all` 自动生成：每个文件＝一张工位卡＋它要读的规则全文，整份粘贴给 GPT、豆包、Kimi 等其他 AI 就能用。

- **不要手改。** 规则在 `.claude/skills/` 里改，改完重新运行导出。
- 文件开头写了导出时的知识库版本和提交号，用来判断是不是最新。
- 编剧（山音）不导出单文件：把 `.claude/skills/script-shanyin/` 整个文件夹上传为知识库，`SKILL.md` 当系统提示词。
- 案例库不在导出里。需要对照案例时，回到本仓库按 `启动.md` 的案例接入去读。
