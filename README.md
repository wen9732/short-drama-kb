# 短剧编导知识库

AI 视频短剧（Seedance 2.5 为主）的编导规则、工位、范例与原始素材。

- **从这里开始：`启动.md`**：一句"启动 X / 调用 X，给我 Y"就能用，任何 AI 都能读懂。
- 总日志：`日志/当前状态.md`
- 工位卡：`工位/`（每个角色读哪几个文件）
- 规则：`.claude/skills/`
- 范例：`范例/`（默认不读，点名才接入）
- 项目：`项目/`
- 维护知识库：`维护手册.md`

在 Claude 会话中接入本仓库后，`CLAUDE.md` 与技能会被加载。
建议设为**私有仓库**：含人物参考、方法论与复刻电影片段的练习稿。
