# 《声声相许》
80 年代末 90 年代初。
公车售票员童嘉许在公车上意外救了海城权势滔天的大佬梁泰声，梁泰声对有未婚夫的童嘉
许一见钟情，随后对她发起了猛烈攻势。他一掷千金只求童嘉许笑，还替童嘉许教训仗势欺
人的大伯，在童嘉许几乎被色狼经理玷污时，夺门而入救下童嘉许。

童嘉许本想和未婚夫卫川结婚以摆脱梁泰声的纠缠，却未能如愿。甚至在婚礼上被出卖，关
键时刻，梁泰声出手相救还求婚，却遭拒绝。后来童嘉许母亲病重，未婚夫承诺要帮忙，却
因劈腿舍不得钱而爽约。梁泰声带钱出现，让童嘉许选择做自己的情人或者结婚一年，童嘉
许选择了后者。

婚后梁泰声贴心照顾岳母，全力保护童嘉许。在相处过程中，童嘉许逐渐发现，原来多年前
救自己的人就是梁泰声，梁泰声也在这段感情中学会了尊重与平等，童嘉许则变得更加清醒
与坚强。两人历经波折，感情逐渐升温，最终解除误会，青根深种，幸福地走到了一起。

## 人物介绍
- **童嘉许**：女主，公车售票员，善良坚韧，虽被生活困境所扰，仍坚守内心底线。面对
梁泰声的强势追求，她果断拒绝，一心想和未婚夫结婚摆脱困境。在母亲病重、未婚夫背叛
后，为救母亲，她无奈选择与梁泰声结婚，在婚姻中逐渐成长，最终认清自己的感情。
- **梁泰声**：男主，是海城权势滔天的大佬，果断狠辣，却对童嘉许一见钟情。他为得到
童嘉许，展开强势追求，用金钱和权势为她扫清障碍。结婚后，他悉心照顾童嘉许的母亲，
在相处中学会尊重与付出，从霸道强势变得温柔深情，只为守护童嘉许一生。
- **卫川**：童嘉许的未婚夫，自私虚伪，表面深情，实则为了利益可以抛弃一切。他在童
嘉许与梁泰声之间摇摆不定，为了钱放弃救助童嘉许母亲，甚至在婚礼上出卖童嘉许，暴露
其丑恶嘴脸。
