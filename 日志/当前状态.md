## 怎么调用

入口 `启动.md`：一句"启动 X / 调用 X，给我 Y"→ 工位卡 → 只读卡里列的文件。案例库默认不读，"调用 <类别> 的写法"才接入。

| 工位 | 卡 | 干什么 | 必读 / 最重一档（字） |
|---|---|---|---|
| 编剧（山音） | `工位/编剧.md` | 想法 → 剧本，五阶段，按阶段只读当前那份 | 1.7 万 / 2.9 万 |
| 导演 | `工位/导演.md` | 一句想法或剧本 → 导演设计（导演出处、站位、镜头表、接缝表）→ 提示词 | 1.8 万 / 2.4 万 |
| 情绪导演 | `工位/情绪导演.md` | 真人情绪戏，克制或爆发 | 0.8 万 / 1.4 万 |
| 爆款策划 | `工位/爆款策划.md` | 短视频选题：Hybrid、高概念、2-5-15 秒 | 0.6 万 / 0.8 万 |
| 美学图像 | `工位/美学图像.md` | 美术定调、参考图、生图提示词 | 0.7 万 / 1 万 |
| 编导总监 | `工位/编导总监.md` | 总控、挑错、`批改：`，按需调度其他工位 | 0.6 万 |
| 库管 | `工位/库管.md` | 入库、收案例、记录、升版本 | 0.7 万 / 1.9 万 |

字数含 `启动.md` 和卡片本身，由 `python3 tools/check_kb.py` 每次自动算出（预算：必读 ≤2 万，最重一档 ≤3 万）。v3.0 前，一次山音调用要先读约 5.6 万字。

给其他 AI 用：`系统提示词/导出/` 下是各工位的独立系统提示词，规则改了运行 `python3 tools/export_agent.py --all` 重新导出。
