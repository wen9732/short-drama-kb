# 生成实验日志

记录每一次拿去生成的提示词：结果怎样、用户怎么评价、问题出在哪一层、改了什么。
**日志是证据，不是规则。** 规则只在 `.claude/skills/` 里；日志里的结论满足"升级门槛"后才能写进规则。

## 记录规则
- 每次生成测试新增一条，编号递增（E001、E002……），**只追加，不删改旧条目**；结论被推翻时新增一条并写"推翻 E00X"。
- **归因层**必填：剧本 / 表演 / 执行 / 动作 / 镜头 / 类型。只改归因层的变量，一次只改一个。
- **升级门槛：** 同一现象在 ≥2 条记录中出现，或用户明确说"以后都这样"，才能升级为规则。升级时在规则后标来源，如 `（经验：E003、E007）`，并在本条"状态"写"已升级 → 某技能"。
- 一次性的个案（某张参考图特有的问题）不升级，只留记录。

## 条目模板
```
### E000｜日期｜片名或场次
- 平台/模型：Seedance 2.5（分辨率、时长）
- 配方：exec-seedance25 + perf-xxx + genre-xxx
- 知识库版本：v1.0
- 提示词：范例或项目文件路径（或直接贴关键段）
- 结果：成功 / 部分翻车 / 翻车
- 现象：看到了什么（具体到秒和部位）
- 用户评价：原话
- 归因层：
- 改动：只改了哪个变量 → 改成什么
- 复测结果：（复测后补）
- 状态：待观察 / 已升级 → 技能名 / 个案不升级
```

### E003｜2026-11-19｜台偶抓马主卧抓包 25 秒单条测试
- 平台/模型：Seedance 2.5（480p，提示词写 25 秒，实测成片压缩为 22 秒）
- 配方：exec-seedance25 + perf-explosive + cam-shot（Alexa 35 + Cooke S4/i + 1/4 Black Pro-Mist）+ 情绪音效与声音桥设计库
- 知识库版本：v3.28
- 提示词：临时会话测试稿（主卧情热→经典挑逗→推门撞破→85mm 落泪特写→冲步甩耳光→男主护短推倒）
- 结果：部分翻车（情绪表演与音效设计通过，存在 3 处实测细节 Bug）
- 现象：
  1. 第 16.02 秒 `85mm` 落泪特写表现极佳（双颊清晰泪痕、眼眶泛红），但第 16.07 秒切至走近扇耳光的 `50mm` 中景时，面部瞬间恢复干爽、毫无哭过痕迹；
  2. 提示词写了“白色欧式木房门”未锁单门实墙，切镜后左侧墙面凭空多刷出一扇带银色把手的关闭白门，与右侧敞开白门形成双门穿帮；
  3. 25 秒（被缩成 22 秒）末尾同时硬塞“冲步甩耳光”和“男方冲出推倒”，模型跳过男方推人过程，导致女方打完一巴掌后自己莫名摔倒。
- 用户评价："情绪表演没问题了……音效设计的可以了；切下个走过去打耳光的镜头又没有哭过的痕迹；房间自动变成好几个门；打完一巴掌自己也摔倒了，应该是被男主推倒的；后续遇到这种情况先审稿判断是否合理，因为上限是 30 秒。"
- 归因层：执行（单条时长超载未前置审稿）＋镜头/空间（缺单门实墙锚定）＋表演（跨镜湿润泪痕未显式延续）＋动作因果（多人连续受力未独立拆拍）
- 改动：
  1. 升格为 **30 秒单条完整版**，将“冲步扇耳光（16-22秒）”与“男方跨步伸手推肩→女方受力跌坐（22-26秒）”彻底拆分独立成拍；
  2. 下一镜显式写死“脸颊挂着未干湿润泪痕、眼眶鼻头持续泛红、沾湿碎发贴颊”；
  3. 锁定“全室仅右侧一扇唯一单开白木门，其余墙面为平滑无框素色实墙”。
- 复测结果：待用户用 30 秒修订版复测后补记
- 状态：已升级 → `工位/_共用/错误库.md`（错35–错38）、`工位/_共用/错误速查.md`（第 14 问）、`exec-seedance25/references/剧本转分镜通用路线.md`（Phase 0 时长密度前置审稿）

### E004｜2026-11-19｜都市霓虹 3A CG 高燃长镜测试 v1（瞬发出拳穿楼）
- 平台/模型：Seedance 2.5（480p，提示词写 25 秒，实测成片约 22 秒）
- 配方：exec-seedance25 + fight-combat + cam-shot（次世代雨夜霓虹 3A CG 质感 + 24mm 荷兰角 + FPV 低空纵深推进）+ 情绪音效与声音桥设计库
- 知识库版本：v3.29
- 提示词：临时会话测试稿（纵深雨夜街景→0.5s 蓄力音爆瞬发重拳穿楼→混凝土柱崩裂→Boss 刃雨反扑→高速近战交锋→Speed-Ramp 环绕收尾）
- 结果：部分翻车（动作升级与 PBR 质感过关，存在 3 处空间逻辑与破坏权重 Bug）
- 现象：
  1. 开场 0.5 秒蓄力音爆闪现重拳将 Boss 击飞穿过多层建筑玻璃/卷帘门/混凝土柱，质感与瞬发打击感大幅升级（第 10.08 秒可见卷帘门撕裂、混凝土柱浓烟）；但随后切至双人近身贴脸交锋（第 17.17 秒、第 20.00 秒）时，**完全未交代双方如何跨越被击飞后的长距离重新贴身**，出现“无理由空间瞬移回归同框”逻辑断层；
  2. Boss 撞入混凝土柱后缺乏“释放能量震飞压身碎石、清场起势”的过渡动作；
  3. Boss 释放漫天黑羽大招时缺乏实体破坏（未拍出街道汽车被劈碎、商铺门面重创爆炸）与重磅爆破音效支撑，观感偏飘、力量感不足。
- 用户评价："这次的升级很大，特别是瞬发出拳；但是 AI 最大的问题就是空间突然位移、没有理由……击飞出去了，没说怎么最后几秒又进入双人战斗场景；混凝土柱崩裂没问题，但缺乏大招震飞碎石的画面；羽刃大招缺乏力量感，必须配重磅音效，街道汽车和店铺都要被重创破坏、爆破声……"
- 归因层：动作（击飞后缺拉近距离过渡拍＋大招缺起势震石与实体破坏）＋镜头/空间（跨区空间逻辑未闭环）＋音效（大招缺重型爆破音轨）
- 改动：在 v2（E005）中精简信息密度、补全 Boss 震飞碎石＋重创街车店铺爆炸＋近战 8 秒非回合制连续力学链，并尝试用空间通道解释拉近距离。
- 复测结果：见 E005（动作近战与大招破坏升级过关，但空间通道引发新 Bug）
- 状态：已升级 → `工位/_共用/错误库.md`（错44）、`工位/_共用/错误速查.md`（第 16 问）、`fight-combat/references/打斗审核.md`（第五节）

- 平台/模型：Seedance 2.5（480p，提示词写 25 秒，实测成片 22 秒）
- 配方：exec-seedance25 + fight-combat + cam-shot + 情绪音效与声音桥设计库
- 知识库版本：v3.29
- 提示词：临时会话测试稿 v2（Boss 震飞碎石＋大招炸毁街车店铺→男主撕开蓝色空间通道切入→8 秒高密度非回合制近身对抗→Speed-Ramp 破面终结）
- 结果：部分翻车（两套方案的动作升级、PBR 质感与连续近战编排均过关，但空间通道出现严重拓扑幻觉与能力体系违和）
- 现象：
  1. 第 00:06.17 秒，提示词让男主正面伸手撕开空间通道，但模型将发光蓝色光环画在了男主**正后背**（形同背后光环）；
  2. 第 00:07.05 秒，男主迈步向镜头前右侧**背离光环往前跑**，完全没有钻进通道；
  3. 第 00:09.19 秒，下一镜却直接画成男主从 Boss 身侧的蓝色光环里单膝钻出落地，形成前后逻辑断裂的 AI 空间幻觉；
  4. 设定层面：物理高速近战型角色强行赋予“手撕空间通道”的法术技能与人设割裂，空间裂隙能力归属超自然妖魔 Boss 才合乎世界观逻辑。
- 用户评价："出现了 bug，空间通道应该是大黑狗 boss 更为合理吧，因为你赋予人物召唤空间通道不合理吧，他都释放空间通道了，人物还要跑向怪物，下一幕又从空间通道出来，形成了逻辑 Bug 只是 AI 出现的幻觉。这 2 个方案动作升级是过关的，出现的 bug 给我记录在案，包括优化后的写法提炼。"
- 归因层：动作/设定（能力体系乱嫁接）＋镜头/空间（正面视角拍传送门致拓扑画反，缺少侧面/背过肩拍清“门在正前方→扑入彻底消失”）
- 改动：不再让物理系角色硬开法术空间门；将空间位移归属原则、传送门三拍防反拓扑写法及两版验证过关的高燃 CG 动作写法提炼入库。
- 复测结果：本轮动作机制测试收官（用户明确无需再出提示词，直接沉淀入库）
- 状态：已升级 → `工位/_共用/错误库.md`（错45）、`工位/_共用/错误速查.md`（第 16 问）、`fight-combat/references/打斗审核.md`（第五节）、`cam-shot/references/空间与调度.md`（第四节）
