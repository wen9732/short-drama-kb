# 生成实验日志

记录每一次拿去生成的提示词：结果怎样、用户怎么评价、问题出在哪一层、改了什么。
**日志是证据，不是规则。** 规则只在 `.claude/skills/` 里；日志里的结论满足"升级门槛"后才能写进规则。

## 记录规则
- 每次生成测试新增一条，编号递增（E001、E002……），**只追加，不删改旧条目**；结论被推翻时新增一条并写"推翻 E00X"。
- **归因层**必填：剧本 / 表演 / 执行 / 动作 / 镜头 / 类型。只改归因层的变量，一次只改一个。
- **升级门槛：** 同一现象在 ≥2 条记录中出现，或用户明确说"以后都这样"，才能升级为规则。升级时在规则后标来源，如 `（经验：E003、E007）`，并在本条"状态"写"已升级 → 某技能"。
- 一次性的个案（某张参考图特有的问题）不升级，只留记录。

## 条目模板
```
### E000｜日期｜片名或场次
- 平台/模型：Seedance 2.5（分辨率、时长）
- 配方：exec-seedance25 + perf-xxx + genre-xxx
- 知识库版本：v1.0
- 提示词：范例或项目文件路径（或直接贴关键段）
- 结果：成功 / 部分翻车 / 翻车
- 现象：看到了什么（具体到秒和部位）
- 用户评价：原话
- 归因层：
- 改动：只改了哪个变量 → 改成什么
- 复测结果：（复测后补）
- 状态：待观察 / 已升级 → 技能名 / 个案不升级
```

### E003｜2026-11-19｜台偶抓马主卧抓包 25 秒单条测试
- 平台/模型：Seedance 2.5（480p，提示词写 25 秒，实测成片压缩为 22 秒）
- 配方：exec-seedance25 + perf-explosive + cam-shot（Alexa 35 + Cooke S4/i + 1/4 Black Pro-Mist）+ 情绪音效与声音桥设计库
- 知识库版本：v3.28
- 提示词：临时会话测试稿（主卧情热→经典挑逗→推门撞破→85mm 落泪特写→冲步甩耳光→男主护短推倒）
- 结果：部分翻车（情绪表演与音效设计通过，存在 3 处实测细节 Bug）
- 现象：
  1. 第 16.02 秒 `85mm` 落泪特写表现极佳（双颊清晰泪痕、眼眶泛红），但第 16.07 秒切至走近扇耳光的 `50mm` 中景时，面部瞬间恢复干爽、毫无哭过痕迹；
  2. 提示词写了“白色欧式木房门”未锁单门实墙，切镜后左侧墙面凭空多刷出一扇带银色把手的关闭白门，与右侧敞开白门形成双门穿帮；
  3. 25 秒（被缩成 22 秒）末尾同时硬塞“冲步甩耳光”和“男方冲出推倒”，模型跳过男方推人过程，导致女方打完一巴掌后自己莫名摔倒。
- 用户评价："情绪表演没问题了……音效设计的可以了；切下个走过去打耳光的镜头又没有哭过的痕迹；房间自动变成好几个门；打完一巴掌自己也摔倒了，应该是被男主推倒的；后续遇到这种情况先审稿判断是否合理，因为上限是 30 秒。"
- 归因层：执行（单条时长超载未前置审稿）＋镜头/空间（缺单门实墙锚定）＋表演（跨镜湿润泪痕未显式延续）＋动作因果（多人连续受力未独立拆拍）
- 改动：
  1. 升格为 **30 秒单条完整版**，将“冲步扇耳光（16-22秒）”与“男方跨步伸手推肩→女方受力跌坐（22-26秒）”彻底拆分独立成拍；
  2. 下一镜显式写死“脸颊挂着未干湿润泪痕、眼眶鼻头持续泛红、沾湿碎发贴颊”；
  3. 锁定“全室仅右侧一扇唯一单开白木门，其余墙面为平滑无框素色实墙”。
- 复测结果：待用户用 30 秒修订版复测后补记
- 状态：已升级 → `工位/_共用/错误库.md`（错35–错38）、`工位/_共用/错误速查.md`（第 14 问）、`exec-seedance25/references/剧本转分镜通用路线.md`（Phase 0 时长密度前置审稿）
