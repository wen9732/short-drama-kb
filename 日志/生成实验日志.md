# 生成实验日志

记录每一次拿去生成的提示词：结果怎样、用户怎么评价、问题出在哪一层、改了什么。
**日志是证据，不是规则。** 规则只在 `.claude/skills/` 里；日志里的结论满足"升级门槛"后才能写进规则。

## 记录规则
- 每次生成测试新增一条，编号递增（E001、E002……），**只追加，不删改旧条目**；结论被推翻时新增一条并写"推翻 E00X"。
- **归因层**必填：剧本 / 表演 / 执行 / 动作 / 镜头 / 类型。只改归因层的变量，一次只改一个。
- **升级门槛：** 同一现象在 ≥2 条记录中出现，或用户明确说"以后都这样"，才能升级为规则。升级时在规则后标来源，如 `（经验：E003、E007）`，并在本条"状态"写"已升级 → 某技能"。
- 一次性的个案（某张参考图特有的问题）不升级，只留记录。

## 条目模板
```
### E000｜日期｜片名或场次
- 平台/模型：Seedance 2.5（分辨率、时长）
- 配方：exec-seedance25 + perf-xxx + genre-xxx
- 知识库版本：v1.0
- 提示词：范例或项目文件路径（或直接贴关键段）
- 结果：成功 / 部分翻车 / 翻车
- 现象：看到了什么（具体到秒和部位）
- 用户评价：原话
- 归因层：
- 改动：只改了哪个变量 → 改成什么
- 复测结果：（复测后补）
- 状态：待观察 / 已升级 → 技能名 / 个案不升级
```

### E003｜2026-11-19｜台偶抓马主卧抓包 25 秒单条测试
- 平台/模型：Seedance 2.5（480p，提示词写 25 秒，实测成片压缩为 22 秒）

- 结果：部分翻车（情绪表演与音效设计通过，存在 3 处实测细节 Bug）
- 现象：
  1. 第 16.02 秒 `85mm` 落泪特写表现极佳（双颊清晰泪痕、眼眶泛红），但第 16.07 秒切至走近扇耳光的 `50mm` 中景时，面部瞬间恢复干爽、毫无哭过痕迹；

  3. 25 秒（被缩成 22 秒）末尾同时硬塞“冲步甩耳光”和“男方冲出推倒”，模型跳过男方推人过程，导致女方打完一巴掌后自己莫名摔倒。

  3. 锁定“全室仅右侧一扇唯一单开白木门，其余墙面为平滑无框素色实墙”。

### E007｜2026-11-20｜真人情绪短剧室内对话 24 秒实测（四项高频翻车复盘）
- 平台/模型：Seedance 2.5（720p，首帧转场＋24 秒室内对话）
- 配方：exec-seedance25 + perf-restrained + cam-shot（ARRI Mini LF + 47mm/Cooke S4/i）
- 知识库版本：v3.33
- 提示词：室内对话 24 秒实测稿（50mm 全身关门＋沙发坐姿正反打＋拨号界面贴耳）
- 结果：部分翻车（人物颜值与光色接近预期，但出现 4 个明显实拍穿帮与情绪失真）
- 现象：
  1. **全身/中景致背景半实不虚与穿帮（`00:05.19`、`00:08.08`）：** 关门给到全身与大客厅背景，背景沙发、落地窗、电视柜均处于“半实不虚”状态，既丢失大光圈商业电影质感，又暴露空间穿帮；
  2. **情绪正向词串味导致内疚角色演成“高兴得意”（`00:12.00`）：** 提示词对自责方写了“难掩庆幸、轻快自然”及偏推卸责任的台词，模型直接生成了轻松甚至略带得意的笑脸，与剧情情绪背道而驰；
  3. **贴耳接电话手机拿反（`00:24.07`）：** 因在贴耳动作同镜写了“屏幕显示拨号参考图”，模型为了把屏幕画面露给镜头，直接将手机物理翻转成**蓝色屏幕朝外、手机背面贴在耳朵上**；
  4. **坐姿固定正反打显得僵硬：** 人物坐沙发静态对谈，缺乏站立调度与单主体轻甩运镜的短剧流动感。
- 用户评价："爸爸的表情还很高兴（完全不对）；减少全身、减少大景，背景需要大光圈的景深关系避免穿帮，不要半实不虚，要高度虚化；接电话 AI 容易搞反，必须是显示屏对着耳朵；人物不要坐着，运镜对话改为人物两边轻甩对着单主体；整理作为 bug 失败库。"
- 归因层：镜头景深（未用半身中近景＋明确 T1.4 高度虚化）＋表演情绪污染（负向基调句中混入正向情绪词）＋物理道具朝向未锁死（贴耳镜要求显示屏幕诱发手机反转）
- 改动：沉淀为 `错48`、`错49`、`错50` 写入通用错误库与速查表；重写傍晚黄金黄昏光影版半身站姿＋单主体轻甩运镜＋T1.4 高度虚化提示词。
- 复测结果：待用户跑新版傍晚版复测
- 状态：已升级 → `工位/_共用/错误库.md`（错48–错50）、`工位/_共用/错误速查.md`（第 18 问）
