# 《儿童座椅TVC》项目档案

> 本档案仅用于《儿童座椅TVC》项目跨窗口交接与资产防漂移，不作知识库通用规则或案例样本外流。

## 项目配置
- **形态与画幅：** 16:9 真人实拍都市家庭情感商业短片（母婴安全座椅题材）。
- **核心商业诉求：** 用真实惊险的追尾事故与亲子情绪反差，证明儿童安全座椅在突发碰撞中的保护力与家庭安心感。
- **全片全局影调基准：** 采用 `情境化全局影调与器材美学库.md` **预设 H（商业人像与温暖家庭 TVC）**——暖白通透肤色、保留立体光影与真实肌理、背景自然光学虚化与柔和光斑（不压人脸）、黑皮革/紫座椅面料/白车漆层次扎实、无塑料磨皮与虚假泛光；**突发事故后仍维持可信白天自然光，绝不切冷蓝灾难片滤镜**。

| 对象 | 身份与固定状态 | 空间 / 视觉防漂移红线 |

## 整片情绪线与场次规划
1. **第一场（已完成分镜拆分，待实测）：** 突发追尾的惊险 → 确认孩子被安全座椅稳稳保护的后怕 → 转移到远离车道的右侧安全人行道内侧驻足护娃报警（保留白车尾部双闪规律跳动，彻底消除“人走光变空镜”造成的肇事逃逸误解）。
   - **A 组（15s）：** 温和入睡 → 堵车急刹 → 后车实撞左后尾 → 撞击声桥同步震醒大哭 → 确认安抚与按顶置双闪。
   - **B 组（14s）：** 车外事故双车与橘色双闪跳动实况 → 树影俯摇揭示安全人行道 → 爸爸抱娃护背焦急报警并驻足守候收尾（与远处闪烁双闪的双车同框）。
2. **后续场次（待推进）：** 回家后夫妻间的埋怨与后怕（可切 `perf-restrained`＋预设 A 私密室内暖冷光分裂）→ 售后给出解决方案 → 一家人重归安心（需补充未写完的后段剧本细节）。
